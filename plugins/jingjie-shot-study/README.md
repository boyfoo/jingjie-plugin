# 镜界拉片

版本 0.5.5。提供完整视频拉片，交付镜头与视听分析，并深入对应既有文字与画面的关系、差异和真实证据。

语义拆分与查漏：独立成败分别判断，保留新主体及限定，后续自然承接；先逐句查原文遗漏，再逐项查证据。MCP 结构校验、译文齐全和保存回执不能替代全文语义检查。拆分变更后核对已授权目标语言，插件升级本身不修改案例。详见[方法与注意事项](skills/video-shot-study/references/judgment-and-coverage.md)和[八组行为示例](skills/video-shot-study/references/segmentation-examples.md)。

- `skills/video-shot-study/`：完整拉片主流程，包含观察方法、镜头分析、原文来源核验、文字与画面的深入对应及镜界保存规则。
- `mcp.json`：镜界 MCP 连接配置，需要使用者在自己的电脑上运行与该配置匹配的镜界服务。
- `.codex-plugin/plugin.json` 与 `.mcp.json`：Codex 客户端配置。
- `assets/`：复用镜界现有品牌图标，主题色为 `#fcd535`。

本包不包含镜界服务器或视频处理工具，也不负责启动它们。没有运行镜界服务时，仍可按 skill 做本地拉片；镜界工具无法连接，需要先启动服务。

使用示例：

```text
使用镜界拉片，对这个视频做有画面证据的拉片，核对完整提示词来源：<视频链接>
```

```text
使用 video-shot-study 分析这份提示词与画面的对应，复用镜头与观察，解释具体呈现、时空关系、差异、真实证据时间与判断限制。
```

拉片及局部画面分析必须先取得与视频对应、完整且可核实的提示词原文；未取得时说明缺口，停下来等待用户补充，不开始视听分析或新建、上传、保存拉片资料。脚本可作补充，不能替代提示词。

通过前置检查后，video-shot-study 完成逐镜分析与提示词、脚本和画面的深入对应，无需另行询问是否深入，也不以 MCP 提交为前提。复用同版素材和既有证据，只补所需观察，不从成片补写要求。局部镜头或文字对应任务只处理选定范围，提取、翻译、保存文本及接口界面开发保持原任务范围。

完整拉片与深入对应交付后，仅在用户尚未决定时询问是否提交。已有保存授权时，将本次拉片与深入分析写入同一案例并逐模块回读，不单独确认深入模块；写入与翻译按各自授权执行。MCP 保存编辑稿，发布由用户在网站操作。

拉片按[源版语言与可选翻译流程](skills/video-shot-study/references/languages.md)执行：先取得完整提示词并核实真实原语言，未取得则停止并等待补充。已授权保存时先保存源版并回读，再询问是否翻译。中文交流不改变作者原文语言；已有明确语言选择沿用，不重复问，已有案例不擅自改 `sourceLanguage`。

需要翻译时，先读 `jingjie_get_translation_context`，再用 `jingjie_save_translation` 保存到同一案例的对应目标语言，保留源版。保存后回读两版全文，不只看 `current`，并交付用户所需语言的入口。深入对应与文字锚点按上述语言与翻译流程处理；不补写未授权模块，不改原文、媒体、时间或分析结论，不自动发布。仅本地翻译不自动新建案例或上传。

可选翻译包含自由补充标签的显示名，原标签和固定分类值保持不变。

本插件源码同时支持通用插件格式及 Codex 插件市场。在 Codex 终端执行：

```powershell
codex plugin marketplace add https://github.com/boyfoo/jingjie-plugin.git
codex plugin add jingjie-shot-study@jingjie-local
```

也可进入本地仓库根目录，运行 `codex plugin marketplace add .`，再执行上面的插件安装命令。详细步骤见仓库根目录 README。
