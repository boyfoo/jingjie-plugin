# 镜界拉片

版本 0.5.7。包含 `video-shot-study` 技能：先核实完整提示词，再逐镜观察视频，逐项说明要求的实现情况、差异和证据。

**能分别成立或失败的要求要拆开核对，每项引用也要准确对应原文。** 每项保留主体、条件和适用范围，根据自己的证据作判断。本项只有一部分得到直接支持时，可以记部分匹配，并写清已看到什么、还差什么或哪里没看清。分析后从原文查漏项，再逐项核对引用和证据。方法与表达可以灵活选择，接口成功不代表分析已经完成。详见[分析方法](skills/video-shot-study/references/judgment-and-coverage.md)和[拆分示例](skills/video-shot-study/references/segmentation-examples.md)。

## 包含内容

- `skills/video-shot-study/`：观察视频、逐镜分析、核实提示词来源、逐项对照提示词与画面，以及按授权保存镜界资料的说明。
- `mcp.json`：镜界 MCP 连接配置，需要在本机运行与配置匹配的镜界服务。
- `.codex-plugin/plugin.json` 与 `.mcp.json`：Codex 客户端配置。
- `assets/`：镜界现有图标，主题色为 `#fcd535`。

本包不包含镜界服务器、服务启动器或视频处理工具。未启动镜界服务时仍可在本地拉片；要使用镜界工具，需要先启动服务。

## 使用

```text
使用镜界拉片，对这个视频做有画面证据的拉片，并核对完整提示词及来源：<视频链接>
```

```text
使用 video-shot-study 分析这份提示词与画面的对应：复用已有镜头和观察，逐项说明实际表现、差异、判断和证据时间。
```

**拉片及局部画面分析前，必须取得并核实与视频对应的完整提示词。** 缺失或无法确认完整性时，说明缺口并等待补充，不开始画面分析，也不新建案例、上传或保存拉片资料。剧情或分镜脚本等资料可作补充，不能替代提示词。

完整拉片包含逐镜分析和提示词与画面的逐项对照，无需单独确认是否深入分析，也不以提交镜界为前提。复用同版素材和有效证据，按问题补查，不从成片反写要求。局部分析、文字提取、翻译、保存文本或界面／接口开发，按用户指定范围处理。

交付完整拉片后，仅在用户尚未决定时询问是否保存。已有授权就直接写入同一案例并逐模块回读，不再单独确认深入分析模块。**MCP 只保存编辑稿，发布由用户在镜界网站操作。** 仅修改 skill 方法，不会自动修改已有案例。

语言按[源版与翻译流程](skills/video-shot-study/references/languages.md)处理：源版采用提示词的实际语言，先完成并核对源版，再按用户选择翻译。中文交流不会改变原文语言；已有明确选择时沿用，不重复询问。中文译成英文、英文译成中文及服务支持的其他已授权方向使用同一套原则。

保存译文到镜界时，先读取 `jingjie_get_translation_context`，再用 `jingjie_save_translation` 保存到同一案例的目标语言，保留源版。保存后核对两版全文、引用和对应关系，不只看 `current`，并提供用户所需语言的入口。通常复用有效的媒体、时间和分析结论；发现实质问题时按任务范围补查或修正。翻译不额外授权修改或发布，单纯本地翻译不自动新建案例或上传。自由补充标签的显示名可翻译，原标签和固定分类值保持不变。

## 安装

本插件支持通用插件格式及 Codex 插件市场。在 Codex 终端执行：

```powershell
codex plugin marketplace add https://github.com/boyfoo/jingjie-plugin.git
codex plugin add jingjie-shot-study@jingjie-local
```

也可进入本地仓库根目录，运行 `codex plugin marketplace add .`，再执行上面的插件安装命令。安装前提、检查连接和完整包结构见仓库根目录 README。
