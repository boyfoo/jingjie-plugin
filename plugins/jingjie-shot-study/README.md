# 镜界拉片

完整拉片从提示词核实和逐镜分析一直做到保存镜界草稿。用户可以直接打开草稿查看画面、原文引用和对应分析。

**能分别成立或失败的要求要拆开核对，每项引用也要准确对应原文。** 每项保留主体、条件和适用范围，根据自己的证据作判断。成片符合要求判已实现，不符或未呈现判失配；无法判断仅用于声音相关项。写明判断依据，取证尚未完成时先补查。分析后从原文查漏项，再逐项核对引用和证据。方法与表达可以灵活选择，接口成功不代表分析已经完成。详见[分析方法](skills/video-shot-study/references/judgment-and-coverage.md)和[拆分示例](skills/video-shot-study/references/segmentation-examples.md)。

## 包含内容

- `skills/video-shot-study/`：核实完整提示词、观察画面、逐项对照，并保存和核对镜界草稿。
- `mcp.json`：镜界 MCP 连接配置，需要在本机运行与配置匹配的镜界服务。
- `.codex-plugin/plugin.json` 与 `.mcp.json`：Codex 客户端配置。
- `assets/`：镜界现有图标，主题色为 `#fcd535`。

本包不包含镜界服务器、服务启动器或视频处理工具。未启动镜界服务时仍可在本地拉片；要使用镜界工具，需要先启动服务。

## 使用

```text
使用镜界拉片，对这个视频做完整拉片，保存到镜界草稿并返回链接：<视频链接>
```

```text
使用 video-shot-study 分析这份提示词与画面的对应：复用已有镜头和观察，逐项说明实际表现、差异、判断和证据时间。
```

**拉片及局部画面分析前，必须取得并核实与视频对应的完整提示词。** 缺失或无法确认完整性时，说明缺口并等待补充，不开始画面分析，也不新建案例、上传或保存拉片资料。剧情或分镜脚本等资料可作补充，不能替代提示词。

首次分析前先读取镜界指南、可选标签和字段说明，弄清要保存什么、怎么填写。核实完整提示词后，逐镜分析并对照画面，同时整理要保存的资料。分析重点由任务和实际素材决定。局部分析和文字提取按用户指定的范围处理。

完整拉片使用同一镜界案例保存资料。保存后重新读取正文，确认正确再交付草稿链接，无需另问是否提交。用户在镜界浏览完整分析；本地保留素材、证据和工作数据，无需再制作供浏览的网页或报告。

语言按[原语言内容与翻译流程](skills/video-shot-study/references/languages.md)处理。确认提示词语言后，直接用该语言填写分析说明，交流用用户指定的语言。先交付原语言的草稿链接，再由用户选择一个或多个翻译语言，也可以跳过。每选一种语言，都翻译整个案例，包括完整提示词、所有镜头和深入分析。

保存译文到镜界时，先调用 `jingjie_get_translation_context` 读取原文和填写要求，再用 `jingjie_save_translation` 保存到同一案例，原语言内容保留。保存后核对原文和译文的全文、引用的文字及其位置，再提供对应语言的链接。已经核实的素材、时间和分析结论直接使用；发现问题时，只补查或修改用户允许处理的部分。翻译不包含发布授权；只在本地翻译时，不新建案例或上传。补充标签的显示名称可翻译，已选标签值和视频时间各语言共用。

## 安装

本插件支持通用插件格式及 Codex 插件市场。在 Codex 终端执行：

```powershell
codex plugin marketplace add https://github.com/boyfoo/jingjie-plugin.git
codex plugin add jingjie-shot-study@jingjie-local
```

也可进入本地仓库根目录，运行 `codex plugin marketplace add .`，再执行上面的插件安装命令。安装前提、检查连接和完整包结构见仓库根目录 README。
