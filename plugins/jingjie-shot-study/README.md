# 镜界拉片

版本 0.5.3。提供完整视频拉片与视频反推提示词。拉片交付镜头与视听分析，并深入对应既有文字与画面的关系、差异和真实证据；反推根据视频交付可直接使用的AI生成提示词，两者按用户目标独立进入。

- `skills/video-shot-study/`：完整拉片主流程，包含观察方法、镜头分析、原文来源核验、文字与画面的深入对应及镜界保存规则。
- `skills/video-to-director-prompt/` · 视频反推提示词：输入参考视频和用户意图，输出完整AI生成提示词及必要的参考图方案。导演思维、动作逻辑和光影分析服务于制作输入的转译与合理改编；已有反推任务可根据试片继续修正提示词并锁定成功内容。普通拉片或只核对文字实现情况不使用本技能，无需先交拉片报告、取得作者原文或提交镜界。
- `mcp.json`：镜界 MCP 连接配置，需要使用者在自己的电脑上运行与该配置匹配的镜界服务。
- `.codex-plugin/plugin.json` 与 `.mcp.json`：Codex 客户端配置。
- `assets/`：复用镜界现有品牌图标，主题色为 `#fcd535`。

本包不包含镜界服务器或视频处理工具，也不负责启动它们。没有运行镜界服务时，仍可按 skill 做本地拉片；镜界工具无法连接，需要先启动服务。

本地反推、改编与试片复盘也不依赖镜界服务。两个技能可复用已有素材和证据，任务分工不要求重复跑完整分析。

使用示例：

```text
使用镜界拉片，对这个视频做有画面证据的拉片，核对完整提示词来源：<视频链接>
```

```text
使用 video-shot-study 分析这份提示词与画面的对应，复用镜头与观察，解释具体呈现、时空关系、差异、真实证据时间与判断限制。
```

```text
使用镜界插件里的 video-to-director-prompt，根据这个视频反推完整可用的AI视频生成提示词，结合我的想法做合理改编，并说明需要哪些参考图及各自用途：<视频链接>
```

```text
用 video-to-director-prompt 根据这次试片修正生成提示词，核对实际输入，保留成功段落，只修改需要变化的文字或参考图安排。
```

视频反推提示词是独立任务入口，不是普通拉片的默认后续步骤。收到反推请求时必须交付完整可用的生成提示词，单有分析或分镜不算完成。导演判断和参考图配置用于支持这个产出；反推过程中的局部咨询按当前问题回答。新提示词与作者原文分开，也不能用新方案反过来证明旧试片实现了原要求。需要交付制作包时，参考图文件名与 `@图片N` 对应，HTML先展示图片与用途，再展示可复制的完整提示词。

video-shot-study 是完整拉片入口，直接完成逐镜分析与提示词、脚本和画面的深入对应，无需另行询问是否深入，也不以 MCP 提交为前提。复用同版素材和既有证据，只补所需观察；缺少可用比较文本时说明缺口，不从成片反写要求。局部镜头或文字对应任务只处理选定范围，提取、翻译、保存文本及接口界面开发保持原任务范围。

完整拉片及可完成的深入对应交付后，仅在用户尚未决定时询问是否提交。已有保存授权时，将本次拉片与深入分析写入同一案例并逐模块回读，不单独确认深入模块；写入与翻译按各自授权执行。MCP 保存编辑稿，发布由用户在网站操作。

两个技能使用同一[源版语言与可选翻译流程](skills/video-shot-study/references/languages.md)：先取得实际提示词，按真实原语言保存源版并回读，再询问是否翻译。中文交流不改变作者原文语言；已有明确语言选择沿用，不重复问，已有案例不擅自改 `sourceLanguage`。无作者原文的反推任务按用户制作要求确定语言。

需要翻译时，先读 `jingjie_get_translation_context`，再用 `jingjie_save_translation` 保存到同一案例的对应目标语言，保留源版。保存后回读两版全文，不只看 `current`，并交付用户所需语言的入口。深入对应与文字锚点沿用共用流程；不补写未授权模块，不改原文、媒体、时间或分析结论，不自动发布。仅本地翻译不自动新建案例或上传。

可选翻译包含自由补充标签的显示名，原标签和固定分类值保持不变。

本插件源码同时支持通用插件格式及 Codex 插件市场。在 Codex 终端执行：

```powershell
codex plugin marketplace add https://github.com/boyfoo/jingjie-plugin.git
codex plugin add jingjie-shot-study@jingjie-local
```

也可进入本地仓库根目录，运行 `codex plugin marketplace add .`，再执行上面的插件安装命令。详细步骤见仓库根目录 README。
