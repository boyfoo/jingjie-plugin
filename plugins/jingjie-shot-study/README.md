# 镜界拉片

版本 0.3.4。先完成真实视频逐镜拉片及已授权的镜界草稿提交，写入与回读成功后，询问用户是否深入画面与文字的对应；同意后才运行增强分析。

- `skills/video-shot-study/`：基础拉片技能与主流程，包含观察方法、镜头分析、作者原文来源核验和镜界保存规则。
- `skills/video-prompt-alignment/`：用户明确选择后的可选增强，关闭隐式调用；复用基础拉片证据，深化全文语义、时空与主体关系、持续设定及阶段变化的理解，解释具体呈现、差异与判断限制。
- `mcp.json`：镜界 MCP 连接配置，需要使用者在自己的电脑上运行与该配置匹配的镜界服务。
- `.codex-plugin/plugin.json` 与 `.mcp.json`：当前 Codex 客户端兼容配置。
- `assets/`：复用镜界现有品牌图标，主题色为 `#fcd535`。

本包不包含镜界服务器或视频处理工具，也不负责启动它们。没有运行镜界服务时，仍可按 skill 做本地拉片；镜界工具无法连接，需要先启动服务。

使用示例：

```text
使用镜界拉片，对这个视频做有画面证据的拉片，核对完整提示词来源：<视频链接>
```

```text
在已有拉片基础上，用 video-prompt-alignment 深化提示词与画面的关系，复用镜头与观察，解释具体呈现、时空关系、差异与判断限制。
```

video-shot-study 是默认拉片入口。普通拉片、取得提示词或 MCP 提交成功都不自动启动增强。默认完成基础拉片和已授权的 MCP 提交、回读核对后，报告提交结果并询问“要不要继续深入分析画面与文字的对应关系？”用户明确同意后才读取 video-prompt-alignment，承接原拉片进一步分析。

用户拒绝或未答复时不执行增强；未提交、提交或回读失败时，不提前发起默认深入邀请。用户已明确主动要求深入时沿用授权，不重复问、不强制重做全片或提交 MCP。增强获授权后复用已有证据；缺少比较文本时说明缺口，不反写要求。提取、翻译、保存文本及接口界面开发保持原范围。增强只沉淀分析方法，数据字段、结构、接口和产品功能由前后端设计。同意深入本身不自动授权再次写入草稿。

拉片完成后主动询问是否提交；用户明确同意或已经授权时才写入镜界。提交和回读核对成功后，再询问是否深入分析。提交、翻译与深入分析是不同选择，不能互相替代授权。镜界 MCP 保存的是编辑稿，发布由用户在网站操作。

提示词包含非中文正文时，已要求翻译就直接完成，尚未决定时才在其他已授权任务完成后询问，明确拒绝后不再追问。译文保留原有时间且不覆盖原文；仅在用户授权保存时写入镜界并回读核对。

本插件源码同时支持通用插件格式及 Codex 插件市场。在 Codex 终端执行：

```powershell
codex plugin marketplace add https://github.com/boyfoo/jingjie-plugin.git
codex plugin add jingjie-shot-study@jingjie-local
```

也可进入本地仓库根目录，运行 `codex plugin marketplace add .`，再执行上面的插件安装命令。详细步骤见仓库根目录 README。
