# 真实观察与参考资产

用于取得素材、理解运动、判断画面质感和配置参考图。已有素材与局部诊断优先复用，只补当前问题所需证据。

## 建立观察依据

先确认实际文件和版本，按需读取时长、分辨率、帧率、时间基准、起始偏移及音轨。可变帧率或有偏移时使用帧时间戳，不简单用帧号除标称帧率；内部保留寻帧精度。

- 先覆盖整体节奏，再回看快速动作、遮挡、反转、触地和剪切附近的密集帧；抽出帧后必须实际查看。
- 用过程判断身体朝向、位置、支撑点、前后景和结束状态，区分主体旋转、相机环绕与相机滚转。透视歧义未消除时保留不确定性。
- 差分峰值只提供切点候选；遮挡、闪光、模糊或景别变化本身不证明切镜，需核对前后时空关系。
- 有音轨不等于已听音。未试听的内容可另作声音设计建议，不能当作原片事实。

素材不可读时说明缺口，用户描述只作暂定需求。作者原文与反推方案分开；用户要求核验作者原文时才追查来源，没有原文仍可进行有证据的创作。

## 从观察提取制作依据

| 维度 | 要理解的关系 |
| --- | --- |
| 主动作 | 触发、准备、重心、发力、接触、结果与退出，不能只记姿态名称 |
| 空间 | 主体、目标、地标、运动方向与前中后景，区分人物位移和视点变化 |
| 摄影与剪辑 | 观看位置、信息揭示、切点动机和跨镜延续 |
| 光影与材质 | 主次光、亮暗层级、受光、粗糙度与反射 |
| 特效 | 产生位置、形态尺度、路径、作用及消散 |
| 表演与次级运动 | 注意目标、表情、重心节奏及衣发、环境响应 |

先记可见现象，再解释效果或提出改编。画面里有窗户、脸上有亮面，不足以证明亮面由该窗照亮；设计新片可以主动指定光源，原片判断仍须保留推测性质。

## 按职责选择资产

以用户当前选择为准，比较原片截帧、已有设定和生成图是否能约束需要的内容：

| 目的 | 候选资产与检查重点 |
| --- | --- |
| 保留原片风格 | 合适截帧或局部参考；检查模糊、遮挡、压缩及特效干扰 |
| 创造人物、服装或场景 | 生成设定图；核对比例、材质与照明是否符合目标 |
| 控制身份与细节 | 完整人物图，必要时补身体、服装或头部近景；确保同一角色 |
| 约束空间或动作 | 少量关键构图；明确适用阶段，检查是否夹带错误姿态 |
| 规定色彩或特效形态 | 简明色卡或效果设定；避免附带无关人物、场景和高潮构图 |

图像“干净”不代表更适合。若设定图的比例、材质和照明偏离目标，先检查真正提供外观依据的图片，而非不断叠加补充图；图像影响仍须通过试片验证，不能直接断言模型内部因果。

人物是否拆成全身、服装、头部或配件图，按所需细节与用户偏好决定，裁切范围服从该图职责。检查身份、发色、衣领、比例和佩戴关系的一致性；多视图代表同一角色。小物只有在需要独立控制时才另建资产。

场景图按用途交代所需尺度、通路或地标，以及主要光源和常态照明。带强爆发、特定姿态的截图用于局部阶段时，留意是否被误用到其他阶段。

## 色彩与效果资产

“颜色接近”不等于“质感接近”，还要看暗部、中间调、亮部占比、局部对比、材质反射、空气透视与运动模糊。

需要色卡时从代表性帧按场景/状态取样，区分环境、主体强调色和短暂高光，注明提取方式与代表范围；生成的近似色卡不能冒充真实像素取样。

特效图应显示目标所需的离散单元或连续形态、尺度、透明度、配色与关键状态。一个视觉母题可有不同阶段，设定图要让这些差别可读，不把同一幅峰值构图当作全部阶段的设定。

完整图片可能同时约束姿态、构图、光色和空间，文字“只参考某项”不是隔离保证。发生干扰时选择更合适的资产，或在相应片段输入中实际排除该图。

## 资产记录

只生成或编辑当前需要的图片，使用适用且已获授权的图像工具，完成后实际查看。区分原片截帧、像素取样与生成/重绘资产，记录来源、用途及适用范围。

文件编号、引用映射、图文位置与版本校验统一按[交付与核对](iteration-and-delivery.md#按需交付与核对)执行。
