# 试片复盘、受控修正与交付

用于新试片、制作输入迭代、锁定内容及最终交付。评价本次生成目标与用户认可的效果，而不是机械追求与参考片一致。

## 核对实际输入与结果

记录试片、提示词版本、实际上传图片及相关模型/设置。先查已有信息，缺失时简短澄清；观察可并行进行，未确认输入注明假设。

分清三个基准：参考片是学习素材，用户确认的制作输入是本次目标，试片是待检验结果。比较同一事件阶段，不只比较同一秒数；保留要求的条件、顺序和程度，出现相同元素不代表关系成立。

| 情况 | 应对 |
| --- | --- |
| 设计本身不成立 | 先改因果、空间或观看逻辑 |
| 文字遗漏或冲突 | 补缺失关系、消除互斥要求 |
| 已写但未实现 | 不再当作缺少描述，检查主事件负担、资产与生成方式 |
| 资产可能干扰 | 对照图片携带的姿态、光影和构图，隔离输入验证 |
| 新增创作要求 | 按新目标设计，别误判为旧要求执行失败 |

按连续帧或播放记录核查过程。已见支持、尚未核实与明确偏差分别说明；“每次”“全程”等要求要有相称的检查范围，稀疏抽帧未发现问题不等于确认不存在。相似构图重现只能证明可见相似性，不能直接证明模型内部机制。把有效段落也纳入保留依据。

## 修正与保护保留项

先确定正在验证的关系，再选择修改动作设计、文字、资产或生成方式。局部消歧，不靠给所有镜头加长文字解决问题。连续失败时缩小试验；若同时改了多个因素，如实说明。

从用户明确反馈提取锁定句段、图片、衔接、节奏与光影。保留指定原文，需要新增条件时放在锁定段外；改后实际与上一版比较。替换锁定依赖有冲突时先说明，不静默扩大范围。图片需精确保持时可核验哈希。

历史版本可回查，当前入口明确指向最新版；不因修正文档自动重做所有资产。下轮验收写可观察结果，而非检查提示词是否出现了某个词。

需要拆段时提供各段完整提示词、图片子集、入镜/出镜状态与拼接方法，实际排除造成干扰的图片。检查姿态、方向、尺度、曝光与声音的衔接；遮挡或运动匹配有助连接，但不保证独立生成的片段自然连续。

## 按需交付与核对

首次反推给完整生成提示词与必要资产方案；修订制作输入时，默认整合成完整最新版，未改段照录。用户明确只要替换段则给该段及替换位置，纯局部咨询直接回答。需要制作包时再生成HTML、TXT、图片或压缩包；交付的完整版本须自足、可直接复制。

- **资产与引用：** 编号和实际文件一一对应，例如 `@图片1` 对应 `图片1.png`，扩展名与格式一致。保留已交付编号；独立子包确需重编号时同步提示词和映射，不引用包外隐含资产。
- **来源与用途：** 记录编号、文件名、来源、用途、适用阶段；截帧注明时间及必要裁切，生成图明确标注。清单可用表格或JSON，字段按需，不强制哈希。
- **图文报告：** 先展示图片、编号与用途，再给可复制的提示词；分析证据和上传资产分区。
- **同版交付：** 尽量从同一份内容生成HTML、TXT和上传包，实际核对文字、编号、锁定项与必要文件。证据截图留在分析目录，上传包只放真正需要的参考资产。
- **时间与衔接：** 展示时间最多一位小数，内部保留原始精度；篇幅符合已知限制，每镜出入状态及新增声音、光影和动作要求确已进入制作文本。

完成前检查图片存在且可读取、引用齐全、各版本一致、保留项未漂移。遵守项目路径与命名约定，公开包不带签名令牌等凭据；HTML源码检查与浏览器视觉验证分别报告。

只有实际生成并取得新试片后，才能评价生成结果；文件校验只证明交付一致。结束时说明改了什么、保留什么、下轮观察什么，未试片的效果保持待验证。
