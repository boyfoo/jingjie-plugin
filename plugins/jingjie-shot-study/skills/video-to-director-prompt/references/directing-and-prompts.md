# 从创作目的到可执行提示词

用于导演方案、分镜设计和制作文本。细节多少服从观看目的、可读性与执行难度。

## 先决定这一段怎样变化

明确主体、关系、处境、变化和用户希望保留的内容。分别考虑人物状态与观众感受：人物可以从容，观众却因画面边缘逼近的威胁而担心。

提炼原片有效机制，再决定借用什么、改造什么、为什么。合理创作假设可用于设计，主线的显著改变需说明目的，避免把局部优化变成另一支影片。

## 分镜设计单元

每镜按复杂度合并成简短描述，不机械填写长表：

| 项目 | 要解决的问题 |
| --- | --- |
| 目的与注意力 | 新信息/感受是什么，先后看哪里 |
| 入镜状态 | 位置、朝向、动作阶段、目标与环境地标 |
| 表演与事件 | 触发、准备、执行、可见结果与退出 |
| 摄影与构图 | 景别、机位、层次、运动路径与动机 |
| 光影与材质 | 光从哪里来，照亮什么，材质怎样响应 |
| 剪辑与声音 | 切点、变速、重音、同步或跨镜延续 |
| 出镜状态 | 与下一镜如何接位置、方向、姿态和时间 |

静镜、停顿与留白也能服务观察和情绪，不必为了增加动态而不断抖动、转圈或甩头。

## 动作写成可见过程

优先写状态转移、因果、路径与结束条件；次级动态由主动作或环境触发，并服从主事件。常见问题可这样消歧：

- 需要位移的行走，写清身体推进与环境相对变化；原地踏步则明确原地节奏。
- 旋转分清角色绕什么轴/中心运动、相机怎样运动以及收势。
- 起跳或飞行说明出力、方向与后续阶段；超现实能力也需符合本片已建立的规则。
- 接触或其他可理解的作用路径带来对象反应；人物动作结束后，余波与远处反应可以继续，不必让人物保持姿态等特效结束。

跨镜保持动作阶段与空间进展，避免无意重复已完成的动作或走过的位置。有意使用动作重叠、重复、回溯或多角度重放时，明确重叠范围、叙事目的和给观众的提示。

## 摄影与剪辑服务观看

先确定需要看动作细节、周围关系还是场面变化，选择能承担该任务的景别。连续机位变化要说明视点怎样过渡，避免把不相容的视野要求放在同一瞬间。

遮挡转场说明前景物怎样经过、遮住什么、切后接什么动作和方向；环绕、甩镜、倾斜与变焦也需有注意力或空间揭示目的。冲击带动相机时，把位移、余晃衰减及稳定后构图连成一次反应。

慢动作写可见的进入、结束和恢复条件。例如只保留展开姿态的短拍，收势后恢复正常速度；时间预算不能代替动作完成点。

## 光影、材质与特效

确定主光、次光或反射光来源及明暗层级；相机转动时光源仍处于世界中的相应位置，主体受光与反射随角度变化。需要暗部可读时给出合理补光关系，而非均匀提亮所有表面。

选取真正相关的材质响应，如布料折痕、金属窄高光或被水纹打散的倒影。空间层次由前后景、遮挡、空气、景深及明暗共同形成，不只靠提高分辨率。

按目标选择说明特效的来源、形态尺度、路径速度、接触作用、环境响应与消散，区分同一母题在不同事件中的状态。

配色服从目标：需要离散多色格片或粒子各保其色时，说明单元配色与分布；连续渐变、混色或流体效果则写清过渡方式，不套用各单元独立保色的规则。

## 声音与提示词组织

分析原片声音以实际试听为据；另作设计时说明是建议。把情绪或剪辑需要的预示声、同步点、收声、余波及环境声恢复写入制作文本；工具不生成声音时单列后期方案。

每镜突出主事件与关键摄影，再补决定结果的光影、特效和次级动态。方向词可与具体表现并用，例如“街舞律动”配重心和肩胯错拍，“犹豫”配停手和视线变化；不靠抽象形容词替代画面关系。

可用以下骨架，交付时填完整并去掉占位项：

```text
生成[必要规格]的[类型与风格]，表现[创作变化]。
[参考图职责与适用范围。]
[跨镜必要的身份、空间、光影与特效规则。]
[声音要求或独立后期方案。]

以下时间为篇幅预算，关键动作完成后进入下一阶段。
【镜头｜约开始–结束｜主要事件】
[入镜状态与触发 → 主要动作及完成点。]
[景别、机位与运动怎样显示事件。]
[必要光影、特效、次级动态与声音。]
[出镜状态及下一镜衔接。]
```

新增内容或镜头时重新分配篇幅；有硬时长限制时在该范围内调整，必要时提供可衔接片段。模型特定写法或参考权重只在已有能力依据时采用。
