# 从创作目的到可执行提示词

用于新导演方案、分镜设计或改写实际制作提示词。镜头形式服从观看目的，细节多少服从可读性与执行难度。

## 明确想让这一段发生什么

用短段落明确主角/主体、关系、当前处境、这段的变化，以及用户希望保留或重做的部分。分别描述人物的状态变化和观众的情绪变化：人物可以从容，观众却因画面边缘接近的威胁而担心；物品展示也可由好奇进入理解，不必添加人物冲突。

从原片提取有效机制，而不是照搬每个动作。例如“外部事件触发动作，比无缘无故换姿态更可信”“先遮住信息再揭示，能形成期待”。明确我们借用什么、改造什么、为什么。用户想要的炫技也要落到信息、感受和节奏上。

先在脑中走完因果与空间，再组织分镜。可以提出合理创作假设，但对用户不曾要求的主线改动应明确说明；不要把小范围优化变成另一支影片。

## 分镜设计单元

每镜记录下列内容，按复杂度合并成简短描述，不要求输出机械的长表：

| 项目 | 决策 |
| --- | --- |
| 目的与观众 | 本镜带来什么新信息/感受，注意力先后落在哪里 |
| 入镜状态 | 人物位置、朝向、动作阶段、相对目标与环境地标 |
| 表演与事件 | 触发、准备、执行、可见结果、动作退出；次级动态服从主线 |
| 摄影与构图 | 景别、相机位置、高度/角度、遮挡层次、运动路径与动机 |
| 光影与材质 | 光从哪里来，照亮什么，哪里保留暗部，材质如何响应 |
| 剪辑与声音 | 切点、速度变化、节奏重音、声音同步或跨镜延续 |
| 出镜状态 | 与下一镜衔接的位置、方向、姿态、动势和时间阶段 |

停顿、静镜和留白同样可以有目的。不要为了“动态多”让一个观察或情绪镜头不断抖动、甩头、转圈。

## 动作描述的关键关系

动作写成可见的状态转移，优先保证因果、路径与结束条件，再补装饰。

- **走路**：脚步与身体整体向何处推进，环境如何相对后移；仅写脚交替落地容易只表达原地踏步。
- **旋转**：谁围绕什么轴/中心转动，想看到哪一段姿态，完成后如何收拢和离开；把角色转圈与相机环绕分别写清。
- **起跳与飞行**：外力或主动发力从何处来、方向与目标是什么；离地后的惯性和下降阶段如何衔接。不要把姿态变化当成瞬间改变飞行路径的动力。
- **接触与受力**：先有接触或可见作用路径，再有对象反应；离得很远的对象不应无缘无故同时被击飞，除非世界规则已建立。
- **动作与余波**：人物完成动作即可进入后续状态，粒子、冲击传播和远处对手反应可以随后结束；避免要求人物保持一个不自然姿态等待全部特效结束。

超现实作品不要求写实物理，但要有可理解的力、方向和连续规则。舞蹈、飞行、魔法、产品变形都采用相同的“发生原因—过程—结果”判断。

相邻镜头分别拥有明确的动作阶段。前镜已经滑入通道，后镜不能无意再从入口重滑。确实采用重复动作、时间回溯或多角度重放时，说明其叙事目的和给观众的提示，不能把意外位置重复解释成剪辑技巧。

## 摄影和剪辑要服务观看

选择景别与运动时，先确定要看见动作细节、周围关系还是场面变化。需要看到包围关系，就留出前中后景和可读的对手数量；近景不能同时承担完整群体调度。

连续镜头的角度可以变化，但要交代相机怎样从一种观看关系到另一种。仰拍人物和看见下方地面可以安排为连续视角变化，不要把互不相容的视野写在同一瞬间。

遮挡切镜头要有真实前景物：它从哪里掠过、遮住多少画面、遮挡前后跟随什么动作、切后保持什么方向与目标。不是单写“多次遮挡、画面倾斜”。环绕、甩镜、短促倾斜和变焦均应有注意力或空间揭示目的。

相机受冲击时写清冲击到达、短促位移/震动、衰减和稳定后的构图。若用冲击解释后退，就不要另写一次无缘由拉远造成两段动作。

慢动作需有可见的进入和退出条件，例如只展示一次空中展开，回收身体后立即恢复下落速度。时间预算不能代替动作结束条件；也不要为每个细小动作安排僵硬的秒级指令。

## 光影与质感不能只靠形容词

确定场景中的主光、次光或反射光来自哪里，何处保留暗部。相机转动时光源仍在世界中的位置，主体受光面和反射随角度改变。需要看清暗部轮廓时，说明可成立的环境反射或侧后光，不把整个人均匀提亮。

选取与画面真正相关的材质响应：皮肤明暗过渡、布料漫反射与折痕、金属窄高光、湿地被粗糙度打散的倒影等。不要要求所有表面都镜面反光或全画面同样锐利。空间层次来自前后景、遮挡、空气、景深及明暗组织，不只来自分辨率。

特效按以下链条设计：**来源 → 单元形态与尺度 → 路径和速度 → 接触/作用 → 对人物环境的反应 → 残留与消散**。发光应对附近表面产生相应照明，亮部仍尽量留有单元颜色和形状。

同一视觉母题用于不同事件时，明确差别：脚下出现、鞋底喷出、脱离后缓慢落下、击中后横向扩散，是不同状态。终段若是站立旋身释放，就不要复用描述落地蜷身、双手压地的文字和姿态图；检查两者是否在视觉上意外重复。

## 声音与节奏

在可用音频范围内分析原片。另作设计时写明是建议：动作前的短暂收声或预示、接触同步音、余波与环境声恢复、用声音提前引入下一空间。音乐节奏可以支持动作，但不要所有脚步都僵硬对拍。

声音承担了情绪或剪辑作用，就把相应要求写入实际制作提示词。目标工具不生成声音时单列后期声音方案，不能暗示该工具已执行。

## 提示词组织

先把导演方案压缩成模型需要的关系，避免把整篇拉片分析粘进去。每镜突出主要事件和关键摄影，再补决定画面质量的光影/特效/次级动态。全局身份不必逐镜重复，局部职责仍应明确。

可采用以下骨架，交付时填完整并去掉占位项：

```text
生成[必要画幅与规格]的[类型与视觉风格]。这一段表现[明确创作变化]。

@图片1：[主体/外观职责与适用范围]。
@图片2：[场景/物品/动作/色彩职责与适用范围]。
[跨镜必要的空间、身份、光影、特效规则。]
[声音要求；如为另行制作则单列。]

下列时间为篇幅预算，关键动作完成后进入下一阶段。

【镜头1｜约0.0–X.X秒｜事件】
[入镜状态与原因 → 主要动作及完成点。]
[景别、机位、构图与相机运动如何显示事件。]
[必要光影、次级运动、特效与声音变化。]
[出镜状态及下一镜衔接。]
```

方向词和具体表现可以并用。例如“有街舞律动的向前行走”再补脚步推进、重心交替和肩胯轻微错拍；“犹豫”再补手停在物品上方、视线转向对方、手指慢慢收回。不要只写“赶快、紧张、刺激”，也不要因反对抽象词而删掉有用的审美方向。

时长增加或新增镜头时重新安排整体篇幅。关键镜头可以有大致范围，提示词不需要写到百分之一秒。用户工具有硬时长限制时在该范围内调整，必要时提供可衔接片段。

不要假定某种写法、参考图权重或时间标记被所有模型支持。只有具体模型能力影响执行时，核对当前官方资料或实际界面；保留已确认设置，注明未核验项。
