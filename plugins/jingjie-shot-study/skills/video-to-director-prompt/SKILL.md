# 视频反推提示词

把“参考视频＋用户意图”转成可直接使用的生成提示词与必要参考资产。反推是有依据的制作方案，不是作者原始输入，也不默认逐帧复刻；没有改编要求时保留原片的核心内容与有效机制，显著改动说明目的。

默认中文交流，沿用已确认的模型、资产策略、审美和交付选择。模型未知时先做通用方案，只在具体能力影响执行时查证或澄清。

## 入口与范围

- 首次反推：观察视频，完成制作方案、完整提示词及必要参考图选择。
- 已有反推任务的新试片：复用实际输入、素材和保留项，只修正需要变化的部分。
- 局部咨询或修改：只处理当前范围，保留其余成功内容；具体交付见下文，不自动重做资产或文件包。输入版本不清时先查已有文件和对话，未核实的部分注明假设。

只解释已有视频怎么表达，使用 [video-shot-study](../video-shot-study/SKILL.md)；只核对既有文字与画面的关系，使用 [video-prompt-alignment](../video-prompt-alignment/SKILL.md)。需要产出或修正制作输入时才进入本技能。反推可独立执行，无需先交拉片报告、取得作者原文或提交镜界；已有观察可直接复用。

## 核心创作流程

1. **建立可信观察。** 核实实际视频与必要媒体信息，能播放时先完整观看待分析范围，再核对关键过程；无法播放时实际查看覆盖该范围及重点密集帧，说明观察方式。未听音不评价原片声音；区分原片可见事实、分析判断和主动设计。
2. **确定创作变化。** 明确主体、关系、起止状态和观众注意的变化，结合用户目的取舍原片机制。每镜优先决定主要事件、因果、可见结果与结束条件，再安排摄影、光影、声音及跨镜衔接。
3. **配置必要资产。** 按用户选择复用截图、已有设定或新设计；每张图有明确职责和适用阶段。身份、服装、面部或细节是否拆图，取决于控制需要与用户偏好。
4. **写完整制作输入。** 将方案压缩成“创作目标与风格 → 参考图职责 → 必要全局规则 → 分镜”。写清主体与相机各自怎样变化，保留主导关系；声音设计也进入实际制作文本。用户拿到提示词即可使用，无需自行拼接散落的修正。
5. **根据试片修正。** 对照实际输入定位设计、文字、资产或执行问题，保护用户指定的成功内容。连续失败时提出可区分原因的小范围试验；需要拆段就交付各段完整输入与衔接方案。

按当前需要展开细则：

- 需要核验视频、判断画面或选择/制作参考资产：读[观察与资产](references/observation-and-assets.md)。
- 需要设计分镜、动作、摄影、光影或组织提示词：读[导演与提示词](references/directing-and-prompts.md)。
- 收到新试片、需保护锁定内容或制作HTML/TXT/图片包：读[复盘与交付](references/iteration-and-delivery.md)。

## 交付边界

主交付是当前范围内完整可用的生成提示词与必要资产方案，分析只保留帮助使用这些输入的部分。编号、文件、版本及图文包的细则统一见[交付与核对](references/iteration-and-delivery.md#按需交付与核对)。

沿用已有授权范围；外部提交、发布或代为试片须有相应授权。说明实际完成的观察与验证，文件一致不等于生成效果已验证，未取得新试片时不声称问题已解决。
