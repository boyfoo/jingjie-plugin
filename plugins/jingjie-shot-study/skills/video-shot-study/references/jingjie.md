# 镜界 MCP 分模块保存与修改

完整拉片按 [SKILL.md](../SKILL.md#任务范围) 保存本次案例，已有案例和有效素材直接复用。局部任务按用户指定范围处理。语言和翻译见 [languages.md](languages.md)。

## 1. 先看镜界怎么保存、有哪些分类

先读 `jingjie://submission-guide` 和本次工具的参数说明。字段、限制和保存方法以当前工具说明为准。保存深入分析时，看指南中的增强分析章节。

第一次分析前，调用 `jingjie_get_taxonomy` 读取当前分类和使用说明。分类要有实际画面支持；界面显示名称与保存值可能不同。

找不到工具或资源时，先检查当前有哪些工具和资源；仍找不到就说明缺少什么，不编造字段或标识。保留已有资料，继续不受影响且已获授权的工作，并说明尚未完成的部分。

## 2. 默认执行顺序

1. 开工时读取指南、分类和相关工具字段。按[拉片前置条件](../SKILL.md#前置条件先取得提示词)核实完整提示词，确认[源版语言](languages.md)，再进行画面分析。分析时留下可直接保存的记录，避免提交时重新整理。
2. 新案例按指南创建，已有案例先读取当前资料并复用；不为补资料或翻译重复创建。
3. 在授权范围内上传素材，确认成功后再使用返回地址。带时间的提示词和镜头，以已核实并保存的真实视频时长为准。
4. 保存本次涉及的提示词、镜头与分析、案例说明、分类和标签。生成模型有明确来源时填入案例的 `model` 字段，未知就不填。某项内容需要用到另一项时，先保存它需要的那一项，具体顺序按当前工具要求安排。
5. 完整拉片按[第8节](#8-深入分析的时间对应与回读)一并保存深入分析，无需另行确认；沿用同一案例、已核实原文和真实证据。局部任务只处理选定范围，不编造要求凑齐模块。
6. 保存后，把对应正文读回来核对。先完成本次源版内容，包括完整拉片中的深入分析，再处理用户选择的译文。

其他资料缺少时，如实保留空缺并说明。已有案例只改本次涉及的部分，不必最后再覆盖整案。

## 3. 保存规则、版本与工作记录

修改前调用 `jingjie_get_draft`，读取相关内容，确认当前状态和本次要改的范围。按工具规定合并或替换内容，保留本次不修改的资料，以及仍有效的对象 ID 和引用，不用占位值清空已有资料。

**每次保存使用最新返回的 `revision`，保存后回读再继续。** 版本、请求标识及其他参数以当前工具说明为准。发生版本冲突时，先回读并合并当前内容，再按工具说明重试，不直接重发旧数据。

保留案例入口、相关正文、对象 ID 和保存结果，方便中断后接着处理同一案例。

原帖链接、来源核实记录，以及看不清或无法判断的地方，放在指南指定的来源字段或本地记录中，不追加到作者原文里。只写来源说明，也不等于已保存提示词、图片或分析正文。

## 4. 素材上传与恢复

先核实文件、格式、时长和本次上传范围，按指南上传。确认成功后才使用返回的素材地址；不上传无关文件，也不把临时上传地址当作永久素材地址。

完整拉片将[来源随附参考图](../SKILL.md#41-来源随附参考图)保存到同一案例，保留来源顺序和已取得的全部相关图片。补图前先读取已有资料，只补传缺图；保存后逐张读回，确认图片地址正确。用户明确要求只留本地资料时，随素材保留。

上传中断或结果不明时，用指南指定的状态工具核对，再按返回结果恢复，避免重复建案或上传。替换视频前，核对视频版本、时长，以及哪些时间记录需要修改，不自动缩放、裁切或伪造原有时间。

## 5. 提示词整组保存

原文核实方式及前文、时间段、后文的含义，见 [SKILL.md 第4节](../SKILL.md#4-核对提示词及其时间段)。保留完整原文和已有分段，按当前工具要求整组保存；局部修改时也要保留其他已存内容。

分段位置不清时，保留全文并说明疑问。不要漏掉没有时间标记的文字、末尾约束或相关空白，也不要混入页面按钮、助手分析或根据画面补写的内容。提示词时间与视频不一致时，先核对素材版本，再在授权范围内按主文的时间规则处理。

保存后读回全文和时间，不能只凭字数、行数或“保存成功”判断有没有漏内容。

### 5.1 用户选择后的多语言翻译保存

每种目标语言都保存完整案例的译文。各部分分开写入，全部镜头、提示词和深入分析等可译内容都核对完成后，再交付该语言的整案译文。保存和引用定位见 [languages.md](languages.md)。

## 6. 镜头与分类

人物的外观、动作和表演写在对应镜头里。深入分析需要区分或关联人物时，可把人物记为主体。

- 先看内容属于哪个分类分组，再选具体分类；不要未经逐镜核对就套用整片分类，也不要重复保存另一套相同的分类信息。
- 选项不够准确时，把画面里看到的内容写清楚，并说明现有选项哪里不合适，不为了凑选项删掉细节或选取仅字面相似的类别。
- 作者提供的台词原文照存；声音按[主文第3节](../SKILL.md#3-逐镜分析)记为无法判断。未知的台词、模型或来源提示词不猜测，不生成替代尾帧，也不把整片原文复制成每镜提示词。
- 复用已有镜头，只关联本案例中已记录的镜头或分析主体。删除、重排或维护全局分类，也须在本次授权范围内。

### 6.1 选择标签

1. **从成片里找值得学习和搜索的特征。** 挑选时看提示词中的要求实际做到了哪些，也看成片还有哪些值得学习的手法。例如，提示词没写转场，成片里有一次精彩的遮挡转场，就可以选“遮挡转场”，记下对应片段。区分作者原文和画面观察，标签要有实际画面支持。提示词中未实现的要求、避免事项和助手建议留在分析说明里。
2. **已有合适的标签就直接用。** 先查全局分类库，核对同义或近似标签，包括其他语言的名称，以及范围更大或更小的标签。已有标签足以表达时，不因措辞更细就重复新增；读取失败也不代表分类缺项。
3. **没有合适标签时，让用户选择。** 展示对应片段、找到的近似标签，以及建议的新标签名和所属分组，让用户选择用已有标签、新增标签或放弃。名称简短，不凑数量；范围大小不同的标签，只有各自值得单独搜索时才一起保留。局部动作、配件和光色等细节，通常留在逐镜分析或对应的时间段中，不加标签也要保留分析。
4. **确认新增后，先加入全局库。** 按当前 MCP 说明把用户确认的标签加入全局分类库，再关联本案例并保存对应时间段。新增标签不写入案例自由 `tags`；保存失败时如实说明，不用其他字段冒充。
5. **保留本次不修改的标签和时间。** 已有案例自由 `tags` 原样保留，不迁移或清除。只改提示词且没有归类授权时，不顺带改分类。

补充标签显示名的翻译按 [languages.md](languages.md) 执行，翻译本身不新增、删除或重新归类标签。

### 6.2 标签对应的视频时间段

**分析出标签时，一起记下对应的视频时间段。提交镜界时，把标签和时间一起保存，再读回来确认都存对了。具体字段和保存顺序按当前MCP说明操作。**

记录标签名称或已有标识、起止秒数，必要时简短说明为什么选这个标签。需要时补看相关片段。

- 可复用镜头或逐项分析中已核实的证据，时间以真实视频为准，不照抄作者安排，也不直接套用整个镜头的时间。
- 同一标签不连续出现时，分成多个区间，不把中间空档算进去。合并同义标签时，一并保留各处有效区间。
- 确实适用全片的标签标为“全片”。标签已确认但时间尚未定位时，写明“未定位”及原因，不能用零秒或全片范围代填；只能估出大致起止时间时如实注明。
- 时间段要记清对应的是哪版视频。翻译只改显示文字，共用原有时间；更换或剪裁视频后，核对受影响的区间，不自动缩放或平移。

## 7. 回读、失败与完成条件

写入前，核对内容是否有画面或其他可靠依据；写入后，回读相应正文，确认文字、素材、时间、分类和关联保存正确，没有意外丢失或清空。最后的摘要不能代替正文核对。

保存失败、发生冲突或结果不明时，先读取当前内容，再按 MCP 返回结果处理。按报错位置修正字段。报错本身不改变画面判断；缺少真实区间就不猜时间，也不为了保存成功改判。仍无法完成时保留记录，继续不受影响且已获授权的工作，并说明未完成的部分。

交付时说明实际保存了什么、当前状态、案例链接和未完成部分。保存只更新编辑稿，不能称为已更新公开版本。

## 8. 深入分析的时间对应与回读

保存深入分析前，按第1节读取增强分析说明和工具参数，再调用 `jingjie_get_draft` 读取已有 `prompt_alignment`，以及它引用的原文和证据。复用同一案例和有效分析，整份保存用 `replace`，局部修改用 `patch`；具体字段按当前工具说明填写。

判断方法见[证据与判定](judgment-and-coverage.md#3-证据先于判断)。每项要求须有真实原文出处，作者安排的时间与视频实际发生的时间分开记录。声音项不编造观察或证据时间。

保存前按[完成前检查](judgment-and-coverage.md#7-完成前检查)对照原文逐句检查，尤其留意还没引用到的新主体和限定。是否漏掉要求，要根据完整原文判断；MCP 校验通过、保存成功，都不能证明没有遗漏。发现缺项时，在授权范围内补全，或如实说明未完成的内容。

保存前和回读后，都要按[引用范围规则](judgment-and-coverage.md#11-上下文与标注引用分别处理)核对每项的实际引用，不能只检查 `quote` 和记录的文字位置是否对得上。不同要求都引用同一整段时，检查每项是不是多选了本项不需要的文字。**字段齐全、状态是 `current`、接口返回成功，也不能说明每项引文选得合适。**

**调整引用时，优先复用经核对仍有效的分析，避免无关改动。** 只是引用的位置变了、要求含义没变时，原判断、证据时间和关联通常可以沿用。发现要求含义有变、证据连错或其他影响判断的问题时，可在任务范围内补查、重新拆分或修正分析，并说明依据。

需要修正源版时，先保存并回读源版，再取得最新翻译上下文，重新定位已授权目标语言的引用。按当前工具要求提交完整译文并使用最新版本。读回后确认改动有依据、未受影响的有效内容仍在，判断、时间和资料没有被误改或漏掉。

说明哪些画面支持本项要求、哪里不符合、哪些还没法确定，不为通过接口而改变要求或结论。保存与回读时，确认原文、判断和实际观察对应正确。已经看到了变化过程，但还没确定实际起止时间时，说明时间尚未定位；静态要求或无法确认动态事件时，说明实际查看的范围，不编造区间。
