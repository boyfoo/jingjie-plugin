# 镜界 MCP 分模块保存与修改

只执行本次已获授权的创建、上传或修改，复用同一案例和未变的素材。MCP 只保存编辑稿，发布由用户在网站操作。授权范围见 [SKILL.md](../SKILL.md#工作边界)，语言和翻译见 [languages.md](languages.md)。

## 1. 先看镜界怎么保存、有哪些分类

先读 `jingjie://submission-guide` 和本次工具的参数说明。字段、限制、保存和恢复方式以当前工具说明为准；深入对应还须阅读指南中的增强分析章节，不沿用记忆中的旧接口。

保存或归类前，调用 `jingjie_get_taxonomy` 读取当前分类和使用说明。先根据实际画面得出判断，再选择有依据的分类；不能根据工具参数猜分类，也不能把界面显示名称直接当作要保存的值。

找不到工具或资源时，先检查当前可用入口；仍不可用就说明缺少什么，不编造字段或标识。保留已有资料，继续不受影响且已获授权的工作，并说明尚未完成的部分。

## 2. 默认执行顺序

1. 按[拉片前置条件](../SKILL.md#前置条件先取得提示词)核实完整提示词，再读取当前指南和分类，按[语言流程](languages.md)确认源版语言，复用有效观察。
2. 新案例按指南创建，已有案例先读取当前资料并复用；不为补资料或翻译重复创建。
3. 在授权范围内上传素材，确认成功后再使用返回地址。带时间的提示词和镜头，以已核实并保存的真实视频时长为准。
4. 保存本次涉及的提示词、镜头与分析、案例说明、分类和标签。有依赖的内容先保存，具体顺序按当前工具要求安排。
5. 完整拉片按[第8节](#8-深入分析的时间对应与回读)一并保存深入对应，无需另行确认；沿用同一案例、已核实原文和真实证据。局部任务只处理选定范围，不编造要求凑齐模块。
6. 保存后回读对应正文。完成本次源版工作，包括完整拉片中的深入对应，再处理用户选择的译文。

其他资料缺少时，如实保留空缺并说明。已有案例只改本次涉及的部分，不必最后再覆盖整案。

## 3. 保存契约、版本与工作记录

修改前调用 `jingjie_get_draft`，读取相关内容，确认当前状态和本次要改的范围。按工具的合并或替换规则保留其他内容，以及仍有效的对象 ID 和引用，不用占位值清空已有资料。

**每次保存使用最新返回的 `revision`，保存后回读再继续。** 版本、请求标识及其他参数以当前工具说明为准。发生版本冲突时，先回读并合并当前内容，再按工具说明重试，不直接重发旧数据。

保留案例入口、相关正文、对象 ID 和保存结果，方便中断后接着处理同一案例。

原帖链接、来源核实记录和观察限制，放在指南指定的来源字段或本地记录中，不追加到作者原文里。只写来源说明，也不等于已保存提示词、图片或分析正文。

## 4. 素材上传与恢复

先核实文件、格式、时长和本次上传范围，按指南上传。确认成功后才使用返回的素材地址；不上传无关文件，也不把临时上传地址当作永久素材地址。

已获本案例保存授权时，按当前指南一并保存[来源随附参考图](../SKILL.md#41-来源随附参考图)，保留来源顺序和已取得的全部相关图片。补图前先读取已有资料，保留原有有效项，复用已上传素材，只补传缺失图片。保存后逐张核对图片与回读地址；仅放在本地或私有来源记录中，不能称为已保存到镜界。没有远端保存授权时，只在本地保留。

字段、数量限制和上传接口，以当前 MCP 指南和工具参数为准。

上传中断或结果不明时，用指南指定的状态工具核对，再按返回结果恢复，避免重复建案或上传。替换视频前，重新核实版本、时长和受影响的时间记录，不自动缩放、裁切或伪造原有时间。

## 5. 提示词整组保存

原文核实方式及前文、时间段、后文的含义，见 [SKILL.md 第4节](../SKILL.md#4-核对提示词及其时间段)。保留完整原文和已有分段，按当前工具要求整组保存；局部修改时也要保留其他已存内容。

分界不清时，保留全文并说明疑问。不要漏掉没有时间标记的文字、末尾约束或相关空白，也不要混入页面按钮、助手分析或根据画面补写的内容。提示词时间与视频不一致时，先核对素材版本，再在授权范围内处理播放定位。

保存后回读完整文本和时间，不能只凭字数、行数或成功回执确认内容无缺。网页检查见[第8节](#8-深入分析的时间对应与回读)。

### 5.1 用户选择后的多语言翻译保存

译文保存和引用定位统一按 [languages.md](languages.md) 执行。

## 6. 镜头与分类

人物的外观、动作和表演写在对应镜头里。深入分析需要区分或关联人物时，可把人物记为主体。

- 先判断内容属于哪个维度，再选分类；不要未经逐镜核对就套用整片分类，也不要重复保存另一套相同的分类信息。
- 选项不够准确时，保留有依据的具体分析并说明限制，不为了适配选项删掉细节或选取仅字面相似的类别。
- 作者提供的台词原文照存；声音按[主文第3节](../SKILL.md#3-逐镜分析)记为无法判断。未知的台词、模型或来源提示词不猜测，不生成替代尾帧，也不把整片原文复制成每镜提示词。
- 复用已有镜头，只关联本案例中已记录的镜头或分析主体。删除、重排或维护全局分类，也须在本次授权范围内。

### 6.1 选择补充标签

1. **从成片里找值得学习和搜索的特征。** 挑选时看提示词中的要求实际做到了哪些，也看成片还有哪些值得学习的手法。例如，提示词没写转场，成片里有一次精彩的遮挡转场，就可以选“遮挡转场”，记下对应片段。区分作者原文和画面观察，标签要有实际画面支持。提示词中未实现的要求、避免事项和助手建议留在分析说明里。
2. **先查已有分类。** 核对同义、近义、不同语言及上下位概念。已有分类足以表达时，不因措辞更细就重复加标签；读取失败也不代表分类缺项。
3. **合并同义内容。** 使用简短一致的名称；上下位概念只有各自值得单独检索时才并列。局部动作、配件和光色等细节，通常留在逐镜分析或时间对应中，不加标签也要保留分析。
4. **按价值取舍。** 可以不加补充标签，不凑数量。保存限制以当前指南为准；重要标签无法保存时如实说明，不用其他字段冒充。
5. **保留无关旧项。** 新增前先去重，只有已授权重整时才清理重复或过细的旧标签。只改提示词且没有归类授权时，不顺带改分类。

补充标签显示名的翻译按 [languages.md](languages.md) 执行，翻译本身不新增、删除或重新归类标签。

### 6.2 标签对应的视频时间段

**分析出标签时，一起记下对应的视频时间段。提交镜界时，把标签和时间一起保存，再读回来确认都存对了。具体字段和保存顺序按当前MCP说明操作。**

记录标签名称或已有标识、起止秒数，以及必要的简短依据。需要时补看相关片段。

- 可复用镜头或逐项分析中已核实的证据，时间以真实视频为准，不照抄作者安排，也不直接套用整个镜头的时间。
- 同一标签不连续出现时，分成多个区间，不把中间空档算进去。合并同义标签时，一并保留各处有效区间。
- 确实适用全片的标签标为“全片”。标签已确认但时间尚未定位时，写明“未定位”及原因，不能用零秒或全片范围代填；边界只能近似时如实注明。
- 时间段随视频版本记录。翻译只改显示文字，共用原有时间；更换或剪裁视频后，核对受影响的区间，不自动缩放或平移。

## 7. 回读、失败与完成条件

写入前，核对内容是否有画面或其他可靠依据；写入后，回读相应正文，确认文字、素材、时间、分类和关联保存正确，没有意外丢失或清空。最后的摘要不能代替正文核对。

保存失败、发生冲突或结果不明时，先读取当前内容，再按 MCP 返回结果处理。按报错位置修正字段。报错本身不改变画面判断；缺少真实区间就不猜时间，也不为了保存成功改判。仍无法完成时保留记录，继续不受影响且已获授权的工作，并说明未完成的部分。

交付时说明实际保存了什么、当前状态、案例入口和未完成部分。保存只更新编辑稿，不能称为已更新公开版本。网页检查见[第8节](#8-深入分析的时间对应与回读)。

## 8. 深入分析的时间对应与回读

保存深入对应前，按第1节读取增强分析说明和工具参数，再调用 `jingjie_get_draft` 取得已有 `prompt_alignment` 及其依据。复用同一案例和有效分析，只补本次需要的内容。

判断方法见[证据与判定](judgment-and-coverage.md#3-证据先于判断)。每项要求须有真实原文出处，作者安排的时间与视频实际发生的时间分开记录。用动态过程支持判断时，引用实际发生的区间，不用单帧、整镜边界或作者预期时间代替；不连续出现就分段记录。声音项不编造观察或证据时间。

保存前按[完成前检查](judgment-and-coverage.md#7-完成前检查)逐句反查，尤其留意未引用的新主体和限定。是否漏掉要求，要由分析者根据完整原文判断；MCP 校验和保存回执不能证明没有遗漏。发现缺项时，在授权范围内补全，或如实说明未完成的内容。

保存前和回读后，都要按[引用范围规则](judgment-and-coverage.md#11-上下文与标注引用分别处理)核对每项的实际引用，不能只检查 `quote` 是否能从偏移处取回。不同要求都引用同一整段时，检查是否把上下文直接当成了每项标注。**字段齐全、`current` 和接口成功，都不能证明引用范围合适。**

**调整引用时，优先复用经核对仍有效的分析，避免无关改动。** 只是定位变化、要求含义未变时，原判断、证据时间和关联通常可以沿用。发现要求含义有变、证据错连或其他实质问题时，可在任务范围内补证、重新拆分或修正分析，并说明依据。

需要修正源版时，先保存并回读源版，再取得最新翻译上下文，重新定位已授权目标语言的引用。按当前契约提交完整译文并使用最新版本。回读后确认改动有依据，保留未受影响的有效内容，排除意外改判、时间变化或资料丢失。

说明已有支持、真实反例和仍待核实的部分，不为通过接口而改变要求或结论。保存与回读时，确认原文、判断和实际观察对应正确。已有动态过程证据却缺少可播放定位时，说明时间对应尚未完成；静态要求或没有可核实动态事件时，如实说明范围，不编造区间。

界面可用且用户未排除网页检查时，抽查有代表性的区间和文字高亮，留意新主体、限定，以及相邻但判断不同的片段。界面抽查不能代替逐项语义和引用范围核对。用户不需要网页抽查时，仍通过数据核对每项要求、引用和保存结果，并说明未验证界面效果。翻译已有分析按 [languages.md](languages.md) 执行；通常复用有效分析，确需补查或修正时再针对问题处理。
