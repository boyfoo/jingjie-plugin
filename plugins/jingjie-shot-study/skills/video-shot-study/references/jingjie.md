# 镜界 MCP 分模块保存与修改

只执行本次已授权的创建、上传或修改；复用同一案例和未变素材。MCP 保存编辑稿，发布由用户在网站操作。授权边界见 [SKILL.md](../SKILL.md#工作边界)，语言选择与翻译统一见 [languages.md](languages.md)。

## 1. 发现当前契约，读取分类体系

先读取 jingjie://submission-guide，并查看本次使用工具自带的输入结构。字段、限制、保存与恢复规则由 MCP 唯一维护；深入对应使用同一资源中的增强分析章节，不沿用记忆中的旧接口。

保存或归类前调用 jingjie_get_taxonomy，读取当前分类及使用说明。先独立形成画面判断，再选择有依据的合法分类；不从工具参数猜分类，不把显示名称当作存储规则。

工具或资源缺失时先检查当前可用入口；仍不可用就报告具体缺口，不造字段或标识。保留已有资料，继续其他独立且已授权的工作，不把未完成归类称为完整交付。

## 2. 默认执行顺序

1. 读取当前指南与分类，按[语言流程](languages.md)确认源版语言；已有观察直接复用。
2. 新案例按指南创建，已有案例先读取当前资料并复用；不为补资料或翻译重复创建。
3. 在授权范围内上传素材并确认成功。带时间的提示词和镜头应基于已核实且已保存的真实视频时长。
4. 完成本次涉及的提示词、镜头及其逐镜分析、案例说明、人物、分类与标签，依赖内容先保存；不自动补做未授权模块。
5. 按当前工具要求顺序保存并回读目标正文，确认本次源版工作完成后，才进入可选翻译。

缺少资料时保留空缺并说明，不能虚构内容凑齐模块。已有案例只处理本次范围，无需最后再整案覆盖。

## 3. 保存契约、版本与工作记录

修改前先通过 jingjie_get_draft 读取相关内容，核对当前状态和本次范围。按工具说明保留未修改内容及稳定引用，不用占位值清空已有资料。

保存后回读再继续，版本、替换范围、请求标识和重试方法均遵循当前 MCP 返回。保留案例入口、目标内容、对象标识和保存结果，以便中断后接续同一案例。

原帖、来源依据和观察限制放在指南指定的来源位置或本地记录，不追加进作者原文；来源说明不能替代正式保存的内容。

## 4. 素材上传与恢复

先核实实际文件、格式、时长及本次上传范围。按指南完成上传，确认成功后才引用返回的素材地址；不上传无关文件，不把临时上传地址当作永久素材地址。

已获本案例保存授权时，将[来源随附参考图](../SKILL.md#41-来源随附参考图)一并保存到当前 MCP 契约指定的参考图资料中，保留来源顺序。首次保存覆盖已取得的全部相关附图，不能只取第一张；补图前先读取已有资料并合并，保留未修改项，复用已上传素材，只补传缺失图片。保存后逐张核对图片与回读地址的对应，不能仅放在私有来源记录或本地目录便声称已保存到镜界。没有远端保存授权时仅在本地保留。字段、数量限制和上传接口均以当前 MCP 指南及工具输入结构为准，不在技能中另列一套规则。

中断或结果不明时先用指南指定的状态读取工具核对，按当前返回恢复，不重复创建案例或上传已完成素材。替换视频前重新核验版本、时长和受影响时间，不自动缩放、裁切或伪造原有记录。

## 5. 提示词整组保存

原文核验和前文、时间段、后文的含义见 [SKILL.md 第4节](../SKILL.md#4-核对提示词及其时间段)。完整原文与已有分段资料一并保留，按当前保存工具要求提交；修改局部时不能丢掉其他已存内容。

分界不清时保留全文并说明限制，不吞掉无时间文字、末尾约束或相关空白，不混入页面按钮、助手分析或未经核实的复现提示词。时间不一致时先核对素材版本，仅在授权范围内处理播放对应。

保存后回读核对完整文本与真实时间；只比较字数、行数或成功回执不足以确认内容完整。页面播放、跟随与高亮效果另行实测并如实报告。

### 5.1 用户选择后的多语言翻译保存

统一执行 [languages.md](languages.md)：源版完成并回读后才询问目标语言，用户选择后通过 jingjie_get_translation_context 取得完整上下文，再按当前契约保存并回读。深入分析的全文语义翻译与对应见[第4.1节](languages.md#41-深入分析译文的完整对应)。

## 6. 镜头、人物与分类字段

区分可见概述、逐镜分析、固定分类、人物资料和来源引文，按当前指南与分类返回选择保存位置。字段合法不等于语义正确，固定选项也不能代替完整逐镜分析。

- 先判断所属维度，再选择有依据的分类；不能将整片分类直接继承给每个镜头，也不重复建立第二套画面信息。
- 不因选项限制删掉有依据的细节。库中没有准确项时说明限制，保留具体分析；相似措辞不能代替语义相符。
- 人物台词与助手声音分析分开；未知台词、模型和来源提示词不推测，不生成替代尾帧，也不将整片原文复制成每镜提示词。
- 复用已有镜头与人物，关联真实存在的对象；删除、重排和全局分类维护须在本次授权范围内，不借修正字段扩大修改。

### 6.1 提示词概念缺项时补充标签

1. **先筛核心，再查缺项。** 从已核实原文提取有检索价值、能代表案例辨识特征的候选，保留来源与适用范围。主导表达、反复出现或短暂但关键的创意都可考虑；助手建议、负向排除项和成片未实现的文字要求不当作已有特征。
2. **已有分类覆盖就不再补。** 读取相关分类，核对同义、近义、中外文和上下位关系。已有项足以表达检索含义时不因措辞更细重复添加；读取失败不等于分类缺项。
3. **合并相近，细节归位。** 同义内容归并为简短一致的名称；上下位概念仅在各有独立检索意义时并列。局部动作、配件和光色等细节通常留在人物、镜头分析或时间对应中；未入标签不等于删去分析。
4. **少而有用，不凑数量。** 允许没有补充标签，按核心辨识与检索价值取舍。保存限制以当前指南为准；重要内容无法保存时说明，不以其他位置冒充标签已保存。
5. **修改保留范围。** 新增标签先与现有内容去重，保留无关旧项；只有已授权重整时才清理重复或过细项。仅改提示词且未授权归类时不改分类。

## 7. 回读、失败与完成条件

写入前核对内容与画面依据，写入后回读目标正文，确认文字、素材、时间、分类和关联符合预期，且没有非预期丢失或清空。最终摘要不能替代各部分正文核对。

失败、冲突或结果不明时先读取当前内容，按 MCP 返回修正；不盲目重发旧内容，不通过删掉要求或编造数据换取成功。仍无法完成时保留记录，继续独立且已授权的工作，并明确未完成范围。

结尾报告实际保存内容、当前状态及入口，说明来源或验证缺口。保存仅影响编辑稿，不能声称已更新公开版本；界面可用时按范围实测，未实测须明确说明。

## 8. 增强分析的时间对应与回读

取得相应授权后，先读取 jingjie://submission-guide 中的增强分析章节、保存工具自带结构，并通过 jingjie_get_draft 获取已有 `prompt_alignment` 与依据。复用同一案例和既有有效成果，仅补本次范围。

判断方法见[证据与判定](../../video-prompt-alignment/references/judgment-and-coverage.md#3-证据先于判断)。原文要求必须有真实出处；作者预期时间与实际观察时间分开。动态支持应对应真实发生区间，不用孤立帧、整镜边界或预期时间代替；不连续出现时分段记录，未试听不填声音结论。

分别说明已见支持、未核部分和真实反例，不能为通过接口改变要求或结论。保存与回读时核对原文、判断、实际观察及其对应；有动态支持但缺少可播放定位时，不能称为时间对应已完成。静态要求或无可核实动态事件时说明实际范围，不凑区间。

界面可用时抽查代表区间与文字高亮，分别报告数据核对和界面验证结果。翻译已有分析统一按 [languages.md](languages.md) 执行，不重做视频分析或改变已有时间、证据和判定。
