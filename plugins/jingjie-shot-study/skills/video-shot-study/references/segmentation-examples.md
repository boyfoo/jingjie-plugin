# 拆分与查漏示例

这些示例说明如何[拆分要求并作出判断](judgment-and-coverage.md)。例子里的画面是假设的，分析真实视频时要自己查看。下面的“核对内容”是对要求的解释，不是原文；引用原文时要照原字句选取，需要时可以共用文字或选几个片段。不规定唯一拆法或固定条数；能分别判断是否做到的，就分开检查，并说清在看谁、哪段画面、什么关系。

## 1. 同一个人的不同要求也要分开检查

原文：“女孩穿红色风衣，戴黑色手套，站在雪地里。”

- 先弄清后面的衣物和动作都属于这个女孩，再分别看她是否穿风衣、风衣是否为红色、是否戴手套、手套是否为黑色、是否站立、是否身处雪地。不必在每项中重复列出“女孩存在”。
- 若清晰画面中女孩穿红风衣、戴白手套、站在雪地里：手套颜色失配，其余有证据支持的要求分别匹配。
- 引用原文时照原样保留，解释时可以说明风衣、手套属于谁。不能只留下不知在说什么的“红色”“黑色”。一项没做到，不代表其他项也没做到。

### 同一段拆项后，引用也要分别定位

上例英文文本：“The girl wears a red trench coat and black gloves, standing in the snow.”

**中文译成英文、英文译成中文，都可以照这个例子检查引用**。这里只演示部分要求该引用哪些文字，其他要求仍按上文检查；分析说明中要能看出衣物属于谁。

| 核对内容 | 英文实际片段 | 中文实际片段 |
|---|---|---|
| 穿风衣 | `wears`、`trench coat` | `穿`、`风衣` |
| 风衣为红色 | `red trench coat` | `红色风衣` |
| 手套为黑色 | `black gloves` | `黑色手套` |
| 身处雪地 | `in the snow` | `雪地里` |

如果这些项全部引用同一整句，即使判断各自独立、位置也正确，实际引用仍没拆开。两版语序不同，可以分别选取多个真实片段，不要求片段数量或排列方式相同。例如，“No blood or organs.”对应“不要出现血液或器官”时，器官禁令在英文中引用 `No` 与 `organs`，在中文中引用 `不要出现` 与 `器官`。两种方向都要保留否定，但无需把“血液”也算进器官这一项。

“摄影机全程保持固定”作为一项检查时，可以整句引用；不能为了缩短文字丢掉“全程”。几项需要同一段文字时可以重复引用，重点是选得准确。

## 2. 部件与整体关系分别判断

原文：“黄黑机械装甲、带角头盔、层叠甲片和外露的黑色机械结构，共同形成武士轮廓。”

装甲有没有黄色、有没有黑色，分开判断；实际为黄白配色时，黄色匹配、黑色失配，不额外要求颜色占多少、出现在哪里。

各部件和属性分别核对后，整体是否形成武士轮廓、是否由这些部件共同形成，也要按实际证据判断。不能因为某个部件匹配就自动通过，也不能拆完部件后漏掉后半句。

## 3. 动作、结果和原因分开判断

原文：“武士从掌心发出金色能量波，击中怪物胸口，将它向后击飞。”

- 分别看谁发出了能量波、是否发出、从哪里发出、是什么颜色，是否击中怪物及命中哪里，怪物是否被击飞、飞向哪里，以及击飞是否由这次攻击造成。
- 假设画面清楚显示武士从口中发出红色能量波并击中怪物腹部：

| 核对内容 | 判断 |
| --- | --- |
| 发出了能量波 | 匹配 |
| 发出者为武士 | 匹配 |
| 发出位置为掌心 | 失配，实际为口中 |
| 能量波为金色 | 失配，实际为红色 |
| 能量波击中怪物 | 匹配 |
| 命中位置为胸口 | 失配，实际为腹部 |

- 如果怪物被这次攻击击飞，但飞向侧面，“击飞”和“由这次攻击造成”分别匹配，“向后”失配。如果原片在命中后就切走，后面也没出现这次击飞，“击飞”和“向后”都判失配。不能猜镜头外已经发生。
- 要确认是这次攻击把这个怪物击飞，不能拿另一处、另一次攻击造成的结果来代替。

## 4. 新出现的人物和物件也要检查

原文：“一道电弧清晰可见地击中巨型LED广告牌，将其面板向外炸飞。”

新出现的广告牌、面板，以及面板属于哪个广告牌，都要检查，不能只顾动作而漏掉它们。广告牌是不是 LED、看起来是不是巨大，要分开判断；“巨型”按前后文和画面里的大小理解，不自定米数。“击中广告牌”和“命中过程清晰可见”也分开检查，不能看出击中了，就默认过程也看得清。

## 5. 动作与先后关系分别判断

原文：“她先沿栏杆顶部奔跑，再高高跃起。”分别看是否跑动、在哪里跑，是否跃起、跳得是否高，以及两个动作的先后。

- 看完动作，她先在天台地面跑，再高跳：跑动、跃起、高度和先后分别匹配，跑动位置失配，不能把位置错误算到其他项上。
- 两个动作都出现，但先跃起后奔跑：动作本身可以分别匹配，先后关系失配。
- 完整过程确认根本没有前面的跑动：跑动和指定先后关系失配，后面的高跳仍按自身证据判断。

## 6. 次数和全程要求也要检查

原文：“机器人挥手三次。”看完原片，只看到两次完整挥手，“挥手”匹配，“三次”失配。不能猜被挡住时又挥了一次。如果只是没看完视频或抽帧漏掉动作，先补看；确实拿不到需要的视频片段，再记待核。

原文：“国王每次出场都保持金冠、白脸和红色细节。”看完原片，每次都戴金色王冠，但有一次脸变黑；红色细节只在部分出场中看得到，其余出场从头到尾都被遮住。“戴王冠”和“王冠是金色”分别匹配，“白脸”和“红色细节”分别失配。原文要求“每次”，只要有一次没做到，这一项就不符合；其他次符合也不能抵消。每项都要保留“每次”，分别检查。

例如“落地时有撞击声”：落地画面照常判断，撞击声和音画同步按[声音规则](../SKILL.md#3-逐镜分析)记无法判断。

## 7. 按正常观感判断效果

原文：“镜头缓慢推近。”推近动作与推近速度可能一个成立、另一个不成立，应分别判断：

- 对应场景中有一段清楚的缓慢推近，推近和缓慢分别匹配。原文没有要求全程缓慢。
- 对应场景只有快速推近，没有缓慢推近：推近匹配，缓慢要求失配。说明为什么看起来快，不自己规定速度数值。

“人物显得十分疲惫”：能看出疲态就匹配，不用纠结到底有多累；该看的片段都看过了，没有疲态才判失配。

“戏剧性的慢动作”分开看有没有慢动作、有没有戏剧性的效果。画面里已有慢动作，就不用再找后期变速记录；戏剧性的效果按平常看视频的感受判断。

“父女无伤逃脱”分开看：画面里有没有受伤，有没有逃脱。不需要医学证明。

## 8. 从原文检查有没有漏项

假设清单里的每项引用都能对上原文，也有判断、视频证据和完整译文，但原文里的新人物或物件、数量、末尾的禁止事项根本没列进去：

- 结构和保存检查可能全部通过，但从原文逐句查漏时应能发现这些遗漏。
- 对照完整原文检查清单，特别读一遍没被引用的文字。每个要求要么有自己的判断，要么已经和意思相同的要求合并；再看一项里是不是还混着能分开判断的内容。
- 不用为了圈满整段文字而给标点单独列一项，也不能整段都圈起来就算分析完。引用里留着“才”“全程”“三次”，却没检查这些要求，也不算完成。
