# 拆分与查漏示例

这些示例说明如何[拆分要求并作出判断](judgment-and-coverage.md)，也可用于检查修改后的规则是否仍然合理。画面条件都是假设，不能当作具体视频的观察结论。列出的核对内容是在解释原文，不能冒充逐字引文；真正的引用须保留原文字句，必要时共享或组合多个片段。拆法可以不同，不追求固定条目数；能分别成立或失败的要求要分别判断，同时说清对象、范围和前后关系。

## 1. 同一主体承接，属性仍须分别判断

原文：“女孩穿红色风衣，戴黑色手套，站在雪地里。”

- 先弄清后面的衣物和动作都属于这个女孩，再分别看她是否穿风衣、风衣是否为红色、是否戴手套、手套是否为黑色、是否站立、是否身处雪地。不必在每项中重复列出“女孩存在”。
- 若清晰画面中女孩穿红风衣、戴白手套、站在雪地里：手套颜色失配，其余有证据支持的要求分别匹配。不能把“戴黑色手套”整体记成 partial，掩盖“戴手套”成立而“黑色”失败。
- 原文中的省略照留，分析说明可以点明风衣、手套属于谁。不能只留下不知在说什么的“红色”“黑色”，也不能因为一个属性失败，就把其他要求一并降级。

### 同一段拆项后，引用也要分别定位

中文文本：“女孩穿红色风衣，戴黑色手套，站在雪地里。”
英文文本：“The girl wears a red trench coat and black gloves, standing in the snow.”

**两者均可作为源版或目标版，以下示例同时适用于中文译成英文和英文译成中文**。这里只演示部分要求该引用哪些文字，其他独立要求仍按上文核对；分析说明中要能看出衣物属于谁。

| 核对内容 | 英文实际片段 | 中文实际片段 |
|---|---|---|
| 穿风衣 | `wears`、`trench coat` | `穿`、`风衣` |
| 风衣为红色 | `red trench coat` | `红色风衣` |
| 手套为黑色 | `black gloves` | `黑色手套` |
| 身处雪地 | `in the snow` | `雪地里` |

如果这些项全部引用同一整句，即使判断各自独立、位置也正确，实际引用仍没拆开。两版语序不同，可以分别选取多个真实片段，不要求片段数量或排列方式相同。例如，“No blood or organs.”对应“不要出现血液或器官”时，器官禁令在英文中引用 `No` 与 `organs`，在中文中引用 `不要出现` 与 `器官`。两种方向都要保留否定，但无需把“血液”也算进器官这一项。

“摄影机全程保持固定”若作为一个完整要求，可以引用整句；不能为了缩短文字丢掉“全程”。必要的共用文字可以重叠，重点是每项引用是否准确，不追求所有引用互不重叠。

## 2. 并列外观可以分别成败

原文：“黄黑机械装甲、带角头盔、层叠甲片和外露的黑色机械结构，共同形成武士轮廓。”

- 分别看装甲外观和机械特征，以及配色是否含黄色、含黑色，不额外增加颜色比例或位置要求。同样分开检查头盔与角、甲片与层叠关系、机械结构及其黑色和外露状态。不能因为一个词组读起来完整，就把其中不同的要求打包判断。
- 若装甲为黄白配色，头盔存在但没有角：装甲含黄色、头盔存在这两项分别匹配；装甲含黑色、头盔带角这两项分别失配。若看不清指定机械结构是否外露，就说明待核，不能用其他部位的黑色证明它也是黑色。
- 整体是否形成武士轮廓、是否由这些部件共同形成，也要按实际证据判断。不能因为某个部件匹配就自动通过，也不能拆完部件后漏掉后半句。

## 3. 连续动作的独立结果与因果

原文：“武士从掌心发出金色能量波，击中怪物胸口，将它向后击飞。”

- 分别看谁发出了能量波、是否发出、从哪里发出、是什么颜色，是否击中怪物及命中哪里，怪物是否被击飞、飞向哪里，以及击飞是否由这次攻击造成。
- 假设画面清楚显示武士从口中发出红色能量波并击中怪物腹部：

| 核对内容 | 判断 |
| --- | --- |
| 发出了能量波 | 匹配 |
| 发出者为武士 | 匹配 |
| 发出位置为掌心 | 失配，实际为口中 |
| 能量波为金色 | 失配，实际为红色 |
| 能量波击中怪物 | 匹配 |
| 命中位置为胸口 | 失配，实际为腹部 |

- 若怪物确实被这次攻击击飞，但飞向侧面，击飞动作及其与本次攻击的因果关系分别匹配，向后要求失配。若命中后立即切走，后续结果不可见，击飞及方向分别待核；不能把“没看到”直接当作“没有击飞”。
- 别处由另一攻击造成的向后击飞，不能代替这次攻击的结果。即使动作和方向都出现了，也要确认它们发生在同一次攻击中，参与者和因果关系都对应。

## 4. 新主体不能漏在判断之外

原文：“一道电弧清晰可见地击中巨型LED广告牌，将其面板向外炸飞。”

- 逐项检查：是否有电弧、数量是否为一道、是否清楚看到命中、是否命中这个广告牌；广告牌是否为 LED、尺度是否符合“巨型”；被炸飞的是否是它的面板、是否向外飞，以及面板被炸飞是否由这次命中造成。
- 例如，有两道清晰电弧击中广告牌，电弧存在、命中过程清晰和命中广告牌都可以成立，数量要求失配。若这个广告牌明确不是 LED 广告牌，命中仍可匹配，LED 属性失配。若面板随后被另一物体撞飞，也不能把它算作本次电弧命中的结果。
- “巨型”按原文语境和画面中的尺度理解，不擅加米数标准。新出现的广告牌、面板，以及面板属于哪个广告牌，都要有对应的判断，不能只当作动作句的背景。
- 引文里保留了“一道”“清晰可见地”“向外”，还要分别核对这些条件；引用完整，不等于已经判断过它们。

## 5. 时序、条件与否定不能当作连接词跳过

原文：“红球落下后蓝球才移动。”先确认各球的身份和颜色，再分别判断红球落下、蓝球移动及两者的先后。两个动作都出现，但蓝球先动时，动作本身可以匹配，先后关系失配。动作都发生了，先后仍可能不对，因此这层关系也要单独判断。

原文：“她先沿栏杆顶部奔跑，再高高跃起。”分别看是否跑动、在哪里跑，是否跃起、跳得是否高，以及两个动作的先后。假设完整过程显示她先在天台地面跑，再高跳：跑动、跃起、高度和先后都有支持，跑动位置失配，不能把位置错误算到其他项上。若完整过程确认根本没有前面的跑动，则跑动和指定先后关系失配，后面的高跳仍按自身证据判断。

原文：“打开门，门打开后灯才亮，灯不要闪烁。”分别检查开门、灯亮、先后条件和不闪烁。完整观察确认门始终没开、灯却已亮起时，开门失配、灯亮匹配、先后关系失配；不闪烁另按过程证据判断。不能因为门没开，就把整句记成不适用；单张灯亮截图也不能证明先后或不闪烁。

对照：“如果门打开，就亮灯。”若完整观察确认门没开，且原文没有另外要求开门，这个条件响应才是不适用。若没看到开门过程，不知道条件是否触发，就待核。不能把“未看到开门”直接当作“门未打开”。

## 6. 全称范围不能通过拆分消失

原文：“全程保持红色外壳。”多数已看过的片段是红色，但有清晰片段显示外壳变蓝，就违反了“全程”，应判失配，同时保留红色片段的记录。不能删掉“全程”，也不能只拿红色片段证明匹配。若只是抽样时没发现变色，要说明看过哪些范围、哪些仍未核实。

原文：“机器人挥手三次。”完整过程只有两次时，挥手动作可以匹配，“三次”这一项失配，不能按完成比例记成 partial。若关键过程缺失，又没有其他决定性反例，次数待核。

原文：“国王每次出场都保持金冠、白脸和红色细节。”假设金冠在所需范围内有充分支持，某次清晰画面显示脸变黑，而红色细节的关键出场资料缺失、也没有反例：三项分别匹配、失配、待核，都保留“每次”的要求。共用“每次”这个条件，不代表三项必须共用状态，更不能统一套成 partial。多项音频要求若都因未试听而待核，可以得到相同状态，无需刻意凑出差异。

## 7. 部分实现与证据不足分别处理

原文：“镜头缓慢推近。”推近动作与推近速度可能一个成立、另一个不成立，应分别判断：

- 过程证据能确认推近，但无法确认播放速度或持续时间：推近匹配，缓慢程度待核，并说明缺少什么证据；不把整句记成 partial。
- 完整过程明确显示快速推近：推近匹配，缓慢要求失配。结合原文和实际过程说明速度判断，不自设统一的数值标准。
- 只有静态画面，无法确认摄影机运动：推近与速度均待核，不能凭构图猜测。

partial 用于不能合理再拆、且证据足以确认某个程度目标只达成了一部分的情况。例如“人物显得十分疲惫”：假设相关表演完整、清楚，结合语境能确认人物有疲态，但较轻，确实没达到原文要求的强度，就可判部分匹配，并说明依据。“十分”是在描述疲惫程度，不能另造一个“有一点疲惫”的弱化要求来增加匹配项。若人物清楚地表现为精神饱满，与疲惫直接相反，则失配；若关键表演没看见，或无法判断程度，则待核。

可以分开核对不同方面，不能把同一方面拆成一串由弱到强的重复要求。先看能独立判断的内容是否已经分开，再区分“确实没达到要求”和“还没看清”。不能把缺证当 partial，也不能为了减少 partial 强行判成匹配或失配。

判断标准要对应原文要求。在描述成片风格时，“戏剧性的慢动作”分别看慢动作表现和戏剧性效果。前者根据运动过程和节奏判断，不能因为没有后期变速资料就降为 partial；后者结合语境和视听表现解释，不能因为有慢动作就自动通过，资料不足时待核。若原文明示特定升格拍摄工艺，则需要相应来源支持。叙事中的“父女无伤逃脱”，看相关完整画面中的伤势表现和逃脱过程即可，不额外要求医学证明；关键过程确实缺失时，仍要说明。

## 8. 覆盖检查必须能发现清单之外的遗漏

假设已有清单中的每项都有合法引用、判断、视频证据和完整译文，但原文里的新主体、数量或末尾否定根本没有列进去：

- 结构和保存检查可能全部通过，但从原文逐句查漏时应能发现这些遗漏。
- 从完整原文回查清单，特别读一遍未引用的文字，确认每个实质要求都有判断或明确对应的同义项，再看每项内部是否还混着能分别成败的内容。
- 不为凑满字符覆盖而给标点单独建项，也不把整段全选当作已经分析。引用里留着“才”“全程”“三次”，却没判断这些词的要求，同样不合格。
- 源版漏掉的要求，不会因为其他项都已翻译就得到补全。拆分更新后，要按最新源版核对所有已授权目标语言；译文数量一致或状态为 current，都不足以证明全文没有漏项。
- 假设前半记录已经核实英雄落地，后半对全局落地要求却仍写“英雄部分见前半”：合并时应先汇总两段实际看到的支持、反例和缺口，再判断整个适用范围。不能直接拿半片结论当最终结论，也不能用另一段已经完成来代替核对。
- 根据已有状态自动生成“支持／反驳”关联，只是在重复结论。还要检查实际观察是否真的支持或反驳本项要求及其适用范围；不能用这种自动关联反过来证明原判断正确。
