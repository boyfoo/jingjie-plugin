# 拆分与查漏示例

这些示例说明如何[拆分要求并作出判断](judgment-and-coverage.md)。画面条件都是假设，不能当作具体视频的观察结论。列出的核对内容是在解释原文，不能冒充逐字引文；真正的引用须保留原文字句，必要时共享或组合多个片段。拆法可以不同，不追求固定条目数；能分别成立或失败的要求要分别判断，同时说清对象、范围和前后关系。

## 1. 同一主体承接，属性仍须分别判断

原文：“女孩穿红色风衣，戴黑色手套，站在雪地里。”

- 先弄清后面的衣物和动作都属于这个女孩，再分别看她是否穿风衣、风衣是否为红色、是否戴手套、手套是否为黑色、是否站立、是否身处雪地。不必在每项中重复列出“女孩存在”。
- 若清晰画面中女孩穿红风衣、戴白手套、站在雪地里：手套颜色失配，其余有证据支持的要求分别匹配。不能把“戴黑色手套”整体记成 partial，掩盖“戴手套”成立而“黑色”失败。
- 原文中的省略照留，分析说明可以点明风衣、手套属于谁。不能只留下不知在说什么的“红色”“黑色”，也不能因为一个属性失败，就把其他要求一并降级。

### 同一段拆项后，引用也要分别定位

上例英文文本：“The girl wears a red trench coat and black gloves, standing in the snow.”

**两者均可作为源版或目标版，以下示例同时适用于中文译成英文和英文译成中文**。这里只演示部分要求该引用哪些文字，其他独立要求仍按上文核对；分析说明中要能看出衣物属于谁。

| 核对内容 | 英文实际片段 | 中文实际片段 |
|---|---|---|
| 穿风衣 | `wears`、`trench coat` | `穿`、`风衣` |
| 风衣为红色 | `red trench coat` | `红色风衣` |
| 手套为黑色 | `black gloves` | `黑色手套` |
| 身处雪地 | `in the snow` | `雪地里` |

如果这些项全部引用同一整句，即使判断各自独立、位置也正确，实际引用仍没拆开。两版语序不同，可以分别选取多个真实片段，不要求片段数量或排列方式相同。例如，“No blood or organs.”对应“不要出现血液或器官”时，器官禁令在英文中引用 `No` 与 `organs`，在中文中引用 `不要出现` 与 `器官`。两种方向都要保留否定，但无需把“血液”也算进器官这一项。

“摄影机全程保持固定”若作为一个完整要求，可以引用整句；不能为了缩短文字丢掉“全程”。必要的共用文字可以重叠，重点是每项引用是否准确，不追求所有引用互不重叠。

## 2. 部件与整体关系分别判断

原文：“黄黑机械装甲、带角头盔、层叠甲片和外露的黑色机械结构，共同形成武士轮廓。”

配色含黄色、含黑色分别判断；若实际为黄白配色，含黄色匹配、含黑色失配，不额外增加颜色比例或位置要求。

各部件和属性分别核对后，整体是否形成武士轮廓、是否由这些部件共同形成，也要按实际证据判断。不能因为某个部件匹配就自动通过，也不能拆完部件后漏掉后半句。

## 3. 连续动作的独立结果与因果

原文：“武士从掌心发出金色能量波，击中怪物胸口，将它向后击飞。”

- 分别看谁发出了能量波、是否发出、从哪里发出、是什么颜色，是否击中怪物及命中哪里，怪物是否被击飞、飞向哪里，以及击飞是否由这次攻击造成。
- 假设画面清楚显示武士从口中发出红色能量波并击中怪物腹部：

| 核对内容 | 判断 |
| --- | --- |
| 发出了能量波 | 匹配 |
| 发出者为武士 | 匹配 |
| 发出位置为掌心 | 失配，实际为口中 |
| 能量波为金色 | 失配，实际为红色 |
| 能量波击中怪物 | 匹配 |
| 命中位置为胸口 | 失配，实际为腹部 |

- 若怪物确实被这次攻击击飞，但飞向侧面，击飞动作及其与本次攻击的因果关系分别匹配，向后要求失配。若命中后立即切走，后续结果不可见，击飞及方向分别待核；不能把“没看到”直接当作“没有击飞”。
- 别处由另一攻击造成的向后击飞，不能代替这次攻击的结果。即使动作和方向都出现了，也要确认它们发生在同一次攻击中，参与者和因果关系都对应。

## 4. 新主体不能漏在判断之外

原文：“一道电弧清晰可见地击中巨型LED广告牌，将其面板向外炸飞。”

新出现的广告牌、面板，以及面板属于哪个广告牌，都要有对应的判断，不能只当作动作句的背景。广告牌的 LED 属性和“巨型”尺度分别核对；“巨型”按原文语境和画面中的尺度理解，不擅加米数标准。“击中广告牌”和“命中过程清晰可见”分别核对，不能仅因命中成立就默认清晰度符合。

## 5. 动作与先后关系分别判断

原文：“她先沿栏杆顶部奔跑，再高高跃起。”分别看是否跑动、在哪里跑，是否跃起、跳得是否高，以及两个动作的先后。

- 完整过程显示她先在天台地面跑，再高跳：跑动、跃起、高度和先后都有支持，跑动位置失配，不能把位置错误算到其他项上。
- 两个动作都出现，但先跃起后奔跑：动作本身可以分别匹配，先后关系失配。
- 完整过程确认根本没有前面的跑动：跑动和指定先后关系失配，后面的高跳仍按自身证据判断。

## 6. 全称范围不能通过拆分消失

原文：“机器人挥手三次。”完整过程只有两次，挥手动作匹配，“三次”失配。如果已经数到两次，后续被遮挡，总次数记部分匹配，说明只能确认前两次。如果只有一张举手截图，连一次完整挥手都数不出来，次数待核。

原文：“国王每次出场都保持金冠、白脸和红色细节。”假设每次都看清国王戴着王冠，王冠均呈金色，有一次出场过程中脸明显变黑，红色细节只在部分出场时看清，其余出场被遮挡。“戴着王冠”和“王冠呈金色”分别匹配，白脸失配，红色细节部分匹配。白脸已有可靠反例，其他出场匹配或尚未核实，都不撤销失配。若每次出场都看不清红色细节，也没有反例，这一项才待核。各项都保留“每次”，各按自己的证据判断；抽样时没发现反例，不代表每次都已核实。

例如“落地时有撞击声”：落地画面照常判断，撞击声和音画同步按[声音规则](../SKILL.md#3-逐镜分析)记无法判断。配乐风格与原创性仍分开列项，两项都无法判断。

## 7. 部分实现与证据不足分别处理

原文：“镜头缓慢推近。”推近动作与推近速度可能一个成立、另一个不成立，应分别判断：

- 过程能确认推近，但没有可判断速度的证据，推近匹配，速度待核。若其中一段确实缓慢推近，余下过程看不清，速度可记部分匹配，写明看清的是哪一段。
- 完整过程明确显示快速推近：推近匹配，缓慢要求失配。结合原文和实际过程说明速度判断，不自设统一的数值标准。
- 如果只拿到一张截图，推近和速度都待核。

“人物显得十分疲惫”是一个程度要求，作为一项判断。

| 实际画面 | 判断及理由 |
|---|---|
| 整段看清，人物只有轻微疲态 | 部分匹配。有疲态，程度较轻。 |
| 已看出疲态，关键表演被遮挡 | 部分匹配。能确认疲态，是否达到“十分”的程度还看不清。 |
| 表情和姿态都看不清，连有没有疲态也无法判断 | 无法判断。缺少能说明疲惫程度的画面。 |
| 人物全程精神饱满，与疲惫直接相反 | 失配。画面给出了明确反例。 |

**先拆开独立要求。部分匹配要有直接支持这一项的证据，并写清看到了什么、还有什么没做到或没看清。**

判断标准要对应原文要求。在描述成片风格时，“戏剧性的慢动作”分别看慢动作表现和戏剧性效果。前者根据运动过程和节奏判断，不能因为没有后期变速资料就降为 partial；后者结合语境和画面表现解释，只有慢动作本身不足以判断戏剧性效果。若原文明示特定升格拍摄工艺，则需要相应来源支持。

叙事中的“父女无伤逃脱”，按相关完整画面中的伤势表现和逃脱过程分别判断，不额外要求医学证明；关键过程缺失时仍说明缺口。

## 8. 覆盖检查必须能发现清单之外的遗漏

假设已有清单中的每项都有合法引用、判断、视频证据和完整译文，但原文里的新主体、数量或末尾否定根本没有列进去：

- 结构和保存检查可能全部通过，但从原文逐句查漏时应能发现这些遗漏。
- 从完整原文回查清单，特别读一遍未引用的文字，确认每个实质要求都有判断或明确对应的同义项，再看每项内部是否还混着能分别成败的内容。
- 不为凑满字符覆盖而给标点单独建项，也不把整段全选当作已经分析。引用里留着“才”“全程”“三次”，却没判断这些词的要求，同样不合格。
- 源版漏掉的要求，不会因为其他项都已翻译就得到补全。拆分更新后，要按最新源版核对所有已授权目标语言；译文数量一致或状态为 current，都不足以证明全文没有漏项。
- 假设前半记录已经核实英雄落地，后半对全局落地要求却仍写“英雄部分见前半”：合并时应先汇总两段实际看到的支持、反例和缺口，再判断整个适用范围。不能直接拿半片结论当最终结论，也不能用另一段已经完成来代替核对。
- 根据已有状态自动生成“支持／反驳”关联，只是在重复结论。还要检查实际观察是否真的支持或反驳本项要求及其适用范围；不能用这种自动关联反过来证明原判断正确。
