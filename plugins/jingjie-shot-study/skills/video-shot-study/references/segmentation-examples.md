# 拆分与查漏示例

用于校准[语义拆分与判定](judgment-and-coverage.md)，也用于修改插件后检查规则是否仍能处理这些情形。以下画面条件均是假设，不能当作具体视频的观察结论。列出的核验内容解释原文含义，不冒充逐字引文；实际引用保持原样，必要时共享或组合原文片段。允许语义等价的拆法，不追求固定条目数；每个可独立成败的要求都须有判断，保留对象、范围与承接关系。

## 1. 同一主体承接，属性仍须分别判断

原文：“女孩穿红色风衣，戴黑色手套，站在雪地里。”

- 先确认女孩这一主体及后文的承接，再分别核验穿着风衣、风衣为红色、戴着手套、手套为黑色、站立状态、身处雪地。已确认的同一主体不必在每条重复建存在项。
- 若清晰画面中女孩穿红风衣、戴白手套、站在雪地里：手套颜色失配，其余得到证据支持的要求分别匹配。不能把“戴黑色手套”整体记成 partial，掩盖戴手套成立而颜色失败。
- 原文中的省略照留；分析说明可点明风衣、手套属于谁。不能只留下脱离对象的“红色”“黑色”，也不能因一个属性失败降低其他要求的判断。

## 2. 并列外观可以分别成败

原文：“黄黑机械装甲、带角头盔、层叠甲片和外露的黑色机械结构，共同形成武士轮廓。”

- 装甲外观、机械特征、装甲配色含黄色、含黑色分别判断，不额外添加颜色比例或位置要求；同样检查头盔及其角、甲片及其层叠关系、机械结构及其黑色与外露状态。不能因为词组读起来完整，就把其中的不同要求打包成一个结论。
- 若装甲为黄白配色，头盔存在但没有角：装甲含黄色和头盔存在分别匹配，装甲含黑色和带角要求分别失配。外露状态被遮挡时说明待核，不能用其他部位的黑色证明指定机械结构为黑色。
- 整体轮廓与“共同形成”的关系按实际证据判断，不能因某个部件匹配就自动通过，也不能在拆分后漏掉这半句。

## 3. 连续动作的独立结果与因果

原文：“武士从掌心发出金色能量波，击中怪物胸口，将它向后击飞。”

- 分别核验发出主体与动作、发出位置、能量波颜色、命中动作、命中位置、怪物被击飞、击飞方向，以及击飞与同一攻击的因果关系。
- 假设画面清楚显示武士从口中发出红色能量波并击中怪物腹部：

| 核验内容 | 判断 |
| --- | --- |
| 发出了能量波 | 匹配 |
| 发出者为武士 | 匹配 |
| 发出位置为掌心 | 失配，实际为口中 |
| 能量波为金色 | 失配，实际为红色 |
| 能量波击中怪物 | 匹配 |
| 命中位置为胸口 | 失配，实际为腹部 |

- 若怪物确实被该攻击击飞但飞向侧面，击飞动作与属于本次攻击的关系分别匹配，向后要求失配。若命中后立即切走，后续结果不可见，击飞及其方向分别待核；不能用“未看到”直接证明没有击飞。
- 别处由另一攻击造成的向后击飞，不能代替本次攻击的结果。动作、方向均出现，也仍须判断是否属于同一主体、事件和因果链。

## 4. 新主体不能漏在判断之外

原文：“一道电弧清晰可见地击中巨型LED广告牌，将其面板向外炸飞。”

- 逐项检查电弧存在、数量为一道、命中过程清晰可见、命中该广告牌、该广告牌的 LED 属性与巨型尺度、该广告牌的面板被炸飞、飞出方向向外，以及面板结果与本次命中的关系。
- 例如有两道清晰电弧击中广告牌：电弧存在、清晰程度与命中可分别成立，数量要求失配；若该广告牌明确不是 LED 广告牌，命中仍可匹配，LED 属性失配。若面板随后被另一物体撞飞，不能据此判定本次命中使其炸飞。
- “巨型”按原文语境和可见尺度解释，不擅加米数阈值。新出现的广告牌、面板及其所属关系须有明确核验去向，不能只把它们当作动作句中的背景。
- 把“一道”“清晰可见地”“向外”等文字包含在引文中，还须核对各自含义；引用完整不等于这些限定已得到判断。

## 5. 时序、条件与否定不能当作连接词跳过

原文：“红球落下后蓝球才移动。”在核实各球身份和颜色后，分别判断红球落下、蓝球移动及两者的先后关系。两个动作都出现但蓝球先动时，动作本身可匹配，先后关系失配。只要关系能在动作均成立时独立失败，就必须给出自己的判断，不能只留在说明里。

原文：“她先沿栏杆顶部奔跑，再高高跃起。”分别核验跑动、跑动位置、跃起及其高度、两动作先后。假设完整过程显示她先在天台地面跑，再高跳：跑动、跃起、高度与先后均有支持，跑动位置失配，不能把位置失败传给其他项。若完整过程确认根本没有前置跑动，则跑动与指定先后关系失配，后续高跳仍按自身证据判断。

原文：“打开门，门打开后灯才亮，灯不要闪烁。”分别检查开门、灯亮、条件时序与不闪烁。完整观察确认门始终未开而灯已亮起时，开门失配、灯亮匹配、先后关系失配；不闪烁另按过程证据判断。门没开不能让整句变成不适用，单张灯亮截图也不能证明先后或不闪烁。

对照：“如果门打开，就亮灯。”若完整观察确认门未开，且原文未另行要求开门，条件响应不适用；若开门过程没有观察到，是否触发未知，则待核。不能把“未看到开门”直接当作“门未打开”。

## 6. 全称范围不能通过拆分消失

原文：“全程保持红色外壳。”已见多数片段为红色，但清晰片段显示外壳变蓝，构成该全称要求的反例。应判失配并保留局部支持，不能删掉“全程”，也不能只拿红色片段证明匹配。仅抽样未见变色时，保留检查范围与未核部分。

原文：“机器人挥手三次。”完整过程只有两次时，挥手动作可匹配，次数为三次这一项失配；不能把明确数量条件按完成比例记成 partial。若关键过程缺失且没有其他决定性反例，次数待核。

原文：“国王每次出场都保持金冠、白脸和红色细节。”假设所需范围内金冠有充分支持，某次清晰画面显示脸变黑，而红色细节的关键出场资料缺失且没有反例：三项分别匹配、失配、待核，都保留“每次”范围。共享全称范围不意味着共享状态，不能统一套用 partial。多项音频要求若都因未试听而待核，则可以合理同态，无需凑出不同状态。

## 7. 部分实现与证据不足分别处理

原文：“镜头缓慢推近。”推近动作与推近速度可分别成败，应分别判断：

- 过程证据能确认推近，但无法核实播放速度或持续时间：推近匹配，缓慢程度待核，注明缺少的证据；不把整句记成 partial。
- 完整过程明确显示快速推近：推近匹配，缓慢要求失配。速度标准结合原文与实际过程解释，不自设统一数值阈值。
- 只有静态画面，无法确认摄影机运动：推近与速度均待核，不能凭构图猜测。

partial 留给不能合理再拆、且证据充分确认同一连续程度目标只部分实现的要求。例如“人物显得十分疲惫”：假设完整相关表演清楚可见，结合语境可以确认疲态较轻、确实未达到原文要求的强度，可判程度部分匹配并说明表现依据。这里“十分”修饰同一疲惫属性，不额外造出“有一点疲惫”作为新要求；若表演清晰且人物精神饱满，与疲惫直接相反，则失配；若关键表演未见或无法判断其程度，则待核。

独立维度可以拆开，同一维度的强弱不能拆成一串由弱到强的重复要求。先检查独立内容是否已拆开，再区分实际程度不足与无法看清；不把缺证当 partial，也不为减少 partial 强行判成匹配或失配。

核验标准应对应原文目标。在成片风格语境中，“戏剧性的慢动作”分别核验慢动作表现和戏剧性效果：前者按运动过程与节奏判断，不因缺少后期变速资料降为 partial；后者结合语境和视听表现论证，不因慢动作成立就自动通过，缺少足以判断效果的资料时待核。原文若明确要求特定升格拍摄工艺，则须有相应来源。叙事要求“父女无伤逃脱”按完整相关画面的伤情表现和逃脱过程判断，不额外要求医学证明；关键过程确实缺失时，仍说明缺口。

## 8. 覆盖检查必须能发现清单之外的遗漏

假设清单已列出若干项，每项都有合法引用、判断、视频证据和完整译文，但原文中的新主体、数量或末尾否定没有进入任何项：

- 结构与保存检查可以通过，原文语义覆盖检查必须发现遗漏。
- 从完整原文反查清单，并专门阅读未引用文字；核对所有实质内容是否有判断或明确的同义项对应，再回查每项内部是否仍捆绑可独立成败的要求。
- 不为凑满字符覆盖而给标点单独建项，也不把整段全选当作已分析。把“才”“全程”“三次”留在引用里却未核验其含义，同样不合格。
- 源版漏掉的要求，即使其他项全部翻译，也仍然遗漏。拆分更新后按最新源版核对各授权目标语言；单纯译文数量一致或状态为 current 不足以宣布全文无漏项。
- 假设前半记录说明英雄落地已核实，后半对全局落地要求仍写“英雄部分见前半”：合并时先汇总两段的实际支持、反例和缺口，再确定全局状态；不能把半片结论直接当最终结论，也不能以另一段已完成代替核对。
- 已有状态自动生成“支持／反驳”关联，只是复写结论。须检查实际观察是否支持本项要求及其范围；按状态选出的关联不能充当独立验证。
