# 素材观察与切点确认

## 媒体信息与时间轴

先查看当前环境有哪些媒体工具，不预设用户目录、程序路径或下载服务。可用 FFmpeg/FFprobe 时，可参考：

```text
ffprobe -v error -show_format -show_streams -of json "video.mp4"
```

记录视频流时长、`time_base`、`start_time`、`avg_frame_rate`、`r_frame_rate` 及音轨信息。字段缺失，或容器时长包含更长的音频、尾部留白时，结合解码帧和实际使用的播放器，确认画面的起止时间。

- 确认是固定帧率后，可用帧索引辅助定位；可变帧率须按解码帧的 PTS 定位，不能一律用 `frame_index / fps`。
- 将媒体时间换算为从 0 开始的播放时间时，记录所用的偏移量。容器、视频流和播放器的时间不能混用。画面终点是末帧起始 PTS 加上该帧持续时间，记录采用这一时间的依据。

## 观察与取证要点

- 按主文说明，能播放时先观看待分析片段。需要抽帧时，通常先找大致范围再细查；已有可靠定位时，可直接补查相关区间，同时留意本次任务中尚未看过的部分。取帧间隔随动作速度和镜头长度调整。
- 根据要查的问题，按下节的方法整理图片。标上实际播放时间，以能看清目标的尺寸展示，并实际打开查看。生成了图片或检测分数，不代表已经看过内容。
- 疑似切点、短镜头、快动作、遮挡、景别变化或提示词时间边界附近，可加密取帧，必要时逐帧回看。按本项要求查看必要的前后过程：用相邻帧找边界，用前后过程解释原因、判断手法。
- 每镜保留首尾帧和必要的代表图，记录实际时间及判断依据。原始 PTS 等数据只在核对时间轴时补记。

按时间排列、足以看清变化，而且真正看过的原视频帧，可以用来判断过程和大致时间。说清用了抽帧、逐帧回看还是实时播放，不能把密集抽样说成逐帧看完。单帧或稀疏首尾帧不能证明完整事件的起止；关键过程缺失时说清缺什么，不能按故事情节补出来。

## 分层给图与补证

根据要核对的问题选择下列方式，不要求每项都走完四种。同一图片可以作为多项要求的证据，但每项仍须独立判断。

| 方式 | 图片组织与用途 |
| --- | --- |
| 范围总览 | 按时间排列缩略图并标注时间，了解本次分析范围内的事件、镜头和变化，找到需要细查的区间；看不清的细节仍要另查。 |
| 动作过程 | 按时间顺序比较同一对象的位置、朝向、形状和接触关系，以周围物体或自身部位作参照。结合相邻帧和前后过程，留意轻微、短暂或反复的变化，区分对象变化与镜头、视角变化。按动作快慢补看关键变化前后的帧，不能只凭首尾两帧补出中间动作，也不能仅因两帧不同就认定发生了某种动作。 |
| 关键细节 | 打开单张清晰帧，必要时看原始分辨率或局部裁剪；保留完整帧、时间和裁剪位置，确保能认清对象及其周围关系。 |
| 参考对照 | 分别标明作者参考图与视频帧的来源，再对照查看；需要时选较接近的视角或部位，并保留完整图供回查。参考图不能证明视频里已经出现了同样的内容。 |

图片尺寸、每组张数和取帧间隔，以能否认清目标、是否漏掉关键变化为准，不统一规定每秒几张或拼图密度。检查颜色可以用清晰帧；检查“从掌心发射”，就看能量是不是从掌心发出的，需要时看前后几帧。

哪里没看清，就用下面对应的方法补看，不用按顺序都做一遍：

- **小图看不清。** **先单独打开原图，必要时放大或看局部，再判断。** 保留完整帧、时间和局部位置，方便回查。
- **过程缺失。** 关键变化发生在两次取帧之间，就在这段里多取几帧，并补看事件前后。保持原来的时间顺序和间隔，不能靠重排图片或删掉前后画面来证明动作、方向或因果。

看清了就不必重复抽帧或放大，可以继续分析手法、效果和要求之间的关系；发现新问题再补查。**没看完或抽帧漏了动作，先补看；拿不到需要的视频或参考资料，就说明缺什么。看清相关过程后，成片仍未表现出本项要求，就判失配，写清未表现出什么，不猜被挡住的地方发生了什么。** 汇总本项已有的画面证据，再按[判定规则](judgment-and-coverage.md#4-判断实现情况及其边界)给出结论。

记录实际看过的范围和必要图片，连续区间可以合并。

## 怎么判断是否切镜

需要定位切镜时，可以用下面的命令找出相邻两帧变化很大的时间点。

```text
ffmpeg -hide_banner -i "video.mp4" -vf "select='gt(scene,0.30)',showinfo" -an -fps_mode vfr -f null -
```

在工具标出的时间点回看前后几帧。比如爆炸会让画面突然变亮，动作却可能还在同一个镜头里。叠化、淡入淡出，或切到构图相似的画面时，变化可能很小，工具也会漏掉。镜头从哪里开始，以实际画面为准。

## 从画面现象到专业判断

先说清画面哪里变了，再回看前后过程，判断用了什么手法。拿不准时可以参考下表。

| 可见现象 | 要看什么、哪些还不能确定 |
| --- | --- |
| 画面突然变化 | 先看空间和动作是否连续，再判断是否切镜及如何衔接。闪光、快速运动或画面连续性异常也可能造成突变；不能确认就保留为疑似边界。 |
| 前景物体经过镜头 | 看遮挡前后是否真的换了画面、物体是否参与转场；如果空间连续，也可能只是构图或动作变化。 |
| 主体逐渐变大 | 结合主体位移、背景视差和透视关系，区分主体靠近、摄影机推进、变焦或裁切变化；无法区分时，只描述主体在画面中变大。 |
| 画面快速模糊或变清晰 | 看主体及整个画面怎样运动、前后景哪里清晰。仅有模糊不能证明甩镜或切镜，仅有变清晰也不能证明焦点转移。 |
| 亮度突然变化 | 结合空间连续性、亮部和阴影，区分光照变化、曝光变化、闪光或画面切换。 |

镜头在哪里切开、怎么衔接、画面里的运动从哪来、对叙事有什么作用，分别说明。直接切换也可以同时借助遮挡或动作匹配。仅凭成片，不能确定实际采用了实拍剪辑、分段生成还是某种后期处理。

## 边界约定

确认硬切后，以新画面的第一帧为新镜头起点，上一镜头在这里结束，采用 `[start, end)`。上一镜头的尾帧取边界前最后一帧，不能取下一镜头的首帧；时间边界与转场手法仍须分别判断。

遇到叠化或其他渐变转场，记录它持续的区间，并说明采用哪种分界方式，前后保持一致。不能把这段转场记成某一帧发生的硬切。

无法确认的边界标为近似，不用多位小数显得更精确。

## 声音与作者文字

声音按[主文第3节](../SKILL.md#3-逐镜分析)处理，记为无法判断，不补试听。

可以读取音轨的存在、时长和编码等技术信息，但这些信息不能证明具体声音内容。

作者文字与实际成片分别核对，来源与完整性统一按 [SKILL.md 第4节](../SKILL.md#4-核对提示词及其时间段)处理。
