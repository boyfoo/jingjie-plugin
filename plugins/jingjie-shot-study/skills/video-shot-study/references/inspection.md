# 素材观察与切点确认

## 媒体信息与时间轴

先发现环境里可用的媒体工具，不固定用户目录、可执行文件路径或下载服务。可用 FFmpeg/FFprobe 时，参考：

```text
ffprobe -v error -show_format -show_streams -of json "video.mp4"
```

记录视频流时长、`time_base`、`start_time`、`avg_frame_rate`、`r_frame_rate` 与音轨。字段缺失或容器时长包含较长音频／尾部留白时，结合解码帧和目标播放器核准有效画面时间轴。

- 已核实固定帧率时可用帧索引辅助定位；可变帧率按解码帧 PTS，不能一律用 `frame_index / fps`。
- 记录媒体时间到从0开始的播放时间的偏移，不混用容器、视频流和播放器时间。末帧起始 PTS 加上该帧持续时间才是画面终点，保留选用依据。

## 实际观察顺序

1. 按主文的播放优先级观察；抽帧时先粗后细覆盖待分析范围的时间轴，间隔随动作与镜头长度调整。
2. 标注真实播放时间，以可辨尺寸分组并实际打开查看；生成图片或检测分数不等于看过内容。
3. 对疑似切点、短镜头、快动作、遮挡、景别变化及提示词时间边界加密，必要时逐帧回看。覆盖准备、变化和结果：相邻帧定位边界，前后过程用于解释原因及命名手法。
4. 每镜保留起始、结束前与代表帧，必要时存切点前后对照；记录确认时间、原始 PTS、图像路径与判断依据。

实际查看过且对目标变化足够密集的有序真实帧，可支撑过程回看与近似片段定位；按实际覆盖方式注明抽帧或逐帧观察、是否实时播放及试听，不把密集抽样称为逐帧看完。单帧或稀疏首尾帧不扩成事件区间；未看的抽样空档保留未知，不靠叙事补齐。

## 自动检测只是候选

可用场景差分缩小搜索范围，例如：

```text
ffmpeg -hide_banner -i "video.mp4" -vf "select='gt(scene,0.30)',showinfo" -an -fps_mode vfr -f null -
```

先检查工具参数，优先使用可靠的现成检测工具。阈值只影响候选点的漏检与误检，不是边界标准。逐个查看候选前后数个相邻解码帧，也回查可能无明显峰值的缓慢叠化、淡入淡出和相似构图切换。实际边界以画面为准，不按提示词的“镜头二”等文字推定。

## 从画面现象到专业判断

先记录变化，再按前后过程辨别原因；有歧义时用下表查证，不凭峰值或单张代表帧定名。

| 可见现象 | 需要辨别的证据与判断边界 |
| --- | --- |
| 画面突然变化 | 先核对空间和动作连续性，再确认切镜及衔接。闪光、快速运动或画面连续性异常也会造成突变；不能确认就保留疑似边界。 |
| 前景物体经过镜头 | 检查遮挡前后是否实际切换、物体是否参与衔接；空间连续时可能只是构图或动作。 |
| 主体逐渐变大 | 结合主体位移、背景视差与透视关系，辨别主体靠近、摄影机推进、变焦或裁切变化；无法区分时只描述尺度变化。 |
| 画面快速模糊或变清晰 | 检查主体／画面整体运动和各景深层的清晰度；模糊不单独证明甩镜或切镜，变清晰也不单独证明焦点转移。 |
| 亮度突然变化 | 根据空间连续性、亮部及阴影区分光照、曝光、闪光和切换。 |

边界、衔接手法、运动来源和叙事作用分别记录，有依据时可同时成立；直接切换也可借助遮挡或动作匹配。成片表现不能单独证明实拍剪辑、分段生成或后期处理等制作流程。

## 边界约定

明确硬切以新画面第一帧为新镜头起点，上一镜头在该点结束，采用 `[start, end)`。尾帧取边界前最后一帧，不取下一镜头首帧；这一约定不代替转场手法分析。

叠化或其他渐变转场：记录转场区间，并采用清楚、一致的镜头分界约定。不要把一个持续转场假装成已精确确认的硬切帧。

无法确认的边界标为近似或待核，不用多位小数制造精度感。

## 声音与作者文字

实际试听后分析动作声、环境声、配乐、节奏及声画关系；只有 ASR 时限于可靠转写内容，不当作已听过配乐和音效。

作者文字与成片分别核验，来源与完整性统一按 [SKILL.md 第4节](../SKILL.md#4-核对提示词及其时间段)处理。
