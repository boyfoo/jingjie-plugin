# 素材观察与切点确认

## 媒体信息与时间轴

先发现环境里可用的媒体工具，不固定用户目录、可执行文件路径或下载服务。可用 FFmpeg/FFprobe 时，参考：

```text
ffprobe -v error -show_format -show_streams -of json "video.mp4"
```

记录视频流的时长、`time_base`、`start_time`、`avg_frame_rate`、`r_frame_rate` 和音轨情况。字段可能缺失，容器时长也可能包含比画面更长的音频或尾部留白，需要结合解码帧和实际播放器核验。

- 固定帧率且已验证时，可用帧索引与帧率辅助定位。
- 可变帧率视频按解码帧的 PTS 和时间基准定位，不以 `frame_index / fps` 代替所有帧的时间。
- 播放时间从 0 开始时，明确媒体时间到播放时间的偏移。不要混用容器时间、视频流时间和播放器显示时间。
- 最后一帧的起始 PTS 不等于整片终点，还要考虑该帧持续时间。以目标播放器对应的有效画面时间轴为准，并记录依据。

## 实际观察顺序

1. 首轮完整播放，或对全时间轴生成有序抽帧。短片可从每 0.5-2 秒一帧起步，长片先粗后细；间隔随动作和镜头长度调整，不把固定抽样当成不会漏镜头的保证。
2. 每张图标明真实播放时间，按顺序分组，保持可辨识尺寸，不把大量缩略图压到看不清细节。
3. 用图像查看工具实际打开这些图。生成了图片、运行了 OpenCV 或拿到检测分数，都不等于已经看过内容。
4. 针对疑似切点、短镜头、快速动作、遮挡、景别变化和提示词时间边界补帧；必要时逐帧检查对应区间。观察范围随动作调整，覆盖准备、变化过程和结果：相邻帧用于定位边界，完整前后过程用于解释变化与命名手法，不能只围绕差分峰值取两张图。
5. 保存代表帧和边界前后帧，建立图片与镜头时间的对应关系。证据记录是工作材料，不额外生成统计或质量审核章节。

只有抽帧观察时，明确其限制：抽样间隔内可能有短镜头或动作，声音节奏也尚未核验。重要空档不能靠叙事猜测补齐。

## 自动检测只是候选

可用场景差分缩小搜索范围，例如：

```text
ffmpeg -hide_banner -i "video.mp4" -vf "select='gt(scene,0.30)',showinfo" -an -fps_mode vfr -f null -
```

先检查当前工具是否支持所用参数。阈值 `0.30` 只是起点，调整阈值会改变漏检与误检，不是镜头边界的客观标准。优先使用已有、可靠的场景检测库或媒体工具，不为此手写复杂检测引擎。

候选点逐个确认：

- 看候选点之前和之后至少数个相邻解码帧，而非仅对比相隔数秒的图。
- 闪光、曝光突变、快速摇镜、大物体遮挡和主体快速移动，都可能产生高差分但没有切镜。
- 缓慢叠化、淡出淡入、相似构图之间的切镜可能没有明显峰值，须结合连续观察补查。
- 一个连续镜头内，远景推进到特写并不自动变成两个镜头。
- 检测结果与提示词中的“切近”“镜头二”等文字不一致时，以画面证据认定实际镜头；两者分别记录。

## 从画面现象到专业判断

先记录可见变化，再结合前后动作、空间关系与清晰度变化解释原因。检测峰值、单张代表帧或一个显著特征，不能单独确定专业类别；只在有歧义时比较合理解释，无需给普通镜头罗列所有可能性。

| 可见现象 | 需要辨别的证据与判断边界 |
| --- | --- |
| 画面突然变化 | 核对前后空间与动作连续性，确认是否存在镜头边界，再分析衔接手法。若变化也可由闪光、快速运动或画面连续性异常解释，且缺少确认边界的证据，保留疑似边界，不强拆镜头。 |
| 前景物体经过镜头 | 检查遮挡前后是否实际切换、物体运动是否参与衔接；有遮挡但空间连续时，它可能只是构图或动作。 |
| 主体逐渐变大 | 结合主体位移、背景视差与透视关系，辨别主体靠近、摄影机推进、变焦或裁切变化；无法区分时只描述尺度变化。 |
| 画面快速模糊或变清晰 | 检查运动来自主体还是画面整体、不同景深层的清晰度如何变化；模糊本身不证明甩镜或切镜，变清晰本身不证明焦点转移。 |
| 亮度突然变化 | 结合空间连续性、亮部与阴影变化，辨别光照、曝光、闪光与画面切换；证据不足时保留不确定性。 |

分析同一接点时区分边界位置、可见衔接形式、视觉手法与表达作用，有依据的维度分别记录，无法确认的维度不强填。例如直接切换的接点可以同时采用遮挡或动作匹配，并承担信息揭示；这些判断属于不同维度。命名应有相应过程证据，不因出现某个物体或某种模糊就自动套用术语。成片表现也不能单独证明实拍剪辑、分段生成或后期处理等制作流程。

## 边界约定

硬切等直接切换的明确边界：新画面出现的第一帧为新镜头起点；上一镜头在该点结束，采用 `[start, end)`。结束代表帧使用边界之前的最后一帧，而不是下一镜头第一帧。这一时间约定只确定边界，不替代对转场手法的分析。

叠化或其他渐变转场：记录转场区间，并采用清楚、一致的镜头分界约定。不要把一个持续转场假装成已精确确认的硬切帧。

内部证据可以包含候选时间、确认后的播放时间、帧 PTS、图片路径和判断理由。无法确认时标明近似或待核验，不用多位小数制造精度感。

## 声音与作者文字

有听音能力时检查动作声、环境声、配乐进入退出、节奏和声画关系；只有 ASR 文本时，说明这是转写依据，不把它当成已听过配乐和音效。

作者文字是制作意图的证据，不是实际切镜或动作完全实现的证据。核验长帖时注意正文展开、长文容器、附图和附件；下载元数据可能只读取短版正文。遇到结尾突然中断、链接代替后文、只有全局条件或转载比摘要明显更长，继续查完整来源。

没有找到后文只能说明目前获取受限，不能推出作者没有写。若不能核实来源对应关系或完整性，保留限制，停止“作者完整原文”这一结论。
