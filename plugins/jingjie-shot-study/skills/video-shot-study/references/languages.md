# 源版语言与可选翻译

三个技能共用本流程。中文用于交流；案例内容和交付文件使用用户确认的源版语言，作者引文原样保留。界面或交流语言不决定内容语言。

## 1. 先确认源版语言

先核实作者提示词的主要正文语言，据此提出建议，让用户确认一次；已有明确选择直接沿用。原文缺失或语言混合而无法判断时先确认，不默认中文。无作者原文的反推任务依据用户制作要求建议，不把新写内容称为作者原文。

已有案例先核对已保存的语言与资料，不擅自改换。涉及镜界时先读取 jingjie://submission-guide，按当前工具说明设置并回读源版语言；源语言与可选译文语言的范围由服务端说明，不能从站点界面语言反推。等待确认时可核验素材和来源，不先生成尚未确认语言的说明。

## 2. 先完成并核对源版

新生成的标题、简介、逐镜分析、人物说明、深入对应说明，以及反推提示词和制作说明统一使用源版语言；作者原文、台词和其他直接引文不改写。

只完成本次已授权工作，不为翻译补写未授权内容。已授权保存时按 [jingjie.md](jingjie.md) 保存到同一案例并回读核对；包括已授权深入分析在内的源版工作全部完成后，才进入目标语言选择。

## 3. 完成后再选择目标语言

从服务端当前返回的可选语言生成列表，排除源语言，允许多选或跳过。例如：“源版已保存并核对。是否翻译并保存到以下语言：<可选语言>？可多选，也可跳过。”

不预选，不把同意保存或深入分析当作翻译授权。已有明确目标直接沿用；未答复就等待，拒绝或跳过后不再追问。提交、深入和翻译一次确认一项；仅本地翻译不自动创建案例或上传素材。

## 4. 按目标语言和模块保存译文

先读取 jingjie://submission-guide，并通过 jingjie_get_translation_context 获取本次目标语言的完整源内容、已有译文和保存要求。参数、字段、依赖、版本及校验规则只以 MCP 指南、工具自带结构和当前返回为准；技能不另列一套接口契约。

结合全文语义完成已授权内容的翻译，保留条件、否定、程度和引用关系，不以摘要代替全文，不新增创作要求。复用同一案例，按当前工具要求调用 jingjie_save_translation 保存并回读，核对实际内容与预期一致。原文、媒体、既有时间和分析结论保持不变，不自动发布。

### 4.1 深入分析译文的完整对应

从翻译上下文一次取得完整源版深入对应分析 `prompt_alignment`、原文全文、既有文字对应和时间依据，结合已有目标提示词，在同一翻译阶段完成说明与对应。AI 负责语义核对；结构、覆盖完整性与版本检查由 MCP 执行，不增加用户逐条审核，也不重新分析视频。

需要且已获授权修改目标提示词时，先保存提示词并回读，再重新获取实际目标文档，完成所有既有要求的目标语言对应后保存 `prompt_alignment` 译文。已有有效目标提示词直接复用。目标语可自然调序或用多个片段表达同一要求，应依据含义定位，不能机械照搬源文位置。

缺少必要上下文、目标文档或修改授权时，保留已完成源版，明确未完成范围，不编造对应、不遗漏要求后声称全部完成。保持原分析的要求、观察、关系、时间和判定，不借翻译改变分析内容。

## 5. 冲突、恢复与交付

失败或结果不明时先回读，按 MCP 当前返回重新获取上下文并处理；不猜字段、伪造定位、删除要求或覆盖源版来换取成功。工具缺失或仍无法完成时保留工作记录，明确实际保存内容与未完成项。

回读核对完成后报告源语言、实际完成的目标语言与内容，以及同一案例入口。保存仅更新编辑稿，不将既有发布状态当作本次译文已发布。
