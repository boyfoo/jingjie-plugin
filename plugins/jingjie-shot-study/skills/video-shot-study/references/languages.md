# 源版语言与可选翻译

拉片与反推共用本流程。先按真实原语言保存并核对源版，再按用户选择补充译文。中文交流或中文报告要求不改变作者原文语言。

## 1. 先确认源版语言

先取得实际作者提示词并核实主要正文语言，不从帖文介绍、下载简介或交流语言推断。新案例按真实原语言保存源版；已有明确源版选择沿用，已有案例先读取语言与资料，不擅自改 `sourceLanguage`。仅在原语言不明、混合而无法判断，或与既有案例冲突需要澄清时询问；无作者原文的反推任务按用户制作要求确定语言。

涉及镜界时先读取 jingjie://submission-guide，语言范围与保存方式以当前 MCP 说明为准。已有案例源版与作者原文语言不同时，先回读原文及已有译文，保留各版本，不自动改换。

## 2. 先完成并核对源版

新生成的标题、简介、逐镜分析、人物说明、深入对应说明，以及反推提示词和制作说明统一使用源版语言；作者原文、台词和其他直接引文不改写。

只完成本次已授权工作，不为翻译补写未授权内容。已授权保存时按 [jingjie.md](jingjie.md) 将正文保存到同一案例的正确语言版本，并回读全文核对实际语言与内容；完整拉片须包含可完成的深入对应。源版工作全部完成后，再进入目标语言选择。

## 3. 完成后再选择目标语言

源版保存并回读后，询问是否翻译；目标语言从服务端当前可选语言中列出并排除源语言，允许多选或跳过。已有明确目标直接沿用，不重复问；未答复就等待，拒绝或跳过后不再追问。不把拉片或保存授权当作翻译授权。

仅本地交付按用户选定的目标语言翻译，不依赖镜界语言列表，也不自动创建案例或上传素材。

## 4. 按目标语言和模块保存译文

通过 jingjie_get_translation_context 获取本次目标语言的完整源内容、已有译文和保存要求；参数与校验规则以当前 MCP 说明和返回为准。

自由补充标签的显示名也按用户选定的目标语言翻译，保存方式以当前翻译上下文为准；原标签和固定分类值保持不变。

结合全文语义完成已授权内容的翻译，保留条件、否定、程度和引用关系，不以摘要代替全文，不新增创作要求。调用 jingjie_save_translation 将译文保存到同一案例的对应目标语言，保留源版和已有有效译文，不改媒体、既有时间或分析结论，不自动发布。

保存后分别回读源版与目标版全文，核对实际语言、全局条件、前后文、各时间段及本次涉及的深入对应与文字锚点；不能只凭 `current` 或保存成功判断完成。

### 4.1 深入分析译文的完整对应

从翻译上下文一次取得完整源版深入对应分析 `prompt_alignment`、原文全文、既有文字对应和时间依据，结合已有目标提示词，在同一翻译阶段完成说明与对应。AI 负责语义核对；结构、覆盖完整性与版本检查由 MCP 执行，不增加用户逐条审核，也不重新分析视频。

需要且已获授权修改目标提示词时，先保存提示词并回读，再重新获取实际目标文档，完成所有既有要求的目标语言对应后保存 `prompt_alignment` 译文。已有有效目标提示词直接复用。目标语可自然调序或用多个片段表达同一要求，应依据含义定位，不能机械照搬源文位置。

缺少必要上下文、目标文档或修改授权时，保留已完成源版，明确未完成范围，不编造对应、不遗漏要求后声称全部完成。保持原分析的要求、观察、关系、时间和判定，不借翻译改变分析内容。

## 5. 冲突、恢复与交付

失败或结果不明时先回读，按 MCP 当前返回重新获取上下文并处理；不猜字段、伪造定位、删除要求或覆盖源版来换取成功。工具缺失或仍无法完成时保留工作记录，明确实际保存内容与未完成项。

回读核对后报告源语言、已完成的目标语言与内容，并提供用户所需阅读语言的同一案例入口，优先使用工具返回的对应语言预览。保存仅更新编辑稿，不代表本次译文已发布。
