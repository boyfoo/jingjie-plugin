# 逐项拆分、取证和判断

本文说明怎样拆开提示词要求、找证据并作判断。开始文字画面对照前先读本文，完成时再按第7节查漏和查错。不要据此替作者增加要求。

## 1. 拆分到能独立核验的尺度

- **先读完整提示词，边看画面边核对。** 发现一项里有几个能独立判断的要求，就继续拆。最后回到原文查漏。即使画面里没出现、难取证或难保存，原文要求也要保留。
- **能分别成败，就分别判断。** 两个要求若可能一个做到、另一个没做到，就拆开核对，即使最后结论相同。数量、颜色、位置、方向、速度等条件也要检查；只把它们留在引文里，不算已经核对。不能因为原句读起来连贯，就把不同要求合成一个结论。
- **保留上下文，别拆成孤立词。** 每项都应说明是谁、什么属性或动作、在哪个范围内核对。原文出现新人物或物件时，不要只摘动作而漏掉它们的要求。同一主体已经明确时可沿用上下文，不必每句话都重复判断它是否存在。不按字数、词性或条目数量拆分。
- **不同属性分开，同一属性的程度一起判断。** “推近”和“缓慢”可以分别核对；“十分疲惫”则是一个疲惫程度目标，不要再造出“有一点疲惫”等较弱要求来增加匹配项。数量、明确阈值和“全程”等范围要求都要保留，不能删掉限定让原要求更容易满足。
- **关系也要单独判断。** 两个动作都出现，不代表先后、同时、位置或因果关系就正确。若关系可能独立失败，就另作判断。确认涉及的是同一人物、对象和事件，不能拿别处动作代替；“全程”要求也不能只查到一小段成立就算通过。
- **原文与解释分开。** 按原文顺序整理要求，引文保留原字句。分析说明可以补清省略的主体或要检查的属性，但不能冒充作者原文。每项引用按[第1.1节](#11-上下文与标注引用分别处理)选取，不用扩大引用掩盖遗漏，也不替作者增加要求。
- **重复要求合并，范围不同的分别判断。** 同一要求的同义表达或中外文重复不必反复建项，但要保留各处出处。同一要求有多处证据，也不因此拆成多项；对象、阶段或触发条件不同则分别核对。一项可对应多个镜头，不按镜头数强行拆分。

具体拆法与失败情形见[拆分与查漏示例](segmentation-examples.md)。示例的状态来自各自给定的假设证据，不可直接套用到待分析视频。

### 1.1 上下文与标注引用分别处理

**要求拆分和引用范围要分开检查，不能以为要求分了项，引用就自然选准了。** 可以问自己：**这一项里还有能分别成败的要求吗？引文有没有多选本项不需要的其他要求？** 结合完整上下文查看实际选中的文字，不只看条目名称或整段摘录。

- **读完整段，单独选引用。** 完整提示词、作者时间段和上下文摘录照常保留。给具体要求标注引用时，另外选出真正表达本项意思的文字。**要求拆细后，引用也要跟着细化，不能给每个小项都套上同一整段**。
- **把必要条件带全。** **保留本项所需的主体、对象、否定、数量、程度、条件，以及“全程”“每次”和先后顺序**。这些信息可由上下文说明和多个真实片段一起表达。共用的谓语或限定可以重复引用；分散的文字分别选取，不把中间无关要求也圈进去，不在引文中补字或加入省略号。
- **按意思决定引多长。** **以准确表达本项为准，必要时引用整句或跨句片段**。不能只因几项都在同一时间段，就让它们共用整段引用。也不设字数上限，不为缩短引用删掉条件或丢掉对象。
- **同一个词，确认选对了哪一处。** 例如要查装甲的红色，就不能选到眼睛的红色。不同要求都引用同一大段，或引文混进了邻项动作时，逐项重新选取。**必要的上下文允许重叠**，不必为了让所有引用互不重叠而改写原文或改变判断。

## 2. 按任务选择分析角度

**以下是参考角度，可按视频和任务选择、补充，不要求逐项使用。**

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 可见主体及区分特征；现实身份需来源支持 |
| 外观与结构 | 服饰、形状、配件与部件；遮挡或低清处保留限制 |
| 场景与环境 | 场所、背景物及变化；具体地点名称需来源支持 |
| 动作与状态变化 | 起始、过程、结束；单帧不能证明方向或完成 |
| 表演与情绪 | 表情、姿态与节奏；情绪作为解释 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及其变化 |
| 光线 | 受光面、阴影、高光与可见光源，区分方向推测与来源 |
| 构图 | 画内位置、尺度、留白及主体与环境关系 |
| 机位与视角 | 景别、俯仰角与观察方向，区分主体移动 |
| 运镜 | 视点、透视、背景视差与画框，区分主体运动和缩放 |
| 焦点与光学表现 | 清晰区域、焦点、景深与畸变；精确参数需可靠资料 |
| 色彩与美术风格 | 颜色关系与设计语言，按作品风格目标判断 |
| 材质与物理表现 | 反射、透明、形变、碰撞与流体，按写实或风格化目标判断 |
| 时序与节奏 | 持续时间、快慢、停顿、重复及事件顺序 |
| 剪辑与转场 | 实际切点与衔接，无剪切时不强拆 |
| 声音 | 按[声音规则](../SKILL.md#3-逐镜分析)记为无法判断 |
| 图形与合成 | 图形、特效与实景的配合及整体效果 |
| 叙事与信息传达 | 事件、因果线索与揭示顺序，区分明确画面和解释 |
| 连续性与一致性 | 跨片段的身份、外观、空间、动作和状态 |
| 教学与操作流程 | 可见步骤、状态与操作结果 |
| 音画对应 | 按[声音规则](../SKILL.md#3-逐镜分析)记为无法判断 |

每项说清：**原文怎么写、本项要核对什么、视频实际怎样、证据在哪、判断及理由是什么**。上下文和证据可以共用，简单项简写，关键或有歧义的要求展开说明。不强制固定报告版式，也不另造保存字段；缺少证据时说明缺口，不编造位置。

可以进一步解释手法怎样起作用、偏差有什么影响，以及多项之间如何配合或相互抵消。综合分析不能取代逐项结论。风格和情绪可以有多种实现方式，不把自己偏好的手法变成作者必须做到的条件。原文没要求但值得学习的特点可另作观察；推测原因时说明依据和不确定之处。

## 3. 证据先于判断

1. 沿用已核实的同版媒体与时间基准，先了解待分析范围，再补查关键过程；切点只帮助定位，不限制按事件或状态组织观察。
2. 静态属性看清晰帧，动态要求看前后过程。按时间排列、密度足够且实际看过的真实帧，可以支持过程判断和大致定位。**小图看不清，先按[补查方法](inspection.md#分层给图与补证)看清再判断。** 不能只凭单帧或稀疏首尾帧补出过程，也不因没有实时播放就否定已看清的序列证据。说明采用的观察方式；文件技术参数查媒体信息。
3. 动态证据记录动作实际发生的区间，不直接套用作者预期时间、整个镜头的起止或单帧时刻，也不按比例整体缩放。动作不连续就分段记录。只能确定大致边界时标为近似；需要精确时间再查相邻帧和时间戳。视频变速、剪裁、循环或换版本后，重新核对位置。
4. 证据要能定位到具体素材、时刻和对象，并说明有关关系。不能把一处成立说成全程成立；要判断持续设定，就查到相应范围。清晰静帧也可以直接显示某项要求被违反。
5. 分清实际看到的事实、自己的解释和有来源支持的作者意图。例如“有窗户”“脸被照亮”“光从窗户来”是三件事，不能自动互相证明。物件入画不代表完成了指定动作，抽样没发现问题也不代表全程都满足要求。器材、模型、现实身份和精确参数同样不能只凭观感断言。
6. 保存所需字段和关联遵循[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)；接口不能表达真实含义时，不靠改变要求范围或编造反例通过校验。

声音按[主文第3节](../SKILL.md#3-逐镜分析)记为无法判断。**画面和声音能分开判断的，就分开；画面结论照常给。**

## 4. 判断实现情况及其边界

各项独立判断，不套用整句、整镜、邻项或某一片段的结论。

### 4.1 明确本项核验什么

- **在判断什么？** **文件尺寸、帧率、时长等技术参数查媒体信息；画面中的近似身高、机位高度等视觉描述，按可见比例和视角判断。** 例如“约2.1米”“儿童高度”不额外要求标尺或校准记录。只有原文明示的精确实测值、真实身份、器材、生成设置或制作工艺，才需要相应证据。已有过程能证明慢动作观感时，不因缺少后期变速资料就降级；也不要求虚构特效提供现实物理证明。若要求精确符合指定参考，仍须拿到那份参考。
- **在哪个范围成立？** 分清对象、阶段、一次／多次／全程，以及动作是必须发生，还是只在某个条件下发生。“全程保持”不代表每个细节都须每帧无遮挡，要结合实际可见内容和连续性判断。但原文明示必须持续可见或接触清楚时，遮挡就可能是不符合要求的证据。
- **用什么标准判断？** 数量、阈值和精确要求按原文。标称时长、速度、情绪和风格结合上下文解释，并说明实际差异。相同条件下保持同一标准，不因别项成败改变宽严，也不自设通用容差。确实存在会改变结论、又无法确定的歧义时才记待核；已经能判断的内容继续处理。例如叙事里的“无伤逃脱”，不必额外索要医学证明。

按第1节拆开独立内容，同时说清涉及的对象、事件和条件。必需的前置动作缺失，可能使整条指定动作关系失败；位置或颜色错误则不自动否定已经成立的动作及先后顺序。后续动作和其他属性仍按各自证据判断；关系所依赖的事件还不清楚时，也要说明这对关系判断的影响。

### 4.2 汇总本项的支持、反例与缺口

先记录看到了什么、这些画面能说明本项的哪一部分，再选择状态。人物或道具出现，不代表动作和关系已经成立；多项共用证据时，也要分别检查它具体支持什么。只有会影响本项结论的缺失才算关键缺口，不把其他项的未知或笼统免责声明当成本项不足。

分段看完后，汇总相关记录，再判断全片要求。不能沿用半片结论，也不能只写“另见前半”就算核对过。某个不可再分的要求只在局部有支持时，可以保留这部分事实，但不能据此推断没查过的范围。

### 4.3 按证据选择状态

选择状态时，先看有没有可靠反例，再按本项要求和证据判断。各状态的用法如下：

| 顺序与判断 | 适用情况 | 说明重点 |
|---|---|---|
| 1. 失配 | 已有可靠证据直接违反本项要求，或充分检查后确认必需内容缺失 | 写清具体反例。“全程／每次”要求出现一个可靠反例就已失败；其他未查范围不撤销这个反例，但条件范围之外的事件不能算反例 |
| 2. 不适用 | 原文只要求在某个条件下响应，已确认条件没发生，且原文没有另行要求它必须发生，也没有违反条件的反例 | 必需事件没出现、先后顺序错误或条件是否发生还未知，都不能用“不适用”代替 |
| 3. 待核／无法判断（unverified） | 现有证据既无法确认本项任何一部分，也没有足以判定失配的反例。声音项也用此状态 | 说明缺什么证据，或哪处歧义影响判断。声音项用[主文固定原因](../SKILL.md#3-逐镜分析) |
| 4. 已实现 | 对象、条件、关系和要求范围都有足够证据支持 | 按本项原意判断，不扩大到没查过的范围，也不追索原文没要求的证明 |
| 5. 部分匹配（partial） | 已拆开独立要求。本项有直接证据支持一部分，能确认只做到这个程度，或其余部分尚未看清。已有证据明确违反本项要求时判失配 | 指出哪段画面支持哪一部分，分清已看到的不足和仍无法确认的内容 |

**先确认支持的是本项本身。** 看见人物戴手套，能证明“戴手套”，手套的颜色另看。原文明定三次，完整过程只有两次，数量失配。

“开门后灯才亮”中，灯在开门前亮起已违反时序，即使门后来未开也判失配；“如果门打开，就亮灯”且未另行要求开门，在确认门未开、无反例时才不适用。

## 5. 处理否定要求

- 肯定、否定和条件表达不改变所需证据类型：禁字幕仍看文字，禁闪烁仍查变化，无穿模仍看接触过程。
- “全程／每次”等要求的反例按第4节处理。**按要查的现象选检查方法，不必一律逐帧看完；也不能只因有未查帧，就把所有否定项都记待核。** 快闪文字、瞬时穿模和接触瞬间容易漏看，须加密查看相关片段。声音禁令按[声音规则](../SKILL.md#3-逐镜分析)处理。
- 说明实际检查了哪些范围、是否足以回答本项，不只凭“检测器没报警”作结论，也不把局部没见到扩大为全片不存在。若检查已足够，就按证据判断，不继续追索与结论无关的理论可能性。

## 6. 适配不同视频

- 真人、纪录与广告：可见外观不自动证明现实身份、历史真实性、性能或认证，相关主张需独立来源。
- 动画、游戏与特效：遵循作品的风格与世界规则；没有写实要求时，不将夸张重力、形变或材质直接当错。
- 教程、录屏、访谈及配音：围绕任务要求看操作和结果；声音按[主文第3节](../SKILL.md#3-逐镜分析)处理。
- 无剪切、延时、循环：按事件、状态和实际时间观察，留意变速与重复帧，不强套镜头数。

## 7. 完成前检查

这些检查可以穿插在分析过程中。**要求有没有拆好、引用有没有选准，要分别核对。** 尚未解决的问题留在工作记录里，不要求用户逐项审核，也不默认增加一份固定格式报告。

1. **有没有漏拆？** 从完整原文逐句检查，包括前文、分时内容和末尾约束。每项是否还捆着能分别成败的属性、动作或关系？人物、对象和条件是否各有判断？连接文字不用单独建项，否定、数量、程度和先后关系不能略过。
2. **有没有漏判？** 特别查看尚未引用的文字和引用片段之间的内容，确认每个要求都有实际表现、判断和理由，或已对应到同一个重复要求。相应的画面支持本项哪些内容、还有什么没看清，都要说清，并给出判断。
3. **证据或判断有没有套错？** 检查是不是同一人物、对象和事件，证据是否支持本项及其范围。尤其检查部分匹配有哪段画面支持，还差什么或哪里没看清，以及是否已有违反“全程／每次”的反例。不要先按结论生成“支持／反驳”关联，再拿这个关联证明结论。理由重复、邻项套同一结论或直接合并分段状态时，回到原文和证据重看受影响项；同类状态多本身不算错误，不为凑比例改判。动作实际时间与作者预期时间分开记录。字段与回读见[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)。
4. **引用有没有选准？** **逐项看“本项要查什么、实际选了哪些文字、画面证据是否对应”**。检查有没有顺带圈入邻项要求，重复词是否选对位置，缩短引用后是否丢掉否定、数量、“全程”或先后条件。**文字和位置完全对得上，也不代表引用范围选得合适**。
5. **译文有没有变意？** 分析说明使用已确认的源语言，作者引文保留原字句。源版查漏和引用核对完成后，按[语言流程](languages.md)处理已授权目标语言。逐项检查意思、对象、条件和实际引用是否对应，原判断、关联及时间是否仍适用。源版从未列出的要求，不会因为翻译了其他项就自动补上；**只重新计算译文位置，也解决不了整段引用过宽的问题**。
6. **分析完成与保存成功，分清了吗？** 结构合法、版本有效、译文齐全和保存成功，各自只能证明相应操作完成。没有逐句反查原文，就不能说“全文无遗漏”；只确认文字位置或保存状态，也不能说已经核对过引用范围。报告实际采用的观察方式和未完成部分。需要统计时再说明分母与范围，不用数量证明分析质量。

### 常见遗漏为什么发生，怎样阻止

| 错误做法 | 产生的错误 | 必须补上的检查 |
|---|---|---|
| 只摘动作，默认人物和对象可以沿用 | 新人物、物件及相关条件被漏掉 | 对照原文检查是谁、对什么做、条件是什么，尤其留意对象切换 |
| 属性、动作和关系共用一个状态 | 已实现内容被另一项失败或未知拖成 partial | 按独立成败重审要求，包括引用中已保留的限定 |
