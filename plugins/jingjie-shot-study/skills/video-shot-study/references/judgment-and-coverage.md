# 逐项拆分、取证和判断

本文说明怎样拆开提示词要求、找证据并作判断。开始文字画面对照前先读本文，完成时再按第7节查漏和查错。不要据此替作者增加要求。

## 1. 拆成能单独判断的要求

- **先读完整提示词，边看画面边核对。** 发现一项里有几个能独立判断的要求，就继续拆。最后回到原文查漏。即使画面里没出现、难取证或难保存，原文要求也要保留。
- **可能一个做到、另一个没做到，就分开判断。** 即使最后结论相同，也要分别核对。数量、颜色、位置、方向、速度等条件也要检查；只把它们留在引文里，不算已经核对。不能因为原句读起来连贯，就把不同要求合成一个结论。
- **保留上下文，别拆成孤立词。** 每项都应说明是谁、什么属性或动作、在哪个范围内核对。原文出现新人物或物件时，不要只摘动作而漏掉它们的要求。同一主体已经明确时可沿用上下文，不必每句话都重复判断它是否存在。不按字数、词性或条目数量拆分。
- **不同属性分开，同一属性的程度一起判断。** 数量、写明的数值和“全程”等范围要求都要保留，不能删掉这些限定让原要求更容易满足。
- **关系也要单独判断。** 两个动作都出现，先后、同时、位置或因果关系仍可能不对，要单独核对。确认涉及的是同一人物、对象和事件，不能拿别处动作代替。
- **原文与解释分开。** 按原文顺序整理要求，引文保留原字句。分析说明可以补清省略的主体或要检查的属性，但不能冒充作者原文。每项引用按[第1.1节](#11-上下文与标注引用分别处理)选取，不用扩大引用掩盖遗漏。
- **重复要求合并，范围不同的分别判断。** 同一要求换了说法或语言，不必反复建项，但要保留每处原文位置。同一要求有多处证据，也不因此拆成多项；对象、阶段或触发条件不同则分别核对。一项可对应多个镜头，不按镜头数强行拆分。

具体拆法与失败情形见[拆分与查漏示例](segmentation-examples.md)。示例的状态来自各自给定的假设证据，不可直接套用到待分析视频。

### 1.1 上下文与标注引用分别处理

**要求拆分和引用范围要分开检查，不能以为要求分了项，引用就自然选准了。** 可以问自己：**这一项里还有可能一个做到、另一个没做到的要求吗？引文有没有多选本项不需要的其他要求？** 结合完整上下文查看实际选中的文字，不只看条目名称或整段摘录。

- **读完整段，单独选引用。** 完整提示词、作者时间段和上下文摘录照常保留。给具体要求标注引用时，另外选出真正表达本项意思的文字。**要求拆细后，引用也要跟着细化，不能给每个小项都套上同一整段**。
- **把必要条件带全。** **保留本项所需的主体、对象、否定、数量、程度、条件，以及“全程”“每次”和先后顺序**。可用上下文说明和多处原文引用，把这些信息交代清楚。几项共用的词句可以重复引用；分散的文字分别选取，不把中间无关要求也圈进去，不在引文中补字或加入省略号。
- **按意思决定引多长。** **以准确表达本项为准，必要时引用整句或跨句片段**。不能只因几项都在同一时间段，就让它们共用整段引用。也不设字数上限，不为缩短引用删掉条件或丢掉对象。
- **同一个词，确认选对了哪一处。** 例如要查装甲的红色，就不能选到眼睛的红色。不同要求都引用同一大段，或引文混进了邻项动作时，逐项重新选取。**必要的上下文允许重叠**，不必为了让所有引用互不重叠而改写原文或改变判断。

## 2. 按任务选择分析角度

**以下是参考角度，可按视频和任务选择、补充，不要求逐项使用。**

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 视频里的角色或物件是否符合提示词或指定参考 |
| 外观与结构 | 服饰、形状、配件与部件，按实际可见内容核对 |
| 场景与环境 | 视频里的地点、背景和变化，是否符合指定场景 |
| 动作与状态变化 | 起始、过程、结束；单帧不能证明方向或完成 |
| 表演与情绪 | 根据表情、姿态和节奏，说明人物表现出的情绪 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及其变化 |
| 光线 | 根据受光面、阴影、高光和可见光源判断光照方向；没有依据，不断定具体光源 |
| 构图 | 画内位置、尺度、留白及主体与环境关系 |
| 机位与视角 | 看景别、俯仰角和观察方向；主体在动，不一定是机位在动 |
| 运镜 | 看视点、透视、背景视差和画框怎么变，分清是摄影机移动、主体移动，还是画面缩放 |
| 焦点与光学表现 | 清晰区域、焦点、景深与畸变等可见效果 |
| 色彩与美术风格 | 颜色关系与设计语言，按作品风格目标判断 |
| 材质与物理表现 | 反射、透明、形变、碰撞与流体，按写实或风格化目标判断 |
| 时序与节奏 | 持续时间、快慢、停顿、重复及事件顺序 |
| 剪辑与转场 | 实际切点与衔接，无剪切时不强拆 |
| 声音 | 按[声音规则](../SKILL.md#3-逐镜分析)记为无法判断 |
| 图形与合成 | 图形、特效与实景的配合及整体效果 |
| 叙事与信息传达 | 事件、因果线索与揭示顺序，区分明确画面和解释 |
| 连续性与一致性 | 跨片段的身份、外观、空间、动作和状态 |
| 教学与操作流程 | 可见步骤、状态与操作结果 |
| 音画对应 | 按[声音规则](../SKILL.md#3-逐镜分析)记为无法判断 |

每项说清：**原文怎么写、本项要核对什么、视频实际怎样、证据在哪、判断及理由是什么**。上下文和证据可以共用，简单项简写，关键或有歧义的要求展开说明。不强制固定报告版式，也不另造保存字段；缺少证据时说清缺什么，不编造位置。

可以进一步解释手法怎样起作用、偏差有什么影响，以及多项之间如何配合或相互抵消。综合分析不能取代逐项结论。风格和情绪可以有多种实现方式，不把自己偏好的手法变成作者必须做到的条件。原文没要求但值得学习的特点可另作观察；推测原因时说明依据和不确定之处。

## 3. 证据先于判断

1. 沿用已核实的同一版素材和时间基准，先了解要分析的范围，再补看关键过程。切点用于定位，也可以按事件或状态记录观察，不必只按镜头划分。
2. 静态特征可以用看清的一帧作证据，动作和变化要看前后过程。按时间排列、足以看清变化，而且实际看过的原视频帧，也能用来判断过程和大致时间。**小图看不清，先按[补查方法](inspection.md#分层给图与补证)看清再判断。** 不能只凭单帧或稀疏首尾帧补出过程；一组按时间排列的帧已经把过程展示清楚时，就可以据此判断，不要求必须实时播放。说明采用的观察方式。
3. 动作和变化的证据记录实际发生的区间，不直接套用作者预期时间、整个镜头的起止或单帧时刻，也不能把所有时间按比例缩放。不连续发生就分段记录。只能确定大致边界时标为近似；需要精确时间再查相邻帧和时间戳。视频变速、剪裁、循环或换版本后，重新核对位置。
4. 证据要指明是哪份素材、哪个时刻、哪个对象；涉及关系的，也要说清。提示词要求一直做到的，不能只看其中一小段。清晰的单帧也可以证明某项要求没做到。
5. 分清实际看到的事实、自己的解释和有来源支持的作者意图。例如“有窗户”“脸被照亮”“光从窗户来”是三件事，不能自动互相证明。物件入画不代表完成了指定动作，抽样没发现问题也不代表全程都满足要求。器材、模型、现实身份和精确参数同样不能只凭观感断言。
6. 保存所需字段和关联遵循[镜界第8节](jingjie.md#8-深入分析的时间与保存后检查)。如果接口无法准确记录实际情况，不能为了通过校验而改变要求范围或编造反例。

声音按[主文第3节](../SKILL.md#3-逐镜分析)记为无法判断。**画面和声音能分开判断的，就分开；画面结论照常给。**

## 4. 判断实现情况及其边界

各项独立判断，不套用整句、整镜或邻项的结论。

### 4.1 先弄清要检查什么

- **在判断什么？** **文件尺寸、帧率、时长等技术参数查媒体信息；画面中的近似身高、机位高度等视觉描述，按可见比例和视角判断。** 例如“约2.1米”“儿童高度”不额外要求标尺或校准记录。提示词提到的人物、地点、器材和工艺，先看视频有没有做出要求的样子。用户另外要求查真实身份、生成设置或制作过程时，再找相应资料。不要求虚构特效提供现实物理证明。若要求精确符合指定参考，仍须拿到那份参考。
- **要看哪一段？** 看清要求的是谁、哪一段，以及出现一次、多次还是全程保持。提示词没要求一直或反复出现，在对应场景里表现出来就可以判符合。“全程保持”可以结合前后画面判断，不必每一帧都看清所有细节；但写了必须一直清楚可见，就要检查是否一直看得清。
- **怎么判断符合？** 数量、方向、颜色和写明的数值，按提示词检查；时长类要求的绝对偏差 ≤0.5 秒，视为符合，实测数值照常保留。缓慢、疲惫、壮观等，就看视频给人的感觉是否符合，不自己加一个必须达到的程度。同样的要求用同样的标准，不因为其他项做得好坏就放宽或收紧。

按第1节拆分，说明涉及的对象、事件和条件。缺了必须先做的动作，要求的动作关系可能就不成立；位置或颜色不对，不代表动作本身或先后顺序也不对。后续动作和其他属性仍按各自证据判断。相关事件还没弄清楚时，要说明这会怎样影响关系的判断。

### 4.2 整理看到了什么、还有什么没看清

先记录看到了什么、这些画面能说明本项的哪一部分，再选择状态。几项共用画面时，也要分别说清这些画面能证明什么。缺少的内容确实会影响本项结论，才算本项证据不足。其他项没看清，或只是笼统地说证据不够，都不能代替本项的具体理由。

同一要求涉及几段视频时，把各段的观察和证据放在一起，不只写“另见前半”。还要不要看其他片段，取决于提示词要求出现几次、持续多久。

### 4.3 按证据选择状态

还没看清的先补看。按成片是否表现出本项要求判断，不能猜被挡住或切走后发生了什么。各状态的用法如下：

| 顺序与判断 | 适用情况 | 说明重点 |
|---|---|---|
| 1. 失配 | 已经看清成片不符合本项要求，或看清相关过程后，仍未表现出要求的内容或效果 | 写清哪里不符合、什么未表现出来，不把“未表现出”写成“实际不存在”。要求“全程／每次”，只要有一次没做到就不符合；其他次符合也不能抵消。只检查这项要求对应的人物、场景和时间 |
| 2. 无法判断（unverified） | 仅用于声音相关要求 | 用[主文固定原因](../SKILL.md#3-逐镜分析) |
| 3. 已实现 | 成片已表现出本项要求，包括多帧连起来才能看出的表现 | 写清哪些画面能证明；按提示词判断，不自己多加条件 |

## 5. 处理否定要求

- 要求没有某种现象，也要找对应的证据：没有字幕就查画面文字，没有闪烁就查变化，没有穿模就查接触过程。
- “全程／每次”等要求的反例按第4节处理。**按要查的现象选检查方法，不必一律逐帧看完。** 快闪文字、瞬时穿模和接触瞬间容易漏看，须加密查看相关片段。禁止某种声音的要求按[声音规则](../SKILL.md#3-逐镜分析)处理。
- 说清检查过哪些范围、能不能据此判断本项，不只凭“检测器没报警”作结论。某一段没见到，不代表全片都没有。若检查已足够，就按证据判断，不用再猜与结论无关的可能性。

## 6. 适配不同视频

- 真人、纪录与广告：按成片核对提示词要求；本次任务另需核验现实身份、历史真实性、性能或认证时，查独立来源。
- 动画、游戏与特效：遵循作品的风格与世界规则；没有写实要求时，不将夸张重力、形变或材质直接当错。
- 教程、录屏、访谈及配音：围绕任务要求看操作和结果；声音按[主文第3节](../SKILL.md#3-逐镜分析)处理。
- 无剪切、延时、循环：按事件、状态和实际时间观察，留意变速与重复帧，不强套镜头数。

## 7. 完成前检查

这些检查可以穿插在分析过程中。**要求有没有拆好、引用有没有选准，要分别核对。** 尚未解决的问题留在工作记录里，不要求用户逐项审核，也不默认增加一份固定格式报告。

1. **有没有漏拆？** 从完整原文逐句检查，包括前文、分时内容和末尾约束。一项里是否还放着可以分别判断的属性、动作或关系？人物、对象和条件是否各有判断？只起连接作用的词句不用单独建项，否定、数量、程度和先后关系不能略过。
2. **有没有漏判？** 特别查看尚未引用的文字和引用片段之间的内容，确认每个要求都有实际表现、判断和理由；重复的要求可以归在同一项。相应的画面支持本项哪些内容、还有什么没看清，都要说清。
3. **证据或判断有没有套错？** 检查是不是同一人物、对象和事件，证据是否支持本项及其范围，尤其留意是否已有违反“全程／每次”的反例。不要先按结论生成“支持／反驳”关联，再拿这个关联证明结论。发现理由重复、把旁边一项的结论套过来，或直接合并各段的状态时，重新对照原文和证据检查这些项。很多项判成同一状态并不算错，不为凑比例改判。动作实际时间与作者预期时间分开记录。字段与回读见[镜界第8节](jingjie.md#8-深入分析的时间与保存后检查)。
4. **引用有没有选准？** **逐项看“本项要查什么、实际选了哪些文字、画面证据是否对应”**。检查有没有顺带圈入邻项要求，重复词是否选对位置，缩短引用后是否丢掉否定、数量、“全程”或先后条件。**文字和位置完全对得上，也不代表引用范围选得合适**。
5. **译文有没有变意？** 分析说明使用已确认的源语言，作者引文保留原字句。源版查漏和引用核对完成后，按[语言流程](languages.md)处理已授权目标语言。逐项检查意思、对象、条件和实际引用是否对应，原判断、关联及时间是否仍适用。源版从未列出的要求，不会因为翻译了其他项就自动补上；**只重新计算译文位置，也解决不了整段引用过宽的问题**。
6. **分析完成与保存成功，分清了吗？** 结构合法、版本有效、译文齐全和保存成功，都不能说明分析已经做全。没有逐句对照原文，就不能说“全文无遗漏”；只确认文字位置或保存状态，也不能说已经核对过引用范围。报告实际采用的观察方式和未完成部分。需要统计时再说明统计了哪些项、按什么总数计算，不用数量证明分析质量。

发现一处遗漏后，还要在本次分析范围内检查同类问题，别只补这一处。
