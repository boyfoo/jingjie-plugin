# 语义覆盖、证据与判定

用于拆分要求、选择证据和处理判定边界。进行文字与画面对照时，在形成清单前读取本方法，完成时再执行第7节；不据此替作者添加要求或固定输出结构。

## 1. 拆分到能独立核验的尺度

- **先读全文，再逐项核验。** 从原文梳理本次范围的全部要求，再查视频证据。核验中发现复合要求可继续拆分，不能因画面没呈现、难以取证或接口不便表达而删除要求。
- **独立成败优先。** 同一语境下，两个要求可能一个成立、另一个不成立，就分别建项并判断，即使最终结论相同也不合并独立要求；同一要求的重复表达另按去重规则处理。属性、动作、结果以及数量、颜色、位置、方向、速度等限定都要检查；仅把限定保留在引用里不算已核验。自然语义用于保留对象和上下文，不能成为合并独立要求的理由。
- **保留必要语境，不拆成孤立词。** 每项都要能说明核验的是谁、什么属性或事件、在哪个范围成立。首次及切换的主体不得漏掉；后续沿用可回查的承接，同一主体不因每句出现就重复建立存在项。拆到继续细分已不产生独立判断、反而割裂含义时停止，不按字数、词性或条目数量拆分。
- **区分独立维度与同一属性的程度。** “推近”与“速度缓慢”是运动方式和速度两个维度，可分别核验；“十分疲惫”只给出一个疲惫程度目标，不额外造出“有一点疲惫”等弱化要求来增加匹配项。程度词随其属性核验，数量、明确阈值和全称范围也须完整保留；不能靠拆掉限定把原要求变容易。
- **关系单独核验。** 当主体、属性和动作都成立而关系仍可能失败时，该关系必须有独立判断，例如先后、同时、空间与因果。核对同一参与者、对象和事件，不能以别处的动作代证；否定、条件和全称范围始终随对应要求保留，不能把“全程”拆掉后只判断局部成立。
- **原文引用与核验含义分开。** 要求清单按原文顺序整理，引用保留真实文字。说明可补足省略的主体或明确要检查的属性，但不得把说明冒充原文。多个独立要求可以共享必要的原文片段，一项关系也可引用多个片段；多片段分别列出，不将补写或省略号混入原文片段。不能扩大引用掩盖漏析，也不能为拆分给作者增加要求。
- **去重并明确适用范围。** 同义、中外文重复和多次证据不重复建项，保留各处原文对应；不同对象、阶段或触发条件分别判断。全局要求关联其实际适用范围，阶段变化按原文条件处理，不按镜头数重复拆项或强制一项只对应一个镜头。

具体拆法与失败情形见[拆分与查漏示例](segmentation-examples.md)。示例的状态来自各自给定的假设证据，不可直接套用到待分析视频。

## 2. 按任务选择分析角度

以下用于检查原文要求是否有遗漏，不是固定输出模板。选用原文或任务实际涉及的角度；不能跳过难判断的原文要求，也不据此增加原文未要求的验收条件。

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 可见主体及区分特征；现实身份需来源支持 |
| 外观与结构 | 服饰、形状、配件与部件；遮挡或低清处保留限制 |
| 场景与环境 | 场所、背景物及变化；具体地点名称需来源支持 |
| 动作与状态变化 | 起始、过程、结束；单帧不能证明方向或完成 |
| 表演与情绪 | 表情、姿态、节奏与声音表演；情绪作为解释 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及其变化 |
| 光线 | 受光面、阴影、高光与可见光源，区分方向推测与来源 |
| 构图 | 画内位置、尺度、留白及主体与环境关系 |
| 机位与视角 | 景别、俯仰角与观察方向，区分主体移动 |
| 运镜 | 视点、透视、背景视差与画框，区分主体运动和缩放 |
| 焦点与光学表现 | 清晰区域、焦点、景深与畸变；精确参数需可靠资料 |
| 色彩与美术风格 | 颜色关系与设计语言，按作品风格目标判断 |
| 材质与物理表现 | 反射、透明、形变、碰撞与流体，按写实或风格化目标判断 |
| 时序与节奏 | 持续时间、快慢、停顿、重复及事件顺序 |
| 剪辑与转场 | 实际切点与衔接，无剪切时不强拆 |
| 声音 | 实际试听的对白、音乐、音效、静默及声源方向 |
| 文字、图形与合成 | 屏幕文字、图层、遮挡及合成边缘，识别结果需回看 |
| 叙事与信息传达 | 事件、因果线索与揭示顺序，区分明确画面和解释 |
| 连续性与一致性 | 跨片段的身份、外观、空间、动作、状态及声音 |
| 教学与操作流程 | 可见步骤、状态、反馈与讲解对应 |
| 音画对应 | 声音与事件、口型或字幕的时间关系，分别检查两种证据 |
| 技术交付 | 文件尺寸、时长、帧率、音轨、编码等实际参数 |

每项分析应能回查五项内容：**原文依据、核验含义、实际表现、证据位置、结论及理由**。共同语境和证据可共享引用，简单明确项简写，关键、复杂或有歧义的要求展开；各项判断仍独立可回查，不另定义保存字段或固定报告版式。没有适当证据时说明缺口，不填造位置。

可结合已核验内容解释实现方式、偏差影响及跨项共同问题，说明哪些表现相互配合或抵消；综合说明不覆盖分项结论。抽象风格或情绪允许多种实现方式，结合语境和可观察表现论证，不把某种手法擅加为必需条件。原文未要求但有价值的画面特点可作为补充观察，不据此改变符合性判断；原因推断注明依据与不确定性。

## 3. 证据先于判断

1. 沿用已核实的同版媒体与时间基准，先了解待分析范围，再补查关键过程；切点只帮助定位，不限制按事件或状态组织观察。
2. 静态属性可用清晰帧；动态要求需过程证据。实际查看过、有序且对目标变化足够密集的真实帧序列可支持逐帧回看和近似定位。展示过小或关键过程跳跃时，按实际问题选用[图片呈现调整或取帧加密](inspection.md#分层给图与补证)；快动作、接触、遮挡或转场按实际需要补查。不能从单帧或稀疏首尾补造过程，也不因未实时播放抹去序列中的支持；如实注明观察方式。声音须实际试听，技术参数用媒体信息。
3. 动态支持对应实际发生的区间，不以作者预算、整镜边界、孤立帧点或整体缩放代替动作起落。不连续出现时分段保留；只确认到近似边界就标近似，精确判断再查相邻帧和时间戳。变速、剪裁、循环或换版本后重新核验位置。
4. 证据能回查到素材、时刻、对象及相关关系。一处局部支持不扩成全程成立；确认持续设定需覆盖其适用范围，清晰静帧也可提供直接反例。
5. 区分可见事实、解释与有来源的意图，不补造因果。例如窗户存在、脸受光、光来自窗户是不同主张；物件入画不能证明指定动作，抽样未发现违规不能证明全程满足否定要求。器材、模型、现实身份和精确参数也不能仅凭观感断言。
6. 保存所需字段和关联遵循[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)；接口不能表达真实含义时，不靠改变要求范围或编造反例通过校验。

## 4. 判断实现情况及其边界

按“明确含义与尺度 → 拆分独立要求 → 汇总本项证据 → 选择状态”逐项判断。父句、整镜、邻项或分段结论都不能直接充当本项结论。

### 4.1 明确本项核验什么

- **核验对象。** 成片表现按可观察效果判断，可测交付参数按媒体信息判断；原文明确要求的真实身份、器材、生成设置或制作工艺才需要相应来源证明。不能因为没有后期变速资料就降低已有过程支持的慢动作观感，也不要求虚构特效提供现实物理证明。指定参考的精确外观仍须有该参考，不能凭普通外观代证。
- **范围与条件。** 确认对象、阶段、一次／多次／全程，以及必需事件与条件前提。“全程保持”不自动等于每个细节每帧都必须无遮挡；结合实际可见内容与连续性核验，关键变化仍无法确认时保留缺口。原文明确要求持续可见或接触清晰时，遮挡本身可能构成反例。
- **判断尺度。** 明确数量、阈值和精确要求按原文；标称时长、速度、情绪与风格按完整语境解释，说明实际差异和采用的尺度。同等语境沿用同一尺度，不随其他项的成败切换宽严，也不自设通用容差。只有无法消解且会改变结论的关键歧义才记待核，说明不同理解；可独立确定的内容继续判断，不无限重复取证。证据标准应足以回答原要求，例如叙事中的“无伤逃脱”不额外要求医学证明。

按第1节拆开独立内容，必要的对象、事件与条件依赖保留在核验含义中。前置动作未发生可能使指定动作链失配，动作的位置或颜色错误则不自动否定已成立的动作与先后；后续动作、属性或背景仍独立判断。关系所需事件未核时，也须保留其对关系判断的影响。

### 4.2 汇总本项的支持、反例与缺口

先记录实际观察及其与本项要求的关系，再选择状态。人物或道具出现不自动证明动作、关系成立；共享证据须逐项核对具体支持什么。缺失信息只有影响本项结论时才构成关键缺口，不把其他项的未知或泛化免责声明当作本项不足。

主代理分段观察后，先汇总自己的相关记录，再按完整适用范围判断全局要求；不继承半片状态，也不把“另见前半”当作已完成核验。同一不可拆要求的局部支持保留在说明里，不能据此推断未查范围。

### 4.3 按证据选择状态

按下表顺序检查，每种状态都须由本项含义与证据支持：

| 顺序与判断 | 适用情况 | 说明重点 |
|---|---|---|
| 1. 失配 | 本项适用范围内已有决定性反例：直接矛盾，明确数量、阈值或时序被违反，或充分检查确认必需内容缺失 | 说明反例如何否定本项；“全程／每次”有一个可靠反例即可失配，其他未核范围不撤销反例；条件外事件不代作反例 |
| 2. 不适用 | 原文确为条件性要求，已确认适用前提未发生；原文未要求前提必须发生，也不存在违反该条件的反例 | 必需事件缺失、时序失败和前提未知均不能据此免责 |
| 3. 待核（unverified） | 尚不能定论，缺少关键过程、声音、指定参考等证据，或原文歧义仍影响判断 | 保留已知事实，说明具体缺口；未知不当失败或部分实现 |
| 4. 已实现 | 对象、条件、关系与适用范围均有足够支持 | 按已明确的核验含义判断，不扩至未查范围，不追索原文未要求的证明 |
| 5. 部分匹配（partial） | 已合理拆分，不能再分成独立要求；充分证据确认同一连续程度目标只部分实现，且没有推翻明确条件的反例 | 具体说明实现到什么程度、还差什么，以及保留为一项的理由 |

partial 不是其余状态都不便使用时的兜底。仍无法归类时，回查核验含义、拆分及证据缺口；明确要求三次而实际只有两次属于失配，不能按完成比例判 partial。不能为减少 partial 或待核强制二元判断。

“开门后灯才亮”中，灯在开门前亮起已违反时序，即使门后来未开也判失配；“如果门打开，就亮灯”且未另行要求开门，在确认门未开、无反例时才不适用。

## 5. 处理否定要求

- 肯定、否定和条件表达不改变所需证据类型：禁字幕仍看文字，禁闪烁仍查变化，无穿模仍看接触过程。
- 全称反例按第4节处理。要支持某范围内不存在某现象，须完成适合该现象的检查；稀疏帧不足以排除快闪或帧间穿模，没有字幕不证明静默。
- 未发现或检测器未报警本身不是满足证据，说明实际检查范围和检测限制，不把局部未见扩大为全片不存在。

## 6. 适配不同视频

- 真人、纪录与广告：可见外观不自动证明现实身份、历史真实性、性能或认证，相关主张需独立来源。
- 动画、游戏与特效：遵循作品的风格与世界规则；没有写实要求时，不将夸张重力、形变或材质直接当错。
- 教程、录屏、访谈及配音：分别检查可见操作/反馈、文字和实际声音；旁白声称成功不证明操作成功，字幕存在不证明音画同步。
- 无剪切、延时、循环：按事件、状态和实际时间观察，留意变速与重复帧，不强套镜头数。缺少一种模态不妨碍其他有依据的分析。

## 7. 完成前检查

按下列顺序检查，本地工作记录保留尚未解决的缺口；不要求用户逐项审核，也不默认增加一份固定格式报告。

1. **查漏拆。** 从完整原文逐句反查要求清单，覆盖全局前文、时间段与末尾约束。检查每项是否仍捆绑能独立成败的属性、动作或关系；主体和限定即使已被引用，也须有明确的判断去向。纯连接文字不另建项，否定、条件、数量、程度和时序不能略过。
2. **查漏判。** 专门读未引用文字及跨片段边界，再逐项检查是否有实际表现、结论与理由，或可回查的同义项。尚不能定论且关键缺证时记待核并说明已知与未知，不能让要求只被摘录而没有判断。完整引用、字符高亮和条目数量都不能证明完成。
3. **查错连与连带判定。** 核对证据中的主体、对象、事件和适用范围，排除别处动作或局部片段代证；核对理由是否真正支持本项状态，尤其检查 partial 的具体不足和全称反例。支持或反驳关系由观察与要求的比较确定，从已有状态机械生成的关联不能作为独立验证。发现理由模板重复、相邻项共用笼统结论或分段状态直接合并时，暂时忽略旧状态，仅按原文与证据复判受影响项；状态集中本身不证明错误，不为平衡比例改判。动态证据的实际区间与作者预算分开；时间对应未完成时明示限制。字段与回读见[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)。
4. **源版 → 译文。** 新写概括、观察与理由使用已确认的 `sourceLanguage`，作者引文及锚点原样保留。源版覆盖核对完成后，按[多语言流程](languages.md)处理已授权目标语言；逐项核对含义、主体、限定及全部目标引用，保留判定、关系与真实时间。仅把已有条目逐一翻译，无法发现源版中从未建立的要求。
5. **分别确认语义与保存结果。** 引用准确、结构合法、版本有效、译文项齐全和保存成功只验证其各自范围；分析者仍须完成前述语义覆盖与证据核对。未完成逐句反查时不得声称“全文无遗漏”。报告实际观察方式和未完成部分；仅在需要统计时说明分母与范围，不以数量或拆分细度证明分析质量。

### 常见遗漏为什么发生，怎样阻止

| 错误做法 | 产生的错误 | 必须补上的检查 |
|---|---|---|
| 只摘动作，统一假定主体可承接 | 新主体、修饰语被留在判断之外 | 对照原句主语与限定，尤其检查主体切换 |
| 属性、动作和关系共用一个状态 | 已实现内容被另一项失败或未知拖成 partial | 按独立成败重审要求，包括引用中已保留的限定 |
| 把关键证据缺失记成 partial | 混淆“部分实现”和“部分看清” | 可拆要求分别判定；不可拆且尚不能定论时保留已知支持并标明待核 |
| 只遍历已生成的要求清单 | 从未列入的要求永远不会报缺失 | 另从完整原文逐句反查，阅读未引用文字 |
| 用条目数、有效锚点或译文齐全证明完整 | 数据格式正确，但语义仍有遗漏 | 分别报告语义覆盖与结构/保存验证 |
| 发现一处后只补该处 | 相同摘取方式造成的其他遗漏仍在 | 在当前授权分析范围内检查同类问题；仅讨论规则或升级插件时不改案例 |
