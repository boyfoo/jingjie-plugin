# 语义覆盖、证据与判定

用于拆分要求、选择证据和处理判定边界。进行文字与画面对照时，在形成清单前读取本方法，完成时再执行第7节；不据此替作者添加要求或固定输出结构。

## 1. 拆分到能独立核验的尺度

- **先读完整语境，再按独立成败拆分。** 判断同句中的几项是否能分别实现或失败；能自然分开核验的属性、动作和结果分别建项。先从原文梳理所有要求，再找证据，避免只摘出已看见或容易匹配的动作。某项失败不能降低其他已实现项的判断。
- **保持自然语义片段。** 拆分到有明确视觉、声音或技术含义的尺度，不按逗号、词性或字数机械切分。“黄黑机械装甲”可保持为完整描述；“外露的黑色机械结构”是可独立核验的另一项。数量、颜色、方向、程度等限定必须留在对应要求中；需要分别判断时保留明确的修饰对象，不能只剩脱离语境的词。拆分尺度由语义决定，不以条目数或状态比例为目标。
- **沿用原文主体与承接。** 首次出现的主体和切换后的新主体必须进入相应片段；同一主体在后文被原文省略时，保留自然承接，不人为补写重复主语。“女孩穿红色风衣，戴黑色手套，站在雪地里”拆为“女孩穿红色风衣”“戴黑色手套”“站在雪地里”。承接须能明确回查到主体，不能用一句“主体承接原文”掩盖漏掉的新主体。
- **分开判断动作，保留关系要求。** 发出能量、命中、击飞可分别成立或失败；仍须核对同一发出者、受击对象、能量以及因果，别处一次击飞不能证明该攻击的结果。“红球落下后蓝球才移动”还要核验先后。关系可保留在相关要求的范围中，必要时独立核验，不能因拆开事件而丢失否定、条件、同时或先后约束。
- **保留原文及精确引用。** 分析条目按原文顺序组织，引用保留真实文字，不改写作者要求、不把人为补出的主语伪装成引文；必要时用原文多个片段共同表达一项含义。解释与引文分开，不能扩大引用至整段来掩盖实际漏析。
- 同义、中外文重复和多次证据不增加独立要求；合并同义项时仍保留各处原文对应，不能把重复出现的实质文字留成无去向。不同对象、阶段或触发条件分别核验。一项要求可涉及多个角度，无须强塞进单一类别。
- 持续设定与阶段变化分开，如“保持红色外壳”与“开灯后外壳反光”。作用范围由原文决定，不机械按“外观全局、动作局部”归类。
- 保留比较文本的来源、版本、顺序和完整原意；译文、分析概括与创作建议不覆盖原文。每个实质要求都应有分析去向，纯连接文字不必另拆。

具体拆法与失败情形见[拆分与查漏示例](segmentation-examples.md)。示例的状态来自各自给定的假设证据，不可直接套用到待分析视频。

## 2. 按任务选择分析角度

以下仅用于查漏，选用原文或任务实际涉及的角度，不要求全部覆盖或类别互斥。

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 可见主体及区分特征；现实身份需来源支持 |
| 外观与结构 | 服饰、形状、配件与部件；遮挡或低清处保留限制 |
| 场景与环境 | 场所、背景物及变化；具体地点名称需来源支持 |
| 动作与状态变化 | 起始、过程、结束；单帧不能证明方向或完成 |
| 表演与情绪 | 表情、姿态、节奏与声音表演；情绪作为解释 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及其变化 |
| 光线 | 受光面、阴影、高光与可见光源，区分方向推测与来源 |
| 构图 | 画内位置、尺度、留白及主体与环境关系 |
| 机位与视角 | 景别、俯仰角与观察方向，区分主体移动 |
| 运镜 | 视点、透视、背景视差与画框，区分主体运动和缩放 |
| 焦点与光学表现 | 清晰区域、焦点、景深与畸变；精确参数需可靠资料 |
| 色彩与美术风格 | 颜色关系与设计语言，按作品风格目标判断 |
| 材质与物理表现 | 反射、透明、形变、碰撞与流体，按写实或风格化目标判断 |
| 时序与节奏 | 持续时间、快慢、停顿、重复及事件顺序 |
| 剪辑与转场 | 实际切点与衔接，无剪切时不强拆 |
| 声音 | 实际试听的对白、音乐、音效、静默及声源方向 |
| 文字、图形与合成 | 屏幕文字、图层、遮挡及合成边缘，识别结果需回看 |
| 叙事与信息传达 | 事件、因果线索与揭示顺序，区分明确画面和解释 |
| 连续性与一致性 | 跨片段的身份、外观、空间、动作、状态及声音 |
| 教学与操作流程 | 可见步骤、状态、反馈与讲解对应 |
| 音画对应 | 声音与事件、口型或字幕的时间关系，分别检查两种证据 |
| 技术交付 | 文件尺寸、时长、帧率、音轨、编码等实际参数 |

## 3. 证据先于判断

1. 沿用已核实的同版媒体与时间基准，先了解待分析范围，再补查关键过程；切点只帮助定位，不限制按事件或状态组织观察。
2. 静态属性可用清晰帧；动态要求需过程证据。实际查看过、有序且对目标变化足够密集的真实帧序列可支持逐帧回看和近似定位，快动作、接触、遮挡或转场不足时继续加密。不能从单帧或稀疏首尾补造过程，也不因未实时播放抹去序列中的支持；如实注明观察方式。声音须实际试听，技术参数用媒体信息。
3. 动态支持对应实际发生的区间，不以作者预算、整镜边界、孤立帧点或整体缩放代替动作起落。不连续出现时分段保留；只确认到近似边界就标近似，精确判断再查相邻帧和时间戳。变速、剪裁、循环或换版本后重新核验位置。
4. 证据能回查到素材、时刻、对象及相关关系。一处局部支持不扩成全程成立；确认持续设定需覆盖其适用范围，清晰静帧也可提供直接反例。
5. 区分可见事实、解释与有来源的意图，不补造因果。例如窗户存在、脸受光、光来自窗户是不同主张；物件入画不能证明指定动作，抽样未发现违规不能证明全程满足否定要求。器材、模型、现实身份和精确参数也不能由观感反推。
6. 保存所需字段和关联遵循[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)；接口不能表达真实含义时，不靠改变要求范围或编造反例通过校验。

## 4. 判断实现情况及其边界

按要求的含义和适用范围判断，保留各子内容的证据与限制：

| 判断 | 适用情况 | 说明重点 |
|---|---|---|
| 已实现 | 对象、条件及范围均有足够支持 | 成立范围，不扩至未查部分 |
| 部分匹配（partial） | 已按独立成败合理拆分；某个完整语义要求仍只有部分实质支持，余下程度或范围未核、或有局部偏差，继续拆会割裂含义 | 说明已实现与不足，以及保留为一项的理由；不把多项独立要求混成一个 partial |
| 失配 | 有直接矛盾，或充分检查确认必须出现的内容缺失 | 具体反例与依据，不能只说“没找到” |
| 待核（unverified） | 没有适当支持或反例，如未试听、缺参考、动作全被遮挡 | 缺什么证据，不把未知当失败 |
| 不适用 | 要求的前提在当前范围确实不成立 | 前提与理由，不掩盖缺证或偏差 |

- **先核对拆分尺度：** 准备使用 partial 时，先检查是否捆绑了能独立成败的要求；若是，拆开并分别判断。不能为消灭 partial 把自然描述切成零散词语，也不能把未查清的要求强行判为匹配或失配。大量 partial 或待核应触发对拆分尺度与证据缺口的复查，不按比例调状态。
- **全称反例优先：** 明确要求“全程”“每次”成立时，一个可靠反例即可判该全称要求失配，仍保留其他片段的局部支持。拆分不能删除全称范围，也不能用 partial 回避可靠反例。
- 实质支持须落在要求的具体内容上；同一人物或道具出现、假设的因果、仅抽样未发现违规都不够。已有支持不能仅因余项未核而抹成待核，完全未查的内容也不能用 partial 掩盖。
- 持续属性、多次事件与多主体按各自范围检查，不能以一次成功替代“每次”，也不能因同义重复增加要求数量。完整检查须真正覆盖该问题所需证据，不等于文件已加载或抽帧覆盖首尾。
- 条件要求先核实触发再核对结果。“开门后灯亮”中，门未打开就不能验证条件关系；若开门本身也是必需动作，仍须单独判断，不能整句记不适用。
- 速度、程度、情绪等无量化标准时，结合原文解释依据，不擅加阈值；存在多种合理解释就保留边界。

## 5. 处理否定要求

- 肯定、否定和条件表达不改变所需证据类型：禁字幕仍看文字，禁闪烁仍查变化，无穿模仍看接触过程。
- 全称反例按第4节处理。要支持某范围内不存在某现象，须完成适合该现象的检查；稀疏帧不足以排除快闪或帧间穿模，没有字幕不证明静默。
- 未发现或检测器未报警本身不是满足证据，说明实际检查范围和检测限制，不把局部未见扩大为全片不存在。

## 6. 适配不同视频

- 真人、纪录与广告：可见外观不自动证明现实身份、历史真实性、性能或认证，相关主张需独立来源。
- 动画、游戏与特效：遵循作品的风格与世界规则；没有写实要求时，不将夸张重力、形变或材质直接当错。
- 教程、录屏、访谈及配音：分别检查可见操作/反馈、文字和实际声音；旁白声称成功不证明操作成功，字幕存在不证明音画同步。
- 无剪切、延时、循环：按事件、状态和实际时间观察，留意变速与重复帧，不强套镜头数。缺少一种模态不妨碍其他有依据的分析。

## 7. 完成前检查

按下列顺序检查，本地工作记录保留尚未解决的缺口；不要求用户逐项审核，也不默认增加一份固定格式报告。

1. **原文 → 要求。** 从本次范围的完整原文逐句反查，覆盖全局前文、时间段与末尾约束。每个实质要求须对应具体判断，或明确对应已有同义项。重点检查首次/新主体、属性、数量、方向、否定、条件、程度、时序和因果；有要求却无判断的文字必须回到拆分阶段处理。
2. **专门读未引用文字。** 查看引用范围以外的文字及跨片段边界，确认是否漏掉“一道电弧”“清晰可见地”一类主体或限定。标点、空白和纯连接文字无需独立状态；但“才”“同时”“没有”等会改变要求的词不能按连接文字略过。字符覆盖只能提示候选缺口，100%高亮或整句引用不能证明语义已分析。
3. **要求 → 证据。** 对每项反查完整含义、适用主体和范围、具体结论、真实观察与时间。确认相邻项的成功和失败没有互相拖低或代替，关系未因拆分丢失；缺证明确记待核并写明具体缺口，不能让条目无状态。动态支持须有实际区间，时间对应未完成时明示限制。字段与回读见[镜界第8节](jingjie.md#8-深入分析的时间对应与回读)。
4. **源版 → 译文。** 新写概括、观察与理由使用已确认的 `sourceLanguage`，作者引文及锚点原样保留。源版覆盖核对完成后，按[多语言流程](languages.md)处理已授权目标语言；逐项核对含义、主体、限定及全部目标引用，保留判定、关系与真实时间。仅把已有条目逐一翻译，无法发现源版中从未建立的要求。
5. **分别确认语义与保存结果。** 引用准确、结构合法、版本有效、译文项齐全和保存成功只验证其各自范围；分析者仍须完成前述语义覆盖与证据核对。未完成逐句反查时不得声称“全文无遗漏”。报告实际观察方式和未完成部分；仅在需要统计时说明分母与范围，不以数量或拆分细度证明分析质量。

### 常见遗漏为什么发生，怎样阻止

| 错误做法 | 产生的错误 | 必须补上的检查 |
|---|---|---|
| 只摘动作，统一假定主体可承接 | 新主体、修饰语被留在判断之外 | 对照原句主语与限定，尤其检查主体切换 |
| 多项成败不同的要求共用一个状态 | 已实现内容被另一项失败拖成 partial | 按独立成败重审自然语义片段 |
| 只遍历已生成的要求清单 | 从未列入的要求永远不会报缺失 | 另从完整原文逐句反查，阅读未引用文字 |
| 用条目数、有效锚点或译文齐全证明完整 | 数据格式正确，但语义仍有遗漏 | 分别报告语义覆盖与结构/保存验证 |
| 发现一处后只补该处 | 相同摘取方式造成的其他遗漏仍在 | 在当前授权分析范围内检查同类问题；仅讨论规则或升级插件时不改案例 |
