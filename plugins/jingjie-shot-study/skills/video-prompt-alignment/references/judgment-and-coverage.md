# 语义覆盖、证据与判定

用于拆分要求、选择证据和处理判定边界。按当前素材需要查阅，不据此替作者添加要求或固定输出结构。

## 1. 拆分到能独立核验的尺度

- 以一个可独立支持或反驳的主张为尺度，保留主体、属性、否定、程度、方向、条件和先后关系。“红球落下后蓝球才移动”必须核验两者及顺序，不能只确认两个动作出现。
- 复合要求可分出独立成败的部分，但不切断因果链。“缓慢推近”通常一起判断，速度与方向表现不同时再分别说明。
- 同义、中外文重复和多次证据不增加独立要求；不同对象、阶段或触发条件可分别核验。一项要求可涉及多个角度，无须强塞进单一类别。
- 持续设定与阶段变化分开，如“保持红色外壳”与“开灯后外壳反光”。作用范围由原文决定，不机械按“外观全局、动作局部”归类。
- 保留比较文本的来源、版本、顺序和完整原意；译文、分析概括与创作建议不覆盖原文。每个实质要求都应有分析去向，纯连接文字不必另拆。

## 2. 按任务选择分析角度

以下仅用于查漏，选用原文或任务实际涉及的角度，不要求全部覆盖或类别互斥。

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 可见主体及区分特征；现实身份需来源支持 |
| 外观与结构 | 服饰、形状、配件与部件；遮挡或低清处保留限制 |
| 场景与环境 | 场所、背景物及变化；具体地点名称需来源支持 |
| 动作与状态变化 | 起始、过程、结束；单帧不能证明方向或完成 |
| 表演与情绪 | 表情、姿态、节奏与声音表演；情绪作为解释 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及其变化 |
| 光线 | 受光面、阴影、高光与可见光源，区分方向推测与来源 |
| 构图 | 画内位置、尺度、留白及主体与环境关系 |
| 机位与视角 | 景别、俯仰角与观察方向，区分主体移动 |
| 运镜 | 视点、透视、背景视差与画框，区分主体运动和缩放 |
| 焦点与光学表现 | 清晰区域、焦点、景深与畸变；精确参数需可靠资料 |
| 色彩与美术风格 | 颜色关系与设计语言，按作品风格目标判断 |
| 材质与物理表现 | 反射、透明、形变、碰撞与流体，按写实或风格化目标判断 |
| 时序与节奏 | 持续时间、快慢、停顿、重复及事件顺序 |
| 剪辑与转场 | 实际切点与衔接，无剪切时不强拆 |
| 声音 | 实际试听的对白、音乐、音效、静默及声源方向 |
| 文字、图形与合成 | 屏幕文字、图层、遮挡及合成边缘，识别结果需回看 |
| 叙事与信息传达 | 事件、因果线索与揭示顺序，区分明确画面和解释 |
| 连续性与一致性 | 跨片段的身份、外观、空间、动作、状态及声音 |
| 教学与操作流程 | 可见步骤、状态、反馈与讲解对应 |
| 音画对应 | 声音与事件、口型或字幕的时间关系，分别检查两种证据 |
| 技术交付 | 文件尺寸、时长、帧率、音轨、编码等实际参数 |

## 3. 证据先于判断

1. 沿用已核实的同版媒体与时间基准，先了解待分析范围，再补查关键过程；切点只帮助定位，不限制按事件或状态组织观察。
2. 静态属性可用清晰帧；动态要求需过程证据。实际查看过、有序且对目标变化足够密集的真实帧序列可支持逐帧回看和近似定位，快动作、接触、遮挡或转场不足时继续加密。不能从单帧或稀疏首尾补造过程，也不因未实时播放抹去序列中的支持；如实注明观察方式。声音须实际试听，技术参数用媒体信息。
3. 动态支持对应实际发生的区间，不以作者预算、整镜边界、孤立帧点或整体缩放代替动作起落。不连续出现时分段保留；只确认到近似边界就标近似，精确判断再查相邻帧和时间戳。变速、剪裁、循环或换版本后重新核验位置。
4. 证据能回查到素材、时刻、对象及相关关系。一处局部支持不扩成全程成立；确认持续设定需覆盖其适用范围，清晰静帧也可提供直接反例。
5. 区分可见事实、解释与有来源的意图，不补造因果。例如窗户存在、脸受光、光来自窗户是不同主张；物件入画不能证明指定动作，抽样未发现违规不能证明全程满足否定要求。器材、模型、现实身份和精确参数也不能由观感反推。
6. 保存所需字段和关联遵循[镜界第8节](../../video-shot-study/references/jingjie.md#8-增强分析的时间对应与回读)；接口不能表达真实含义时，不靠改变要求范围或编造反例通过校验。

## 4. 判断实现情况及其边界

按要求的含义和适用范围判断，保留各子内容的证据与限制：

| 判断 | 适用情况 | 说明重点 |
|---|---|---|
| 已实现 | 对象、条件及范围均有足够支持 | 成立范围，不扩至未查部分 |
| 部分匹配（partial） | 要求已有相关实质支持，余下细节、条件或范围未核，或部分有偏差 | 分别说明已见支持、未核条件和真实反例（若有） |
| 失配 | 有直接矛盾，或充分检查确认必须出现的内容缺失 | 具体反例与依据，不能只说“没找到” |
| 待核（unverified） | 没有适当支持或反例，如未试听、缺参考、动作全被遮挡 | 缺什么证据，不把未知当失败 |
| 不适用 | 要求的前提在当前范围确实不成立 | 前提与理由，不掩盖缺证或偏差 |

- **全称反例优先：** 明确要求“全程”“每次”成立时，一个可靠反例即可判整体失配，仍保留其他片段的局部支持。其他复合要求可按部分匹配解释各部分，不在“整句实现”和“整句未知”之间二选一。
- 实质支持须落在要求的具体内容上；同一人物或道具出现、假设的因果、仅抽样未发现违规都不够。已有支持不能仅因余项未核而抹成待核，完全未查的内容也不能用 partial 掩盖。
- 持续属性、多次事件与多主体按各自范围检查，不能以一次成功替代“每次”，也不能因同义重复增加要求数量。完整检查须真正覆盖该问题所需证据，不等于文件已加载或抽帧覆盖首尾。
- 条件要求先核实触发再核对结果。“开门后灯亮”中，门未打开就不能验证条件关系；若开门本身也是必需动作，仍须单独判断，不能整句记不适用。
- 速度、程度、情绪等无量化标准时，结合原文解释依据，不擅加阈值；存在多种合理解释就保留边界。

## 5. 处理否定要求

- 肯定、否定和条件表达不改变所需证据类型：禁字幕仍看文字，禁闪烁仍查变化，无穿模仍看接触过程。
- 全称反例按第4节处理。要支持某范围内不存在某现象，须完成适合该现象的检查；稀疏帧不足以排除快闪或帧间穿模，没有字幕不证明静默。
- 未发现或检测器未报警本身不是满足证据，说明实际检查范围和检测限制，不把局部未见扩大为全片不存在。

## 6. 适配不同视频

- 真人、纪录与广告：可见外观不自动证明现实身份、历史真实性、性能或认证，相关主张需独立来源。
- 动画、游戏与特效：遵循作品的风格与世界规则；没有写实要求时，不将夸张重力、形变或材质直接当错。
- 教程、录屏、访谈及配音：分别检查可见操作/反馈、文字和实际声音；旁白声称成功不证明操作成功，字幕存在不证明音画同步。
- 无剪切、延时、循环：按事件、状态和实际时间观察，留意变速与重复帧，不强套镜头数。缺少一种模态不妨碍其他有依据的分析。

## 7. 完成前检查

- 全文实质要求有去向，条件、否定、程度和顺序完整，同义重复没有增加要求。
- 每项结论与证据、范围相称；观察、解释、意图及局部支持、反例、未核内容分清。
- 动态已见支持与文字关联了可回查的实际区间；尚无可用区间时明示时间对应未完成。镜界字段、回读与时间联动验收见[第8节](../../video-shot-study/references/jingjie.md#8-增强分析的时间对应与回读)。
- 交付说明观察方式和仍需补证的限制，既解释有效呈现也说明差异。仅在需要统计时说明口径、分母与范围，不以数量、拆分细度或写入成功代替分析完成。
