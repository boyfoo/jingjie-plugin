# 语义覆盖、证据与判定

用于在基础拉片的素材与镜头观察上，深化原始提示词或制作要求与画面的关系，并解释具体呈现、实现情况与差异。优先复用已有证据，按问题补查。以下是分析思路和判断依据，不限定交付结构或术语。分析角度用于查漏，不能因为清单中有某个角度，就替作者补写要求。

## 1. 拆分到能独立核验的尺度

- 确认比较基准及其来源：作者原始提示词、用户选定的脚本或创作要求不能混为一谈。保留完整原意与版本，翻译、简写和分析概括不能覆盖原文。没有明确比较基准时，只能整理观察和待补充的问题，不能根据成片反写要求，再宣称成片符合要求。
- 按“一个可以单独支持或反驳的主张”理解每段文字。保留主体、否定、程度、方向、先后和条件，避免只摘一个名词失去要求本意。
- “角色穿蓝色外套，走到门口后停下”包含外观、移动、停下及顺序关系；只关注动作会掩盖外观和顺序要求。“走到门口”也不能仅凭角色在门口的一帧得到确认。
- “缓慢推近”通常作为完整要求理解；当速度和运动方向呈现不同结果时，再分别解释。拆分服务于判断，不能把拆得越细当作分析越充分。
- 同一要求的中英文、同义表述、重复出现、多个证据帧及多个对应片段，不因此变成多个独立要求。针对不同对象或阶段的独立要求可以分别分析，但应说明差别来自哪里。
- 一项要求可以涉及多个角度。例如“暖光照在金属表面”同时涉及光线、颜色和材质，不必强制归入一个类别。若用户需要分类统计，再解释计数口径及重叠情况。
- 持续设定与具体事件分开理解：“保持红色外壳”是持续属性；“灯光切换时红色外壳出现反光”是条件事件。不能按“外观都是全局、动作都是局部”机械分类；应根据原文确认它对哪些对象、条件和阶段成立。
- 逐段回看原文，确认每个实质要求都已考虑，未能判断的也应说明原因。纯连接文字不必另作要求；难以验证或暂未观察的要求不能被悄悄略过。
- 只有任务需要时才统计数量或比例。梳理了多少、取得多少证据、确认实现多少是不同问题；重复和拆细不能提高实现率，没有可靠分母时不输出百分比。

## 2. 按任务选择分析角度

以下角度是一份可扩展的检查清单，只采用原文或任务实际需要的部分。遇到新题材，应从具体要求和可用证据补充分析角度；不要求每个视频覆盖全部类别，也不要求类别互斥。证据说明用于选择观察方法，并不意味着单张抽帧足够。

| 分析角度 | 主要核验证据 |
|---|---|
| 主体与身份 | 可见人物、动物、物体或界面实体及其区分特征；不可凭外观认定未知现实身份 |
| 外观与结构 | 服饰、形状、配件、部件组成；遮挡或低清处保留不确定性 |
| 场景与环境 | 场所、天气、背景物、可见环境变化；具体地点名称需另有来源支持 |
| 动作与状态变化 | 连续画面的起始、过程、结束状态；单帧不能证明动作方向或完成 |
| 表演与情绪 | 表情、姿态、节奏、声音表演；情绪判断作为解释而非心理事实 |
| 空间关系 | 前后、远近、朝向、接触、遮挡及运动中的相对关系 |
| 光线 | 受光面、阴影、高光、可见光源和时间变化；区分可见光源与推测光源 |
| 构图 | 画面边界内的位置、尺度、留白、对称和视觉引导；结合主体与环境的关系观察 |
| 机位与视角 | 景别、俯仰角、观察方向；不能仅凭主体移动判断机位改变 |
| 运镜 | 连续画面中视点、透视、背景视差和画框变化；区分相机运动、主体运动及裁切缩放 |
| 焦点与光学表现 | 清晰区域、焦点转移、景深、畸变和散景；焦距等精确参数需元数据或可靠来源 |
| 色彩与美术风格 | 颜色关系、调色、设计语言及风格一致性；遵循作品约定的风格目标 |
| 材质与物理表现 | 反射、透明、纹理、形变、碰撞及流体运动；按写实或风格化目标分别判断 |
| 时序与节奏 | 动作持续时间、快慢、停顿、重复、节拍以及事件顺序 |
| 剪辑与转场 | 实际切点、叠化、遮挡转场和镜头连接；无剪切视频不强行拆出剪辑点 |
| 声音 | 实际音轨中的对白、音乐、音效、静默和声源方向；字幕不能证明声音存在 |
| 文字、图形与合成 | 屏幕文字、字幕、图表、图层、遮挡和合成边缘；文字识别结果需回看画面核验 |
| 叙事与信息传达 | 事件、因果线索、信息揭示顺序；区分画面明确提供的信息与观众解释 |
| 连续性与一致性 | 跨时间或镜头的身份、外观、空间、动作、状态和声音一致性 |
| 教学与操作流程 | 可见步骤、界面状态、操作反馈及讲解对应；仅展示鼠标轨迹不能证明操作成功 |
| 音画对应 | 声音与可见事件、口型、字幕或教学步骤的时间关系；需分别检查相关内容 |
| 技术交付 | 实际文件的尺寸、时长、帧率、音轨、编码及其他明确约定的交付要求 |

“不要字幕”仍然需要检查可见文字，“不许闪烁”仍然需要检查光线或画面变化。要求是肯定、否定还是附带条件，与它涉及什么内容、最终是否实现是不同问题，应分别理解。

## 3. 证据先于判断

1. 确认分析对象是用户指定的实际文件或版本，并了解影响判断的时长、清晰度、音轨和播放时间基准。作者安排的时间不等于实际事件发生时间，应分别说明。
2. 先了解全片或现有材料，再按要求回看相关片段。切点可以帮助寻找证据；长镜头、录屏、动画也可以按事件或状态变化组织观察，不必硬套固定镜头数量或时长。
3. 静态属性可用清晰帧作证；动作、运镜及连续过程需相应的连续证据；确认全程一致需覆盖要求成立的范围，但清晰静帧仍可证明某一时刻的直接反例。声音需实际音轨，技术参数需媒体信息。截帧、接触表、检测器或转录只是辅助，不能让辅助材料的局限变成对原视频的结论。
4. 证据应能回查到具体素材及相关时刻或片段。描述空间关系时，说明涉及哪个主体、画面哪一部分、与什么对象构成何种关系；关系随时间改变时，应说明变化发生的阶段。全场色调、节奏或画外声音不必硬归到某个局部区域。
5. 把关系拆清楚，但不要补造看不见的原因。例如侧光可从受光面和阴影方向判断；窗户在画面里、脸部受光、光线来自窗户是三个相关但不等同的判断。看不到光源时可说明推测方向，不能把推测说成已经看见。
6. 时间精度应与证据相符。不能把大致发生阶段写成看似精确的毫秒；需要精确判断时，应回看实际播放时间或媒体时间戳。可变帧率、变速、循环和不同剪辑版本都可能使帧号或作者标注失准。
7. 分清观察事实、分析解释和作者意图。例如“背景相对主体产生视差”是观察，“可能为横移机位”是解释，“要营造压迫感”须有创作要求或可靠来源才称意图。每一步推断都应与证据强度相称。
8. 现实参数和感知效果分别核验：尺寸不能证明细节真实，编码帧率不能证明全部帧独立，锐化不能证明高解析度，电影感不能证明具体镜头或灯具型号。

## 4. 判断实现情况及其边界

结论描述的是要求在已检查范围内的实现情况。下面区分几种判断含义，实际表达应服务于解释，不需要套用固定名称。尚未完成检查属于证据不足，不能用“部分实现”掩盖“尚未看完”。

| 判断含义 | 适用情况 | 应解释清楚的内容 |
|---|---|---|
| 有证据支持实现 | 相关条件、对象、属性或事件在声明范围内有足够证据支持 | 依据及成立范围，不扩张到未检查部分 |
| 只有部分要求实现 | 已检查的复合要求只有一部分满足，或不同片段有不同表现 | 哪些部分实现、哪些部分偏离，以及各自依据 |
| 与要求存在偏差 | 有直接证据与要求矛盾，或充分检查后确认应发生的事件缺失 | 具体矛盾和检查依据，不能只写“没找到” |
| 暂时无法判断 | 没有足够、适当或完整的证据作出判断 | 缺少声音、遮挡、清晰度不足、未检查范围或其他原因 |
| 当前条件下不适用 | 按原文及明确任务范围，这项检查的前提不成立 | 前提及理由，不能用不适用隐藏已经违反的要求 |

- 一段实现、另一段偏离时，分别解释局部情况。若原要求明确“全程”或“每次”均须成立，一个经核验的反例就足以说明这一整体要求被违反，同时仍保留其他片段实现的事实。不能让一处成功覆盖全片偏差，也不能让一处失败抹去其他实现片段。
- 持续设定应按原文要求的有效范围检查。某帧衣着正确只支持该帧，不能直接确认全片保持；角色未入画或被遮挡的时间应承认不可观察。同一持续属性无需被重复解释为许多新的要求，但跨片段出现的变化仍需检查。
- 完整检查与抽样检查的结论力度不同。完整检查意味着确实检查了声明范围内该问题所需的画面、声音或其他证据，不能把文件已加载或抽帧覆盖首尾当作看完。
- 抽样未发现问题，只能说明所检查片段未见问题。样本可以支持局部成立，通常不足以确认整片始终满足；若抽样已发现明确反例，则可以据此指出相应偏差。
- 对重复事件和多主体，说明检查了哪些对象、哪些出现情况，不把一例当作全部实例。“每次出现都要有”与“至少出现一次”需要不同的检查范围。
- 条件要求先核实触发条件，再检查相应结果。若“开门后灯亮”中的门根本没有打开，应说明条件未发生；若开门本身也是必须发生的要求，则还要单独检查开门是否实现，不能将整句简单视作不适用。
- 程度、速度、情绪等要求可能含糊。结合原文上下文和可观察表现解释判断依据；缺少量化标准时避免擅自添加阈值，必要时承认多种合理解释。

## 5. 处理否定要求

- “不要字幕”“禁止闪烁”“无穿模”分别涉及文字、光线或技术表现、物理或连续性；不能因为它们采用否定表达就省略具体观察。
- 发现一次明确违反，就能证明该处偏离要求；抽样没有发现不等于全程不存在。
- 要确认完整声明范围内没有某种现象，需要适合该现象的完整检查。快速闪烁不能仅靠稀疏抽帧，静默不能仅凭没有字幕，帧间穿模不能仅看关键帧。
- 检测器未报警不自动等于确认满足。应考虑检测能力、检查范围以及必要的人工回看，无法完整检验时解释已检查部分和仍然未知的部分。

## 6. 适配不同视频

- 真人、纪录：区分画面中可见事实与无法由视频独立证明的身份、地点、历史真实性；没有证据时不替作者背书。
- 动画、游戏、特效：以要求的风格与世界规则为依据；夸张形变、非真实重力或不自然材质不自动构成错误。若明确要求写实，再核验相应物理目标。
- 广告、产品演示：外观呈现与性能主张分开；画面显示防水演示，不等于已经证明产品具备某项认证或真实性能。
- 教程、录屏：同时检查步骤、界面文字、状态变化、结果反馈和讲解时序；看不清文字就保留疑问，不能从旁白声称成功推断界面操作成功。
- 访谈、配音、音乐视频：字幕是可见文字的证据，音轨是说话或音乐的证据，二者不能相互代替；两者都存在也不意味着时间同步。
- 无剪切、延时、循环：按事件、状态和实际播放过程观察。循环次数、变速和重复帧会影响节奏判断，不能套用固定镜头数量或固定秒数规则。
- 缺少某种材料不妨碍其他要求继续分析。若要求明确包含声音但交付文件没有音轨，应先核实是否为正确版本，再判断该要求；若只提供截图，就不能推断原视频没有声音。

## 7. 完成前检查

- 逐段核对原意：实质要求没有遗漏，否定、条件、程度和先后没有丢失；同义、翻译和重复证据没有被当成额外要求。
- 回查结论：证据能支持相应判断，观察、解释与意图区分清楚，局部证据没有冒充全局结论，因果推断没有超出观察。
- 检查不确定性：没有把未检查当作已失败，没有把尚未发现当作不存在，没有用不适用回避实际偏差。
- 解释分析边界：说明梳理了什么、实际检查了什么、哪些要求实现或偏离、哪些仍需补证。表达详略随任务调整，不以固定数量或形式替代完整思考。
